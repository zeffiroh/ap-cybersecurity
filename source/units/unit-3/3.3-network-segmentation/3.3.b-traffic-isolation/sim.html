3.3.b - Private VLAN and Traffic Isolation[_][^][X]

Objective

Configure Private VLAN (PVLAN) port security classifications for the clinic switch. You must ensure that:

  • All hosts can communicate with the Internet Gateway.
  • Doctor workstations can communicate with each other (Community).
  • Guest devices and the legacy MRI machine are completely isolated from all hosts except the gateway.
