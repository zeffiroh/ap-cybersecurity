# 3.5.c tutor notes

Notes for the pre- and post-lecture tutor posts.

## The intuition to hold onto
The single sentence worth memorizing before this lecture, because it's the atom's entire argument in miniature: detecting an attack is the beginning of the story, not the end of it, and what an organization does in the next few hours is what actually determines whether this becomes a contained inconvenience or a catastrophe. Every detection tool this unit has built up, firewalls, IDS/IPS, traffic monitoring, exists to trigger this skill's process, not to replace it.

## The big picture
The ordering logic is the part worth being able to defend, not just recite: containment has to come before eradication because cleaning a still-connected host gives the attacker a chance to notice and either react or simply reinfect a moment later, and recovery has to wait for eradication to be verified complete because bringing a system back online before the root cause is actually gone just restarts the incident from the same starting point. That's not bureaucratic sequencing for its own sake, each phase is a genuine precondition for the next one succeeding at all, the same each-layer-assumes-the-one-before-it-held logic that ran through 3.2.c's defense-in-depth model, just applied to a timeline instead of a network diagram. And don't let Lessons Learned read as an afterthought: it's the phase that closes the loop back to Preparation, the very first phase, which is precisely why skipping it is how the *same* incident keeps recurring, the technical fix in Eradication handles this specific instance, but the process gap that allowed it in the first place (a missing patch policy, an unmonitored segment, exactly the kind of managerial-control failure 3.2.b warned about) goes unaddressed until someone deliberately writes it down and fixes it. This skill is a fitting closer for Unit 3 because it's where every technical control from 3.1 through 3.5, spoofing defenses, segmentation, firewalls, IDS/IPS, monitoring, finally meets the organizational process that decides whether any of it actually mattered when a real incident happens.
