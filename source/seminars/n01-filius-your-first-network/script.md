# Lecture script: Network lab 1: Your first network (Filius)

Free network lab · about 30 minutes · in Filius, a free program on your own computer

Read it aloud while you show the program on screen, or record your screen with the Teaching Desk. The captions are this text, word for word.

## Opening

Welcome to your first network lab. We'll install Filius, a free network simulator made for schools, cable four computers to a switch, and use ping to find out why one of them can't be reached.

## 1. Install Filius and meet the two modes

Welcome to your first network lab. We'll install Filius, a free network simulator made for schools, cable four computers to a switch, and use ping to find out why one of them can't be reached.

On screen: Filius, then the step's questions here.

## 2. Cable four computers to a switch

In design mode, drag one Switch and four Computers onto the canvas. Pick the Cable tool and click a computer, then the switch: Filius picks a free port for you. Cable all four.

On screen: Filius, then the step's questions here.

## 3. Ping, and explain the one that fails

Press the green arrow. Click till-1, open Software installation, add Command line, and press Apply. Open the command line and type ipconfig, then ping 192.168.1.12 and ping 192.168.1.13. Then ping 192.168.2.14.

On screen: Filius, then the step's questions here.

## 4. Fix it and watch the data exchange

Go back to design mode and change stray to 192.168.1.14. Run again and ping it: it answers now.

On screen: Filius, then the step's questions here.

## 5. Where next

You built a network, broke it on purpose and read the packets that fixed it. Network lab 2 adds a router, so two networks can talk.

On screen: Filius, then the step's questions here.

## Closing

That's a working network, a broken one, and the packets that explain the difference. Next we add a router.
