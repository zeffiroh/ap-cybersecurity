## 2. The same hunt in KQL

KQL starts with a table, then pipes into operators. Where filters. Summarize count by groups. Project picks columns. Sort by orders. Remember the count column is called count underscore, strings use double equals and double quotes. Run the hunt you ran in SPL. The answer must be identical. If it is not, one of the two searches is wrong, and finding which is the skill.
