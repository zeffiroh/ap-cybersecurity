# Aayat-AP-Prep · Cybersecurity

The complete AP Cybersecurity course: a textbook, 30 lecture decks, notes and slides for every topic,
practice for every skill, quizzes, assignments, adaptive unit tests and a capstone investigation.

**Opening the course.** Online, open the course's web address. Without internet, open the `offline`
folder and double-click **Start Offline (Windows)** or **Start Offline (Mac-Linux)**; the course opens
in your browser. Keep that window open while you work.

## For students

### Finding your way

Every page has the same bar across the top:

```
Aayat-AP-Prep / Cybersecurity v / Unit N v / X.Y Topic v | Overview Notes Slides Practice SimLab Flashcards Quiz Assignments Activities | <- X.Y   X.Y ->
```

- **Cybersecurity** opens the course pages: Book, Lectures, Glossary, Unit tests, CW/HW quizzes,
  Capstone, Calendar, Report card and Downloads.
- **Unit** and **Topic** jump anywhere in the course.
- The tabs show everything a topic has; the arrows go to the same tab of the previous or next topic.
- **Sign in** (just your email, no password) saves your progress online, so it follows you to any
  computer. Without signing in, progress stays in this browser.

### Working through a topic

1. **Notes**: read the topic.
2. **Slides**, or the lecture deck for that topic.
3. **Practice**: each skill has a lesson, a simulation, a coding problem and a short quiz.
4. **Quiz**: the topic quiz. Aim for 80% or more before moving on.

At the end of each unit, take the **unit test**.

### What each part does

| Part | How to use it |
|---|---|
| Notes | The topic as a readable chapter. |
| Slides | The topic's slide deck; use the arrow keys. |
| Practice | One page per skill: read the lesson, then use the Sim, Code and Quiz buttons at the top. |
| SimLab | Hands-on simulations, one per skill. |
| Flashcards | Click a card to flip it. **Export to Anki** downloads the deck for the Anki app. |
| Quiz | Choose **Practice** to see feedback after each answer, or **Exam** to see it at the end. |
| Assignments | Practice questions, plus the coding problems for the topic. |
| Coding problems | Write your code in the editor, press **Run Tests** until every test passes, then **Submit**. **Reset** brings back the starter code. |
| Activities | Classroom activities: tick off the materials to unlock the steps, log what you and your partner found, then submit the exit ticket. |
| Unit tests | Adaptive: each question depends on your previous answers. 8 to 24 questions. |
| CW/HW quizzes | Review quizzes for each unit. |
| Capstone | *Operation Quiet Harbor*, an investigation of a simulated hospital network. Its stages open as you finish the units. |
| Book | The whole textbook on one page, with a search box and "Check Your Understanding" questions. |
| Lectures | The 30 class decks; use the arrow keys. |
| Downloads | Printable quizzes and assignments (PDF and Word), topic slides (PowerPoint), flashcards (Anki) and the textbook (PDF). |
| Calendar | A suggested pace: two skills a day. |

### Your progress

**Progress** in the Cybersecurity menu shows a level for every skill:

| Level | How you get there |
|---|---|
| Attempted | any graded work on the skill |
| Familiar | the skill quiz or practice questions at 70% or more |
| Proficient | Familiar, plus a perfect skill quiz or a fully passing coding problem |
| Mastered | Proficient, plus passing the unit test or 80% or more on the topic quiz |

Topic, unit and course percentages are built from these levels. The **Report card** shows your
quiz and assignment scores; the **Skill quiz results on this device** link on the Progress page lists
the skill quizzes taken in this browser.

## For instructors

### The teacher hub

Teacher pages are not linked from any student page. Open `teacher/index.html` in the course's web
address (for example `https://<your-site>/teacher/`), or `site/teacher/index.html` when working from
the folder. Bookmark it.

The hub links to:

- **Class progress**: every student's level for every topic and skill; click a student for detail;
  export to CSV.
- **Class dashboard**: quiz and assignment scores.
- **Adaptive test dashboard**: unit test results for every student.
- **Database check**: confirms the shared gradebook is connected.
- **Tutor posts feed**, the support page and the site icon.
- **One page per topic**, with everything for teaching it:
  - the topic deck with speaker notes and the classroom PowerPoint;
  - answer keys for the quiz, the assignment and the activities (PDF and Word);
  - for each skill: the reference solution, solution and student notebooks, the assignment page,
    pre- and post-lecture posts and handouts;
  - the topic's Google Forms.
- **Lecture decks** with their PowerPoint files.

### Teaching asynchronously

Per topic: Notes, then Slides or the lecture deck, then each Practice skill (lesson, sim, code,
quiz), then the topic quiz with an 80% gate. At the end of each unit, the unit test; students below
Proficient get a tutoring session before moving on.

About 4–6 hours a week. A tutor's week: post the week's links on Monday (the topic's pre-lecture
posts are ready to paste); check the dashboards midweek and message anyone inactive or below the
gate; read check-ins and give feedback on one coding problem on Friday; a 15-minute one-to-one at the
end of each unit for anyone below the gate.

Weekly check-in, three questions: what could you explain to a friend; what tripped you up and what
did you try; your quiz scores.

### Grading

A starting point:

| Component | Weight | Where to find it |
|---|---|---|
| Skill quizzes | 15% | Class dashboard |
| Coding problems | 20% | Class dashboard (graded automatically) |
| Topic and CW/HW quizzes | 15% | Class dashboard, adaptive test dashboard |
| Unit tests (5) | 25% | Adaptive test dashboard |
| Capstone | 25% | Rubric in the capstone instructor guide |

The unit test sets the unit gate: **Proficient** or above passes. Per-skill bars in the test
dashboard show where a student is weak.

### Good to know

- Everything in the course is published, answer keys included; teacher pages are unlinked, not
  hidden. Students who go looking can find them.
- The gradebook is open by design: anyone who knows a student's email can see that student's report
  card. Students sign in with their email only.
- Progress and scores reach the dashboards only for students who signed in.
