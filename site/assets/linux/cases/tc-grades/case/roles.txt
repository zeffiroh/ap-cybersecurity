Westbrook High - grade system roles (excerpt)
teacher: view and change grades for their own classes; no approval needed for any change
head_of_year: view all grades in their year
registrar: view and change all grades; changes after report day need head teacher approval
remember-me: allowed on all school computers, token valid 7 days
MFA: required on staff laptops only
lab PCs: one shared browser profile for every user (kiosk image), so saved sign-ins stay after logoff
