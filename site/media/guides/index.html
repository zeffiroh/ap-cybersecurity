Lab guides

Your first investigation

Someone changed the school Wi-Fi welcome page using a teacher's account. Learn ls, cat, head, tail, grep, wc, cut, sort, uniq and sha256sum one at a time, and find the password guessing attack behind it.

The invoice that wasn't

A fake overdue invoice reaches three people at Kestrel Logistics. One opens it. An hour later the HR and Finance folders are encrypted. Find patient zero, trace the attack, contain it and choose a backup to restore.

Evidence, notes and handoffs

Rewrite a poor helpdesk ticket into a triage note, an escalation and a shift handover that the next analyst can act on, using the evidence from a real phishing case.

The night shift download

An engineer who has just resigned to join a competitor badges into an empty office at 01:47. Build a timeline from badge, VPN, Git, USB and DLP records, and handle it the right way: evidence first, then HR and Legal.

Reading evidence: packets, Linux, Windows and network sensors

Read four kinds of evidence from one night at a clinic: a Linux server's auth log and processes, a packet capture, Zeek connection logs and Windows event logs. Find a brute force, a script download, a beacon and a hop to a reception PC, then write a host triage note and a network finding.

Exam day outage

Five minutes into an online exam, the school's portal stops answering, and an extortion email arrives. Tell real students from attack traffic, name the three kinds of flood, and choose how to get the exam back.

Log search and detection as code

Run one hunt in SPL, KQL and SQL over real-format logs, parse a raw log into fields, then turn the hunt into Sigma rules you test for hits and false positives, tune, and convert with pySigma.

SOC triage: alerts, phishing, threat intel and AI verdicts

Work a ten-alert queue the morning after a ransomware attack: triage five reported emails, write and test a YARA rule, check indicators against intel and map them to ATT&CK, decode a suspicious command in CyberChef, and review an AI assistant's verdicts.

The hacked web shop

NimbuMart's web server is busy and sending data out. Follow the attacker from SQL injection to a web shell, a hidden backdoor and a command server.

The key in the commit

A deploy key with admin rights sat in an old Git commit. The repo went public for one evening. By 02:00 someone had copied customer data, made a backdoor admin and started 20 crypto-miners. Trace it, shut it down and fix the root cause.

Capstone A: the night shift

Run an overnight shift alone for a credit union client: an unlabelled, noisy queue of twelve alerts, one real intrusion hiding in it, and a morning team waiting for your escalation, a new detection and a shift report.

The miner in the build server

Brightloom Games' build server has run at full CPU all night. Trace a brute-forced CI login to a script console, a dropper, three kinds of persistence and a cryptominer talking to a mining pool, then clean up and rebuild.

Incident response: ransomware, lateral movement and memory

Take a ransomware incident at an engineering firm from the first call to the executive summary: keep a chain of custody, rebuild the night from VPN, Windows, Sysmon and process logs, read memory-forensics and triage output, map every step to ATT&CK, decide under pressure in a tabletop, and write the report.

Quiet DNS

A Finance laptop at Harbourline Credit Union never touched the internet, yet a confidential file left the building. Find the DNS tunnel, measure it, and rebuild the stolen file from base32 chunks hidden in query names.

Breach clocks: CERT-In 6 hours, DPDP, RBI and GDPR

Rehearse a personal-data breach at a microfinance company after India's DPDP breach rules take effect: start the clock, scope the breach from the logs, file with CERT-In inside six hours while injects arrive, work out every other clock that applies (RBI, DPDP, GDPR), and write the Board note, the notice to customers and the notification order.

Identity from both sides: AD, Entra and cloud IAM

Review a company's accounts like an auditor, then walk the same directory like an attacker: find the path from a helpdesk login to Domain Admins, see the kerberoast and the DCSync in the domain controller's logs, follow a stolen cloud key through the audit trail, and cut it all off with a least-privilege policy and detections.

Cloud and DevSecOps: posture, pipelines, secrets and automation

Audit a start-up's repository, pipeline and cloud account the way a cloud security engineer does: find leaked secrets (including in Git history), vulnerable packages and unsafe Dockerfile, Kubernetes and Terraform settings, read Trivy, Checkov and Prowler output, cut a leaked key down to least privilege, rank every finding, write the pipeline gate, automate the response, and test a Python check.

Authorised testing: web, APIs and findings that get fixed

Run a small, authorised penetration test of the NimbuMart shop the way professionals do: rules of engagement first, recon inside scope, then three findings proved with the intercept proxy and the JWT inspector, scored with CVSS, written up so a developer can fix them, retested, and explained to the board.

Design, risk and audit

Review a new payments feature before it ships: threat-model it with STRIDE and an attack tree, write the design review memo, build the risk register, mark an ISO 27001 Statement of Applicability with evidence, write an audit exception that an auditor will accept, and decide on a vendor.

AI security: attacking and governing LLM apps

Test a travel company's support assistant the way an AI red team does: direct and indirect prompt injection, secrets spelled out and encoded, poisoned documents in its knowledge base, and tools it calls without asking. Then defend it layer by layer, and write the test report, the company's AI policy and its AI risk register.

Capstone B: a breach across teams

A breach at a payroll company that crosses every team: a password spray on the VPN, a scan and a script with secrets on a file share, a hop to an application server, salary files copied out on-premises and from the cloud. No hints. Rebuild it, scope it, contain it, file and notify on time as a data processor, leave new detections behind, and brief the board.

Who changed the grades?

Grades changed under a teacher's name, in subjects he doesn't teach, from a student lab PC. Use the audit log, sign-in records and lab logins to find out how, and fix the access control.

Password spraying at the library portal

Nobody was locked out, yet a library member's account was taken over. Find the slow password spray, the one account it opened and what the attacker changed.

The QR code parking fine

Fake parking fines arrive by text and by QR stickers on parking meters. Compare the fake site with the real one and find where the card details go.
