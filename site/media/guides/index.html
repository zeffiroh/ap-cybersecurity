Lab guides

Your first investigation

Someone changed the school Wi-Fi welcome page using a teacher's account. Learn ls, cat, head, tail, grep, wc, cut, sort, uniq and sha256sum one at a time, and find the password guessing attack behind it.

The invoice that wasn't

A fake overdue invoice reaches three people at Kestrel Logistics. One opens it. An hour later the HR and Finance folders are encrypted. Find patient zero, trace the attack, contain it and choose a backup to restore.

Evidence, notes and handoffs

Rewrite a poor helpdesk ticket into a triage note, an escalation and a shift handover that the next analyst can act on, using the evidence from a real phishing case.

The night shift download

An engineer who has just resigned to join a competitor badges into an empty office at 01:47. Build a timeline from badge, VPN, Git, USB and DLP records, and handle it the right way: evidence first, then HR and Legal.

Exam day outage

Five minutes into an online exam, the school's portal stops answering, and an extortion email arrives. Tell real students from attack traffic, name the three kinds of flood, and choose how to get the exam back.

Log search and detection as code

Run one hunt in SPL, KQL and SQL over real-format logs, parse a raw log into fields, then turn the hunt into Sigma rules you test for hits and false positives, tune, and convert with pySigma.

SOC triage: alerts, phishing, threat intel and AI verdicts

Work a ten-alert queue the morning after a ransomware attack: triage five reported emails, write and test a YARA rule, check indicators against intel and map them to ATT&CK, decode a suspicious command in CyberChef, and review an AI assistant's verdicts.

The hacked web shop

NimbuMart's web server is busy and sending data out. Follow the attacker from SQL injection to a web shell, a hidden backdoor and a command server.

The key in the commit

A deploy key with admin rights sat in an old Git commit. The repo went public for one evening. By 02:00 someone had copied customer data, made a backdoor admin and started 20 crypto-miners. Trace it, shut it down and fix the root cause.

Capstone A: the night shift

Run an overnight shift alone for a credit union client: an unlabelled, noisy queue of twelve alerts, one real intrusion hiding in it, and a morning team waiting for your escalation, a new detection and a shift report.

The miner in the build server

Brightloom Games' build server has run at full CPU all night. Trace a brute-forced CI login to a script console, a dropper, three kinds of persistence and a cryptominer talking to a mining pool, then clean up and rebuild.

Quiet DNS

A Finance laptop at Harbourline Credit Union never touched the internet, yet a confidential file left the building. Find the DNS tunnel, measure it, and rebuild the stolen file from base32 chunks hidden in query names.

Logs with pandas

Load web server logs into pandas tables, count and group like an analyst, spot the one connection that sent 48 MB out, and build a tiny phishing classifier you can read line by line.

Who changed the grades?

Grades changed under a teacher's name, in subjects he doesn't teach, from a student lab PC. Use the audit log, sign-in records and lab logins to find out how, and fix the access control.

Password spraying at the library portal

Nobody was locked out, yet a library member's account was taken over. Find the slow password spray, the one account it opened and what the attacker changed.

The QR code parking fine

Fake parking fines arrive by text and by QR stickers on parking meters. Compare the fake site with the real one and find where the card details go.
