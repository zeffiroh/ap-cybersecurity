Network lab 8: Capture a link in Wireshark (GNS3)

Intermediate · about 40 min

Build a tiny network in GNS3 with its built-in computers and switch, start a capture on a link, and read ARP and ICMP packets in Wireshark.

WalkthroughPracticeSolo

The files for this seminar are in ~/case (Linux) and case/ (Python): README.txt.

1. Install GNS3 and place three nodes

GNS3 is free and open source. Download it from https://www.gns3.com (a free account is needed), and install Wireshark when the installer offers it. This lab uses only the built-in VPCS computers and the built-in Ethernet switch, so you don't need any router images or the GNS3 VM.

Start a new project. From End devices, drag two VPCS nodes; from Switches, drag one Ethernet switch. Use Add a link to join each VPCS to the switch. Press the green Start button.

  • ☐ GNS3 and Wireshark installed
  • ☐ Two VPCS and one Ethernet switch, linked
  • ☐ All nodes started (green)

Hint: If GNS3 asks to run nodes on the GNS3 VM, choose to run them on your local computer for this lab.

Question: What are GNS3's built-in simple computers called? (four letters)

2. Give the computers addresses

Right-click PC1 → Console, and type ip 10.0.0.1/24 10.0.0.254. On PC2: ip 10.0.0.2/24 10.0.0.254. Check with show ip.

  • ☐ PC1 and PC2 addressed
  • ☐ show ip checked on both

Hint: The VPCS ip command takes the address with its prefix length, then the gateway.

Question: Which VPCS command shows a computer's address?

3. Capture and read the packets

Right-click the link between PC1 and SW1 → Start capture. Wireshark opens. On PC1, type ping 10.0.0.2. In Wireshark, type the display filter arp || icmp and read the list from the top: an ARP request (who has 10.0.0.2?), an ARP reply, then ICMP Echo (ping) request and reply pairs. Click one echo request and open Internet Control Message Protocol in the details pane to see its type.

  • ☐ Capture running on the PC1 link
  • ☐ arp || icmp filter applied
  • ☐ ARP pair and echo request/reply pairs found
  • ☐ ICMP type read in the details pane

Hint: Echo request is ICMP type 8, echo reply is type 0.

Question: Which ICMP type number is an echo request? Question: Which protocol asks "who has 10.0.0.2" first? (three letters)
