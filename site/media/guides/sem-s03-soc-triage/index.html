1. How the alert queue works

Before you triage, learn the program. An alert queue (the triage console of a SOC) takes alerts from many sources, the mail gateway, the proxy, antivirus, sign-in logs and staff who press Report phishing, and lines them up for a person to decide.

Every alert carries the same fields: an ID, the time, the rule that fired, the host and user it is about, a detail line, and the evidence files to open next. The queue doesn't decide anything. You give each alert one disposition:

Disposition Meaning
True positive: escalate Real, and a person must act now
True positive: handled Real, and already contained (blocked, removed, quarantined)
Benign: expected activity The rule worked, but what it saw is normal here
False positive: rule fired wrongly The rule matched something it was never meant to catch
Needs more information You can't decide yet: write the question and who can answer it

The Linux cell shows the raw queue file, so you can see that the program is only reading JSON. The queue below is the one you will work today, at Lotus Lake Hotels in Udaipur. Don't set any dispositions yet: just open it and look around. Read README.txt first.

  • ☐ Compare the raw JSON with how the queue shows the same alert
  • ☐ Open one alert's evidence list
  • ☐ Find the summary line that counts dispositions

Hint: The difference between "handled" and "benign" is whether anything bad happened. A blocked phishing click is handled; a scanner doing its job is benign.

5. Decode the suspicious command

AL-4106 is an encoded PowerShell command on pms01, the server that runs the hotel's booking system. Encoding hides what a command does, which is why attackers use it, but IT scripts sometimes use it too. Decode it before you judge it.

Open the command in CyberChef (From Base64, then Decode text as UTF-16LE). Or decode it in the Linux cell.

  • ☐ Decode the command
  • ☐ What does it do? Is anything in it harmful?
  • ☐ Which account runs it, and when?
  • ☐ Write the disposition and a note to IT: an encoded command in a scheduled task trips the alert every night

Hint: PowerShell's -EncodedCommand is Base64 of UTF-16LE text. On Linux, base64 -d decodes it and tr -d '\000' drops the zero bytes UTF-16 puts between letters.

8. Review the AI assistant's verdicts

The SOC's AI triage assistant gave a verdict on every alert. It is fast and usually right, but it only sees the alert text, not your evidence, and it reads everything in that text, including words an attacker wrote. Agree, or override it and say why. Every override needs a fact from the evidence.

  • ☐ Read each verdict and its reason
  • ☐ Agree or override
  • ☐ For each override, the fact that proves it wrong
  • ☐ For each override, the kind of mistake: too trusting, too alarmed, missing context, or obeying text an attacker wrote

Hint: Four verdicts are wrong. One trusted a display name. One believed a sentence inside the email that was written for it. One was alarmed by encoding without decoding it. One didn't know about the trade show.
