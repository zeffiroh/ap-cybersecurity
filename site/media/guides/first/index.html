Tutorial guide

Your first investigation

Beginner · about 25 min

Someone changed the school Wi-Fi welcome page using a teacher's account. Learn ls, cat, head, tail, grep, wc, cut, sort, uniq and sha256sum one at a time, and find the password guessing attack behind it.

Worked exampleGuidedOn your own

Monday 2 Nov, 10:25. At Maple Grove School the Wi-Fi welcome page in the library is showing strange text. The change log says a teacher's account made the change, but the teacher says it wasn't him. You are the new student helper in the IT office, and this is your first case.

You will use one Linux command at a time. Every step explains a command, lets you run it, and asks you one question about what you saw.

What you'll learn

  • ls, cat, head and tail to look at evidence safely
  • grep and wc -l to find and count lines
  • cut, sort and uniq -c to turn a log into a ranking
  • sha256sum to fingerprint files and test passwords
  • nmap, dig and curl to look at the network
  • How a password guessing attack shows up in a log

How to use this runbook

  • Run a cell with Shift+Enter (or its Run button). Run the cells in order: the first Linux cell copies the evidence into ~/case.
  • Tick each - [ ] box when you have done it.
  • Stuck? Open a Hint under the step.
  • Type your answer into each check box and it tells you if you are right. Answers are short: an address, a name, a number or a time such as 09:05.
  • Write your notes under each step. Download .ipynb keeps your notes and every output.

6. Rank the addresses: cut, sort, uniq -c

This is the most useful pattern in log work. Each command passes its output to the next with a pipe |:

  1. grep FAIL keeps the failed lines
  2. cut -d' ' -f5 keeps the 5th field (fields are separated by spaces), which is src=...
  3. sort puts the same addresses next to each other
  4. uniq -c counts each group
  5. sort -rn puts the biggest number first
  • ☐ Run it, then change -f5 to -f4 to rank the usernames instead

Hint: The top line is the address with the most failures. Question: Which address failed most often? (just the IP)

grep FAIL wifi_login.log | cut -d' ' -f5 | sort | uniq -c | sort -rn
echo ---
grep FAIL wifi_login.log | cut -d' ' -f4 | sort | uniq -c | sort -rn

Expected output

      1 src=10.10.0.41

      1 src=10.10.0.102
---

9. Fingerprints: sha256sum

sha256sum FILE prints a 64-character fingerprint (a hash). Change one letter in the file and the hash changes completely. Investigators hash evidence so they can prove later it was not changed.

The portal stores a hash of each password instead of the password. But it uses plain SHA-256 with no salt, so anyone can hash a list of common passwords and look for a match. That is exactly what a guessing attack exploits.

  • ☐ Hash the evidence files
  • ☐ Hash each common password and look for it in portal_hashes.txt

Hint: echo -n WORD | sha256sum hashes a word. -n stops echo adding a newline, which would change the hash. Hint: The loop prints any username whose stored hash matches a common password. Question: Which common password is mr.patel using? Question: Which other account uses the same password?

sha256sum *.log *.csv *.txt
echo ---
for p in $(cat common_passwords.txt); do
    h=$(echo -n "$p" | sha256sum | cut -d' ' -f1)
    grep "$h" portal_hashes.txt | while read user hash; do echo "$user uses: $p"; done
done

10. The network: nmap, dig, curl

The network tools work on a recorded copy of the school network; nothing leaves your browser.

  • nmap -sn 10.10.0.0/24 asks which machines are switched on
  • dig +short NAME turns a name into an address

  • curl URL fetches a web page, like a browser without the pictures

  • ☐ Is the attacker's device (10.10.0.66) still on the network?

  • ☐ Look at the Wi-Fi welcome page the attacker changed

Hint: Count the Nmap scan report lines. 10.10.0.66 is not one of them: the device has left. Question: How many machines does nmap find up? Question: What address does wifi.maplegrove.lan point to?

11. The changed banner (the flag)

The attacker replaced banner.txt with text that looks like nonsense. It ends in =, a sign of base64: a way to write any data with plain letters. base64 -d decodes it.

  • ☐ Fetch the banner and decode it
  • ☐ Submit the aayat{...} flag on the CTF board

Hint: curl -s URL | base64 -d fetches and decodes in one line. Add ; echo to get a clean new line.

curl -s http://wifi.maplegrove.lan/banner.txt
echo ---
curl -s http://wifi.maplegrove.lan/banner.txt | base64 -d; echo
