Network lab 2: Two networks and a router (Filius)

Beginner · about 40 min

Join two office networks with a router, set every computer's gateway, and trace a packet's path across it.

WalkthroughPracticeSolo

The files for this seminar are in ~/case (Linux) and case/ (Python): README.txt.

1. Build both networks

In design mode, make two groups: two computers and a switch for the shop, two computers and a switch for the back office. Add one Router between them. When Filius asks, give it 2 interfaces. Cable the router to both switches.

  • ☐ Two switches, four computers
  • ☐ One router with two interfaces, cabled to both switches
  • ☐ Addresses typed from README.txt

Hint: Each router interface belongs to one network, so each needs its own address.

Question: How many interfaces does the router need here?

2. Set the gateways

Click the router and give interface 1 192.168.1.1 and interface 2 192.168.2.1, both with netmask 255.255.255.0. Now set every computer's Gateway: shop computers use 192.168.1.1, back-office computers use 192.168.2.1.

The gateway is where a computer sends anything that isn't in its own network.

  • ☐ Router interfaces set
  • ☐ Shop gateways 192.168.1.1
  • ☐ Back-office gateways 192.168.2.1

Hint: A gateway must be inside the computer's own network. 192.168.2.1 is useless as a gateway for till-1.

Question: What is till-1's gateway? Question: Which device carries packets between the two networks: the switch or the router?

3. Ping across, then break a gateway

Run the simulation. From till-1, ping accounts at 192.168.2.21: it answers. Open Show data exchange on the router while you ping, and see the same packet arrive on one interface and leave on the other.

Now go back to design mode, delete manager's gateway, and run again. Manager can still ping accounts (same network) but not till-1. Put the gateway back.

  • ☐ till-1 to accounts works
  • ☐ Router data exchange shows the packet on both interfaces
  • ☐ Without a gateway, manager only reaches its own network

Hint: A missing gateway is one of the most common faults on real help desks: "I can print but I can't reach the internet".

Question: Without a gateway, can manager reach till-1? (yes or no)
