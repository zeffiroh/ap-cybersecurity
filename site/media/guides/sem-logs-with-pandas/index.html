2. Who did web01 talk to?

Group by destination and port, then add up the bytes. This is the same as a SIEM stats sum(bytes_out) by dst, dport.

  • ☐ Find the destination that received the most bytes
  • ☐ Notice the unusual port

Question: Which port carried most of the data?

import pandas as pd

df = pd.read_csv("case/conn.csv", parse_dates=["time"])
out = df.groupby(["dst", "dport"]).agg(connections=("bytes_out", "size"), bytes_out=("bytes_out", "sum")).sort_values("bytes_out", ascending=False)
print(out)

3. Find the odd one out

Most beacon connections send about 240 bytes. A robust score compares each value with the median, so one huge value can't hide itself by pulling the average up.

  • ☐ Read the score for each connection to port 4444
  • ☐ Find the connection that stands out

Hint: a robust z-score above 3.5 is a common cut-off.

Question: At what time did the big upload happen? (HH:MM)

import pandas as pd

df = pd.read_csv("case/conn.csv", parse_dates=["time"])
beacon = df[df["dport"] == 4444].copy()
median = beacon["bytes_out"].median()
mad = (beacon["bytes_out"] - median).abs().median()
beacon["score"] = 0.6745 * (beacon["bytes_out"] - median) / mad
print(beacon[["time", "bytes_out", "score"]].round(1).to_string(index=False))
print()
print(beacon[beacon["score"] > 3.5][["time", "bytes_out"]].to_string(index=False))

4. A phishing classifier you can read

subjects.csv has 20 email subjects marked phish or ham (normal mail). The cell counts which words appear in each kind, then scores new subjects with naive Bayes: the words of a subject vote for the side they appear in more often.

  • ☐ Run it and read the words that count most
  • ☐ Add your own subject to the tests list and run it again

Hint: a model trained on 20 emails is a toy. Real filters learn from millions, and attackers keep changing their words.

Question: Which label does the model give "Quarter-end report attached for comments"?

import math
import re
from collections import Counter

import pandas as pd

data = pd.read_csv("case/subjects.csv")


def words(text):
    return re.findall(r"[a-z]+", text.lower())


counts = {label: Counter() for label in data["label"].unique()}
docs = Counter(data["label"])
for subject, label in zip(data["subject"], data["label"]):
    counts[label].update(set(words(subject)))
vocab = set().union(*counts.values())


def score(subject):
    best = None
    for label in counts:
        s = math.log(docs[label] / len(data))
        total = sum(counts[label].values()) + len(vocab)
        for w in words(subject):
            s += math.log((counts[label][w] + 1) / total)
        if best is None or s > best[1]:
            best = (label, s)
    return best[0]


lean = sorted(vocab, key=lambda w: (counts["phish"][w] + 1) / (counts["ham"][w] + 1), reverse=True)
print("Words that lean phish:", ", ".join(lean[:8]))
tests = ["Quarter-end report attached for comments", "Verify your account today or it will be suspended", "Team lunch moved to Thursday"]
for t in tests:
    print(f"{score(t):5}  {t}")
