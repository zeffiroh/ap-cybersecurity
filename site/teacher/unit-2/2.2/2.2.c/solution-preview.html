1. Brief

The situation. The IT security team receives reports whenever a device is reported stolen or found to show signs of tampering. Each report needs to be triaged into a risk level so the team knows what needs an immediate incident response versus what can be logged and monitored.

Your task is to write a function solve(data) that takes a list of incident reports and returns a dictionary mapping each incident's id to a risk level: "LOW", "MEDIUM", or "HIGH".

Rules, by incident type

type == "theft" (a device was physically taken): 1. "HIGH" if the device was not encrypted (encrypted is False), an unencrypted stolen device exposes its data with no cryptographic barrier. 2. "MEDIUM" if the device was encrypted, but contains_sensitive_data is True and hours_since_check is greater than 48, encryption protects the data, but a long detection delay on a sensitive device still raises risk (e.g., the device may have been unlocked and in active use when taken). 3. "LOW" otherwise.

type == "tampering" (a device was found to show signs of covert alteration): 1. "HIGH" if the tamper-evident seal was not intact (seal_intact is False), physical evidence the enclosure was opened. 2. "MEDIUM" if the seal was intact but hours_since_check is greater than 48, a long window since the last inventory check means tampering that does not require opening the enclosure (e.g., a rogue USB implant) could have gone unnoticed even with an intact seal. 3. "LOW" otherwise.

Any other type value should be treated as "LOW".

Lesson objective. Distinguish device theft from device tampering, identify the attack techniques each enables (offline password reset, disk imaging, hardware implants, evil-maid attacks), and evaluate whether a given device's configuration (encryption, boot protections, asset tracking) would contain the damage if the device were stolen or tampered with.

What comes in

A list of dictionaries, each representing one incident report:

[
    {
        "id": "inc-1",
        "type": "theft",
        "encrypted": False,
        "seal_intact": True,
        "contains_sensitive_data": True,
        "hours_since_check": 10,
    },
    {
        "id": "inc-2",
        "type": "tampering",
        "encrypted": True,
        "seal_intact": False,
        "contains_sensitive_data": False,
        "hours_since_check": 5,
    },
]

Every report includes all five fields (type, encrypted, seal_intact, contains_sensitive_data, hours_since_check), even if a field is not relevant to that report's type (e.g., seal_intact is present but ignored for type == "theft").

What must come out

A dictionary mapping each incident's "id" to its risk level string:

{
    "inc-1": "HIGH",
    "inc-2": "HIGH",
}

Entry point

def solve(data: list[dict]) -> dict[str, str]

Input (data)

A list of dictionaries representing device incident reports. Each dictionary contains: - id (str): Unique identifier for the incident. - type (str): "theft" or "tampering" (other values default to "LOW"). - encrypted (bool): Whether the device's storage was encrypted. - seal_intact (bool): Whether the tamper-evident seal was intact when discovered. - contains_sensitive_data (bool): Whether the device held sensitive data. - hours_since_check (float/int): Hours since the device was last verified present/unaltered.

Output (result)

A dictionary where keys are the id of each incident from the input and values are the risk level: "LOW", "MEDIUM", or "HIGH".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only.
  • Rules by type (see the problem statement above for full detail):
  • theft: not encrypted -> HIGH; encrypted and contains_sensitive_data and hours_since_check > 48 -> MEDIUM; else LOW.
  • tampering: not seal_intact -> HIGH; seal_intact and hours_since_check > 48 -> MEDIUM; else LOW.
  • any other type -> LOW.

3. Build it

This is the model solution.

  • [ ] solve handles your edge cases
def _theft_risk(incident: dict) -> str: if not incident["encrypted"]: return "HIGH" if incident["contains_sensitive_data"] and incident["hours_since_check"] > 48: return "MEDIUM" return "LOW" def _tampering_risk(incident: dict) -> str: if not incident["seal_intact"]: return "HIGH" if incident["hours_since_check"] > 48: return "MEDIUM" return "LOW" def solve(data: list[dict]) -> dict[str, str]: results = {} for incident in data: rid = incident["id"] itype = incident["type"] if itype == "theft": results[rid] = _theft_risk(incident) elif itype == "tampering": results[rid] = _tampering_risk(incident) else: results[rid] = "LOW" return results
