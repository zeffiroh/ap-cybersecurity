1. Brief

The situation. You are building the alerting logic for the IP camera network at Crestfield Analytics. Each camera emits a stream of motion/detection events. Given the full event log (already sorted ascending by timestamp), identify every alert condition described below and return a sorted, de-duplicated list of alert strings.

This mirrors the lesson's monitoring concepts: active monitoring depends on software correctly surfacing anomalies (after-hours presence, a person lingering where they shouldn't, a "ghost motion" pattern consistent with a camera fault or someone deliberately avoiding facial capture) so a human operator or SIEM can act on them.

Lesson objective. Describe the components and layout of physical surveillance systems, explain the security differences between active and passive monitoring, and analyze vulnerabilities in surveillance networks to recommend mitigations.

What comes in

events: list[dict], sorted ascending by "ts", each dict has: - "camera_id": str - "ts": int, Unix timestamp (seconds, UTC) - "motion": bool - "person_detected": bool - "area": str - "authorized_hours": tuple[int, int], (start_hour, end_hour), both in 0..24

What must come out

A sorted, de-duplicated list[str] of alert strings, e.g. "AFTER_HOURS:CAM-01", "GHOST_MOTION:CAM-02", "CROWD_SERVER_ROOM". Empty list if no alerts.

<details><summary>Reference: the exact contract</summary>

Entry point

def solve(events: list[dict]) -> list[str]

Input (events)

list[dict], sorted ascending by "ts", where each dict has: - "camera_id": str, camera identifier, e.g. "CAM-01" - "ts": int, Unix timestamp in seconds (UTC) - "motion": bool, whether the camera's motion sensor triggered - "person_detected": bool, whether analytics confirmed a person in frame - "area": str, the monitored area name, e.g. "lobby", "server_room" - "authorized_hours": tuple[int, int], (start_hour, end_hour) UTC hours during which a person detection at this camera is authorized; authorized iff start <= hour < end

Output (result)

A sorted, de-duplicated list[str] of alert strings. Empty list if no alerts.

Alert rules

  • AFTER_HOURS:\<camera_id>: flag if any event on that camera has person_detected == True and its timestamp's UTC hour ((ts % 86400) // 3600) falls outside authorized_hours.
  • GHOST_MOTION:\<camera_id>: flag if that camera has 3 or more consecutive events (in timestamp order) with motion == True and person_detected == False. Any event with motion == False or person_detected == True resets the streak to 0.
  • CROWD_SERVER_ROOM: flag once (globally, not per-camera) if more than 2 events anywhere have person_detected == True and area == "server_room" within any 60-second sliding window.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Output always sorted ascending and de-duplicated (a set internally, then sorted(...)).
  • Empty events input returns [].

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

from __future__ import annotations from collections import defaultdict def solve(events: list[dict]) -> list[str]: if not events: return [] alerts: set[str] = set() for ev in events: if ev["person_detected"]: hour = (ev["ts"] % 86400) // 3600 start, end = ev["authorized_hours"] if not (start <= hour < end): alerts.add(f"AFTER_HOURS:{ev['camera_id']}") cam_events: dict[str, list[dict]] = defaultdict(list) for ev in events: cam_events[ev["camera_id"]].append(ev) for cam_id, cam_evs in cam_events.items(): streak = 0 for ev in cam_evs: if ev["motion"] and not ev["person_detected"]: streak += 1 if streak >= 3: alerts.add(f"GHOST_MOTION:{cam_id}") break else: streak = 0 server_ts = sorted( ev["ts"] for ev in events if ev["person_detected"] and ev["area"] == "server_room" ) n = len(server_ts) for i in range(n): count = 1 for j in range(i + 1, n): if server_ts[j] - server_ts[i] <= 60: count += 1 if count > 2: alerts.add("CROWD_SERVER_ROOM") break else: break if "CROWD_SERVER_ROOM" in alerts: break return sorted(alerts)
