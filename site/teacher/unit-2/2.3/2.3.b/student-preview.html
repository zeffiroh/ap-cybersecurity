Coding problem, 2.3.b: Camera event log anomaly detector

Skill: Detect Attacks · Maps to: 2.3.A · Language: Python 3 (pytest)

Problem

You are building the alerting logic for the IP camera network at Crestfield Analytics. Each camera emits a stream of motion/detection events. Given the full event log (already sorted ascending by timestamp), identify every alert condition described below and return a sorted, de-duplicated list of alert strings.

This mirrors the lesson's monitoring concepts: active monitoring depends on software correctly surfacing anomalies (after-hours presence, a person lingering where they shouldn't, a "ghost motion" pattern consistent with a camera fault or someone deliberately avoiding facial capture) so a human operator or SIEM can act on them.

Alert rules

  • AFTER_HOURS:\<camera_id>, a person was detected (person_detected: True) at a camera outside that event's authorized_hours window. authorized_hours is a (start, end) tuple of UTC hours; an hour h is authorized if start <= h < end. The hour of an event is derived from its Unix timestamp: hour = (ts % 86400) // 3600.
  • GHOST_MOTION:\<camera_id>, 3 or more consecutive events on the same camera (in timestamp order) where motion is True but person_detected is False. Any event that breaks the pattern (motion is False, or person_detected is True) resets the streak count to zero. "Ghost motion" describes a camera repeatedly reporting motion with nothing confirmed human, often a maintenance issue (foliage, a loose mount) or a deliberate attempt to trigger false fatigue in an operator.
  • CROWD_SERVER_ROOM, more than 2 person_detected: True events occur in area == "server_room" within any 60-second sliding window (across any cameras). This is a single global alert, not per-camera.

Function contract

Implement solve(events) in the code editor (see the Reference section below).

Input

events: list[dict], sorted ascending by "ts", each dict has: - "camera_id": str - "ts": int, Unix timestamp (seconds, UTC) - "motion": bool - "person_detected": bool - "area": str - "authorized_hours": tuple[int, int], (start_hour, end_hour), both in 0..24

Output

A sorted, de-duplicated list[str] of alert strings, e.g. "AFTER_HOURS:CAM-01", "GHOST_MOTION:CAM-02", "CROWD_SERVER_ROOM". Empty list if no alerts.
