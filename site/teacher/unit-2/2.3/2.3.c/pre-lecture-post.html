2.3.c, Security guards and layered defense-in-depth

Before class today. No single security control protects a facility completely. A lock can be picked. A camera can be obscured.

The intuition to hold onto: The idea to internalize here is that layers don't add security, they multiply the attacker's cost, and that distinction matters more than it sounds like it should. If a facility has five independent control categories, an attacker doesn't need to be five times as capable; they need to succeed at all five simultaneously, and failing any single one ends the attempt. That's a fundamentally different kind of hard than "climb a slightly taller fence." It's also why the depth score in this skill counts categories, not raw control count, three guards covering the same job as one guard adds cost without closing a single new gap.

A myth worth busting before we start: "More guards means more security", Redundant personnel in the same role add cost without closing new gaps; the benefit comes from covering additional categories, not duplicating existing ones.
