1. Brief

The situation. In physical security auditing, we look at the combination of active controls to identify vulnerabilities or gaps in a layered defense. You are tasked with implementing a function that takes a description of a facility's physical security inventory and returns all identified security gaps based on audit rules.

Implement solve(data: dict[str, bool]) -> list[str] in the code editor.

Lesson objective. Identify the purpose of each physical access control layer, locks, badge readers, biometrics, and mantraps, explain how they combine into a defense-in-depth strategy, and pinpoint gaps when one or more controls are absent.

What comes in

A dictionary containing the following keys (each mapping to a boolean representing presence of that control): - keyed_lock - badge_reader - biometric_reader - mantrap - cctv - security_guard

Example:

{
    "keyed_lock": True,
    "badge_reader": True,
    "biometric_reader": False,
    "mantrap": False,
    "cctv": True,
    "security_guard": False
}

What must come out

A list of strings representing the detected security gaps, sorted alphabetically: - no_key_control: triggered if both keyed_lock and badge_reader are absent. - no_electronic_access: triggered if both badge_reader and biometric_reader are absent. - no_tailgating_prevention: triggered if mantrap is absent. - no_visual_monitoring: triggered if cctv is absent. - no_identity_verification: triggered if both security_guard and biometric_reader are absent.

Entry point

def solve(data: dict[str, bool]) -> list[str]

Input (data)

A dictionary mapping physical access control elements to boolean values indicating their presence (True if present, False if absent): - keyed_lock: bool - badge_reader: bool - biometric_reader: bool - mantrap: bool - cctv: bool - security_guard: bool

Output (result)

A sorted list of string identifiers representing the security gaps discovered in the facility: - no_key_control - no_electronic_access - no_tailgating_prevention - no_visual_monitoring - no_identity_verification

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only.
  • The rules for gaps are:
  • If keyed_lock is False AND badge_reader is False: gap "no_key_control"
  • If badge_reader is False AND biometric_reader is False: gap "no_electronic_access"
  • If mantrap is False: gap "no_tailgating_prevention"
  • If cctv is False: gap "no_visual_monitoring"
  • If security_guard is False AND biometric_reader is False: gap "no_identity_verification"
  • The resulting list of gaps must be sorted alphabetically.

Acceptance

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
def solve(data: dict[str, bool]) -> list[str]: gaps = [] if not data.get("keyed_lock", False) and not data.get("badge_reader", False): gaps.append("no_key_control") if not data.get("badge_reader", False) and not data.get("biometric_reader", False): gaps.append("no_electronic_access") if not data.get("mantrap", False): gaps.append("no_tailgating_prevention") if not data.get("cctv", False): gaps.append("no_visual_monitoring") if not data.get("security_guard", False) and not data.get("biometric_reader", False): gaps.append("no_identity_verification") return sorted(gaps)
