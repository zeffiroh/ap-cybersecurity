Coding problem, 2.3.d: Facility control-compliance checker

Skill: Mitigate Risk · Maps to: 2.3.C · Language: Python 3 (pytest)

Problem

You are auditing environmental controls across a facility's zones (rooms) for Crestfield Analytics. Each zone has a room type and a set of installed controls (UPS presence, HVAC redundancy level, fire suppression type, and floor-level leak sensor presence). The facility's control policy specifies, per room type, the minimum controls required. Given a list of zones and the policy, identify every zone that is non-compliant, missing one or more controls required for its room type.

This mirrors real facility audits: a server room without a UPS or with water-sprinkler suppression is a serious finding, while a general office is held to a much lighter standard.

Function contract

Implement solve(zones, policy) in the code editor (see the Reference section below).

Input

  • zones: list[dict], each dict has:
  • "name": str, zone identifier, e.g. "server-room-a"
  • "room_type": str, key into policy, e.g. "server", "closet", "office"
  • "has_ups": bool
  • "hvac_redundancy": int, number of extra HVAC units beyond the minimum needed (0 means no redundancy, a single unit)
  • "suppression": str, one of "water", "clean_agent", "none"
  • "has_leak_sensor": bool
  • policy: dict[str, dict], maps a room_type string to a requirements dict, which may contain any subset of these keys (a missing key means that control is not required for that room type):
  • "require_ups": bool, if True, zone must have has_ups == True
  • "min_hvac_redundancy": int, zone's hvac_redundancy must be >= this value
  • "allowed_suppression": list[str], zone's suppression must be in this list
  • "require_leak_sensor": bool, if True, zone must have has_leak_sensor == True
  • A zone whose room_type is not a key in policy has no requirements and is always compliant.

Output

A sorted list of unique zone name strings that fail at least one applicable requirement. Empty list if every zone is compliant.

Examples

policy = {
    "server": {
        "require_ups": True,
        "min_hvac_redundancy": 1,
        "allowed_suppression": ["clean_agent"],
        "require_leak_sensor": True,
    },
    "office": {
        "allowed_suppression": ["water", "clean_agent"],
    },
}

zones = [
    {"name": "server-room-a", "room_type": "server", "has_ups": True,
     "hvac_redundancy": 1, "suppression": "clean_agent", "has_leak_sensor": True},
    {"name": "server-room-b", "room_type": "server", "has_ups": False,
     "hvac_redundancy": 1, "suppression": "clean_agent", "has_leak_sensor": True},
    {"name": "office-1", "room_type": "office", "has_ups": False,
     "hvac_redundancy": 0, "suppression": "water", "has_leak_sensor": False},
]

solve(zones, policy)  ->  ["server-room-b"]
# server-room-a meets every requirement for "server".
# server-room-b fails require_ups (has_ups is False).
# office-1 has no UPS/HVAC/leak-sensor requirements for "office", and water is an allowed
#   suppression type for office, so it is compliant.

Constraints

  • Deterministic, offline, standard library only.
  • A room type not present in policy has no requirements (always compliant).
  • A zone is non-compliant if it fails ANY applicable requirement key present in its room type's policy entry.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(zones: list[dict], policy: dict) -> list[str]

Input (zones)

list[dict] where each dict has: - "name": str, zone identifier - "room_type": str, key into policy - "has_ups": bool - "hvac_redundancy": int, count of extra HVAC units beyond the single minimum (0 = no redundancy) - "suppression": str, one of "water", "clean_agent", "none" - "has_leak_sensor": bool

Input (policy)

dict[str, dict] mapping room_type -> a requirements dict with any subset of: - "require_ups": bool - "min_hvac_redundancy": int - "allowed_suppression": list[str] - "require_leak_sensor": bool

A room type absent from policy has no requirements. A requirement key absent from a room type's entry is not enforced for that room type.

Output (result)

A sorted, de-duplicated list[str] of zone name strings that fail one or more applicable requirements. Empty list if every zone is compliant.

Compliance rules

  • require_ups: True -> zone fails if has_ups is not True.
  • min_hvac_redundancy: N -> zone fails if hvac_redundancy < N.
  • allowed_suppression: [...] -> zone fails if suppression is not in the list.
  • require_leak_sensor: True -> zone fails if has_leak_sensor is not True.
  • A zone fails (is non-compliant) if it fails ANY one applicable rule.
  • A zone whose room_type has no entry in policy is always compliant.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Zones may be given in any order.
  • Output always sorted ascending and de-duplicated.

# Reference solution """Reference solution for 2.3.d. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List, Dict, Any def solve(zones: List[Dict[str, Any]], policy: Dict[str, Dict[str, Any]]) -> List[str]: """Return sorted list of zone names that are non-compliant with their room type's policy. A zone is non-compliant if it fails any applicable requirement key present in the policy entry for its room_type: - require_ups (bool): zone.has_ups must be True - min_hvac_redundancy (int): zone.hvac_redundancy must be >= this value - allowed_suppression (list[str]): zone.suppression must be in this list - require_leak_sensor (bool): zone.has_leak_sensor must be True A room_type absent from policy has no requirements (always compliant). """ non_compliant = set() for zone in zones: rules = policy.get(zone["room_type"]) if not rules: continue if rules.get("require_ups") and not zone.get("has_ups", False): non_compliant.add(zone["name"]) continue min_hvac = rules.get("min_hvac_redundancy") if min_hvac is not None and zone.get("hvac_redundancy", 0) < min_hvac: non_compliant.add(zone["name"]) continue allowed = rules.get("allowed_suppression") if allowed is not None and zone.get("suppression", "none") not in allowed: non_compliant.add(zone["name"]) continue if rules.get("require_leak_sensor") and not zone.get("has_leak_sensor", False): non_compliant.add(zone["name"]) continue return sorted(non_compliant)
