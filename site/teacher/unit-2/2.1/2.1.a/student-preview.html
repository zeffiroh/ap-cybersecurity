CIA triad: confidentiality, integrity, availability

Coding problem, 2.1.a: CIA Triad Classifier

Skill: Analyze Risk · Maps to: 2.1.A · Language: Python 3 (pytest)

Problem

In cybersecurity, classifying incidents according to the CIA triad helps organizations prioritize response and apply correct controls. You are tasked with implementing a rule-based classifier that scans incident descriptions for keywords indicating violations of Confidentiality, Integrity, or Availability.

Implement solve(data) in the code editor (see the Reference section below).

Input

A list of dictionaries containing "id" and "description" of the security incidents:

[
    {"id": "INC-01", "description": "Attacker intercepted the unencrypted credentials."},
    {"id": "INC-02", "description": "A script corrupted the production database records."}
]

Output

A dictionary mapping each incident ID to a sorted list of violated pillars:

{
    "INC-01": ["Confidentiality"],
    "INC-02": ["Integrity"]
}

Rules

A pillar is violated if the incident's description contains (case-insensitively) any of these keywords: - Confidentiality: leak, expose, disclose, intercept, steal, stole, read, password, credential - Integrity: modify, alter, change, corrupt, tamper, edit, forge, spoof - Availability: down, offline, unavailable, flood, crash, lock, ransomware, denial

The output list of pillars for each incident ID must be sorted alphabetically.

def solve(data: list) -> dict:

Input (data)

A list of dictionaries, where each dictionary represents a security incident report:

[
    {"id": "INC-01", "description": "The customer database was leaked online."},
    {"id": "INC-02", "description": "A DDoS attack took the server down."}
]

Output (result)

A dictionary mapping each incident ID to a sorted list of violated CIA pillars ("Confidentiality", "Integrity", "Availability"):

{
    "INC-01": ["Confidentiality"],
    "INC-02": ["Availability"]
}

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only.
  • An incident description violates a pillar if it contains any of the following substring keywords (case-insensitive):
  • Confidentiality: "leak", "expose", "disclose", "intercept", "steal", "stole", "read", "password", "credential"
  • Integrity: "modify", "alter", "change", "corrupt", "tamper", "edit", "forge", "spoof"
  • Availability: "down", "offline", "unavailable", "flood", "crash", "lock", "ransomware", "denial"
  • If no keywords match, the list of pillars for that incident is empty [].
  • The list of pillars for each incident ID must be sorted alphabetically (e.g. ["Availability", "Confidentiality"]).
