Coding problem, 2.4.c: Motion-sensor event classifier

Skill: Detect Attacks · Maps to: 2.4.B, 2.4.C · Language: Python 3 (pytest)

Problem

You are building the automated triage logic for a facility's motion-sensor monitoring system at Crestfield Analytics. Given a list of motion-sensor trigger events, classify each one as a TRUE_DETECTION (a real person likely caused it) or a FALSE_POSITIVE (a known nuisance cause, sunlight, HVAC airflow, a pet, an insect, vibration, or foliage, likely caused it), and return the IDs of the events that are true detections.

Single-technology sensors (pir, microwave, ultrasonic) report one cause tag. A dual-technology sensor reports two independent cause tags, one from its PIR element, one from its microwave element, and only counts as a true detection when both elements agree the cause is genuine (AND-logic). This mirrors the lesson: a dual-tech sensor exists specifically to suppress the false-positive causes that fool a single technology, so if either element's cause is a known false-positive cause, the whole event is a false positive.

Function contract

Implement solve(events, false_positive_causes) in the code editor (see the Reference section below).

Input

  • events: list[dict], each dict has:
  • "id": str, event identifier, e.g. "EVT-001"
  • "sensor_type": str, "pir", "microwave", "ultrasonic", or "dual-tech"
  • single-tech events also have "cause": str
  • dual-tech events instead have "cause_pir": str and "cause_mw": str
  • false_positive_causes: set[str], known false-positive cause tags, e.g. {"sunlight", "hvac_airflow", "pet", "insect", "vibration", "foliage"}

Output

A sorted list of unique event ID strings that classify as TRUE_DETECTION. Empty list if none.

Examples

events = [
    {"id": "EVT-001", "sensor_type": "pir", "cause": "person"},
    {"id": "EVT-002", "sensor_type": "pir", "cause": "sunlight"},
]
fp = {"sunlight", "hvac_airflow", "pet", "insect", "vibration", "foliage"}
solve(events, fp)  ->  ["EVT-001"]

    {"id": "EVT-011", "sensor_type": "dual-tech", "cause_pir": "hvac_airflow", "cause_mw": "person"},
]
solve(events2, fp)  ->  ["EVT-010"]

Entry point

def solve(events: list[dict], false_positive_causes: set[str]) -> list[str]

Input (events)

list[dict] where each dict represents one motion-sensor trigger event and has: - "id": str, unique event identifier string - "sensor_type": str, one of "pir", "microwave", "ultrasonic", "dual-tech" - For sensor_type in {"pir", "microwave", "ultrasonic"} (single-technology sensors): - "cause": str, the tag describing what triggered the sensor (e.g. "person", "sunlight", "hvac_airflow", "pet", "insect", "vibration", "foliage") - For sensor_type == "dual-tech": - "cause_pir": str, the cause tag reported by the PIR element - "cause_mw": str, the cause tag reported by the microwave element

Input (false_positive_causes)

set[str], the set of cause tags that are known false-positive causes (e.g. {"sunlight", "hvac_airflow", "pet", "insect", "vibration", "foliage"}). Any cause tag NOT in this set is treated as a genuine, person-consistent cause.

Output (result)

A sorted, de-duplicated list[str] of event IDs that classify as TRUE_DETECTION. Events that classify as FALSE_POSITIVE are simply omitted from the result. Empty list if none.

Classification rules

  • Single-technology sensor (pir, microwave, or ultrasonic): the event is a TRUE_DETECTION if and only if "cause" is NOT in false_positive_causes.
  • Dual-technology sensor (dual-tech): AND-logic. The event is a TRUE_DETECTION if and only if BOTH "cause_pir" and "cause_mw" are NOT in false_positive_causes. If either element's cause is a known false-positive cause, the whole event is a FALSE_POSITIVE, even if the other element's cause is genuine.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Every event dict has a well-formed "id" and "sensor_type" plus the cause field(s) required for that sensor type, per the input spec above.
  • Event IDs are unique within a single call.
  • Output is always sorted ascending and de-duplicated.

# Reference solution """Reference solution for 2.4.c. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import Dict, List, Set def solve(events: List[Dict], false_positive_causes: Set[str]) -> List[str]: """Return sorted list of event IDs that classify as TRUE_DETECTION. Single-technology sensors (pir, microwave, ultrasonic): TRUE_DETECTION iff "cause" is NOT in false_positive_causes. Dual-technology sensors (dual-tech): AND-logic. TRUE_DETECTION iff BOTH "cause_pir" and "cause_mw" are NOT in false_positive_causes. Either element reporting a known false-positive cause makes the whole event a FALSE_POSITIVE. """ true_detections = [] for e in events: sensor_type = e["sensor_type"] if sensor_type == "dual-tech": pir_ok = e["cause_pir"] not in false_positive_causes mw_ok = e["cause_mw"] not in false_positive_causes is_true = pir_ok and mw_ok else: is_true = e["cause"] not in false_positive_causes if is_true: true_detections.append(e["id"]) return sorted(set(true_detections))
