Coding problem, 2.4.b: Alarm event classifier

Skill: Detect Attacks · Maps to: 2.4.B · Language: Python 3 (pytest)

Problem

You are building the triage logic for an alarm control panel at Crestfield Analytics. Given a timestamp-ordered stream of sensor events (one per zone trip), classify each event using the arm-state, exit-delay, and cross-zone verification rules taught in the lesson:

  • SUPPRESSED, the system was "DISARMED" when the event occurred (does not apply to panic buttons, see below).
  • FALSE_ALARM, the event's sensor is "contact" or "glass_break", the system was armed, and the event happened less than exit_delay_sec seconds after the zone was armed (still inside the exit-delay grace period).
  • LOCAL_ONLY, a real trip (armed, past the exit delay) that has no corroborating trip in a different zone within verify_window_sec seconds. Only the local siren sounds.
  • DISPATCH, either (a) the sensor is "panic" (a panic/duress button always dispatches, regardless of arm state or timing), or (b) a real trip that has a corroborating real trip in a different zone within verify_window_sec seconds (cross-zone verification).

Function contract

Implement solve(events, exit_delay_sec=45, verify_window_sec=120) in the code editor (see the Reference section below).

Input

  • events: list[dict], each with:
  • "ts": int, Unix timestamp (seconds) the event occurred
  • "zone": str, zone/door identifier, e.g. "front-door"
  • "sensor": str, one of "contact", "glass_break", "panic"
  • "arm_state": str, one of "DISARMED", "ARMED_AWAY", "ARMED_STAY"
  • "since_armed_sec": int, seconds elapsed between arming and this event (ignored for "panic" and when arm_state == "DISARMED")
  • exit_delay_sec: int, default 45, grace period after arming.
  • verify_window_sec: int, default 120, max gap (in ts) between two different-zone real trips for cross-zone verification to apply.

Output

A list[str] of classifications, one per input event, in the same order as the input. Each entry is one of "SUPPRESSED", "FALSE_ALARM", "LOCAL_ONLY", "DISPATCH".

Examples

events = [
    {"ts": 1000, "zone": "front-door", "sensor": "contact",

]
solve(events)  ->  ["FALSE_ALARM"]

events2 = [
    {"ts": 1000, "zone": "z1", "sensor": "panic",
     "arm_state": "DISARMED", "since_armed_sec": 0},
]
solve(events2)  ->  ["DISPATCH"]

    {"ts": 1000, "zone": "z1", "sensor": "contact",
     "arm_state": "ARMED_AWAY", "since_armed_sec": 300},
    {"ts": 1050, "zone": "z2", "sensor": "glass_break",
     "arm_state": "ARMED_AWAY", "since_armed_sec": 305},
]
solve(events3)  ->  ["DISPATCH", "DISPATCH"]

Constraints

  • Deterministic, offline, standard library only.
  • Events may be given in any timestamp order in the list; the output order must match the input order (do not re-sort the output).
  • Cross-zone verification: two real trips (armed, past exit delay) in different zones with abs(ts_a - ts_b) <= verify_window_sec corroborate each other. A real trip may be corroborated by more than one other zone; any single qualifying pair is enough to promote it to DISPATCH. Same-zone repeats never corroborate each other.
  • since_armed_sec >= exit_delay_sec counts as past the exit delay (boundary is inclusive on the "past delay" side, i.e. exactly exit_delay_sec is a real trip, not a false alarm).
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(events: list[dict], exit_delay_sec: int = 45, verify_window_sec: int = 120) -> list[str]

Input (events)

list[dict] where each dict has: - "ts": int, Unix timestamp in seconds - "zone": str, zone/door identifier - "sensor": str, one of "contact", "glass_break", "panic" - "arm_state": str, one of "DISARMED", "ARMED_AWAY", "ARMED_STAY" - "since_armed_sec": int, seconds since the zone was armed when this event occurred (only meaningful when arm_state != "DISARMED" and sensor != "panic")

Input (other parameters)

  • exit_delay_sec: int, default 45, an armed contact/glass_break trip with since_armed_sec < exit_delay_sec is a false alarm.
  • verify_window_sec: int, default 120, max ts gap between two different-zone real trips for cross-zone verification.

Output (result)

A list[str] the same length as events, in the same order as the input, where each element is one of "SUPPRESSED", "FALSE_ALARM", "LOCAL_ONLY", "DISPATCH".

Classification rules

  1. Panic override: if sensor == "panic", classification is always "DISPATCH", regardless of arm_state or since_armed_sec.
  2. Suppressed: else if arm_state == "DISARMED", classification is "SUPPRESSED".
  3. False alarm: else if since_armed_sec < exit_delay_sec, classification is "FALSE_ALARM".
  4. Real trip, verification: otherwise the event is a "real trip" candidate. A real trip is promoted to "DISPATCH" if there exists at least one other real-trip event (per rules 1-4, excluding panic events) in a different zone with abs(ts_i - ts_j) <= verify_window_sec. Otherwise it is "LOCAL_ONLY".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Output order matches input order exactly (do not sort by timestamp for output).
  • Same-zone events never corroborate each other for cross-zone verification.

Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List, Dict def solve(events: List[Dict], exit_delay_sec: int = 45, verify_window_sec: int = 120) -> List[str]: """Classify each alarm event as SUPPRESSED, FALSE_ALARM, LOCAL_ONLY, or DISPATCH. Rules (see the Reference section below): 1. sensor == "panic" -> DISPATCH (always, overrides everything else) 2. arm_state == "DISARMED" -> SUPPRESSED 3. since_armed_sec < exit_delay_sec -> FALSE_ALARM 4. otherwise a "real trip": DISPATCH if another real trip in a DIFFERENT zone occurs within verify_window_sec seconds, else LOCAL_ONLY. """ n = len(events) base = [None] * n # per-index: "PANIC", "SUPPRESSED", "FALSE_ALARM", or "REAL" for i, e in enumerate(events): if e["sensor"] == "panic": base[i] = "PANIC" elif e["arm_state"] == "DISARMED": base[i] = "SUPPRESSED" elif e["since_armed_sec"] < exit_delay_sec: base[i] = "FALSE_ALARM" else: base[i] = "REAL" real_indices = [i for i in range(n) if base[i] == "REAL"] result = [""] * n for i, e in enumerate(events): if base[i] == "PANIC": result[i] = "DISPATCH" elif base[i] == "SUPPRESSED": result[i] = "SUPPRESSED" elif base[i] == "FALSE_ALARM": result[i] = "FALSE_ALARM" else: corroborated = False for j in real_indices: if j == i: continue if events[j]["zone"] == e["zone"]: continue if abs(events[j]["ts"] - e["ts"]) <= verify_window_sec: corroborated = True break result[i] = "DISPATCH" if corroborated else "LOCAL_ONLY" return result
