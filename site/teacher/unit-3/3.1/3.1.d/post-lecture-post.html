Packet capture and traffic sniffing

Unit 3 · Securing Networks · 3.1 Network-Level Exploits

Nice work today. Here's what to lock in:

  • Recap handout: post-lecture-handout.docx
  • Simulation: SimLab
  • Self-check quiz: due before next class

The big picture: This skill is the payoff for everything Unit 3 has built up to this point: ARP spoofing (3.1.c) earns an attacker the position to sniff traffic that a switch would otherwise keep hidden from them, and this skill shows you what that position is actually worth, cleartext credentials on HTTP, Telnet, and FTP sitting there in plain readable bytes, versus HTTPS and SSH traffic that shows up as unreadable binary even to an attacker sitting directly in the traffic's path. That's the cleanest demonstration in the whole unit of a principle worth generalizing: you often cannot stop an attacker from reaching a position to listen, so the real defense is making sure whatever they hear is useless to them. Keep the capture-filter-versus-display-filter distinction straight for the exam too, a capture filter decides what's ever recorded, a display filter only decides what you're currently looking at within what was already recorded, and that's an irreversible-versus-reversible distinction the exam likes to probe.

Key terms to lock in:

  • Packet capture (sniffing): intercepting and logging network traffic passing a network interface.
  • Promiscuous mode: a NIC setting that accepts all frames it physically receives, not just those addressed to its own MAC.
  • Port mirroring / SPAN port: a switch feature that copies traffic from one or more ports to a monitoring port for legitimate analysis (or, if misused, for eavesdropping).
  • Capture filter: a filter applied before capture that determines which packets are recorded at all.
  • Display filter: a filter applied after capture to narrow which already-captured packets are shown.
  • Cleartext protocol: a protocol (HTTP, Telnet, FTP, unencrypted SMTP/POP3/IMAP) that sends payload data, including credentials, without encryption.

Common misconceptions to watch for:

  • "You need to be an attacker to use Wireshark." → Packet capture is a standard, legitimate network-troubleshooting and security-monitoring tool; it becomes an attack only through unauthorized access or misuse of legitimate positioning (e.g. a misconfigured SPAN port granted to the wrong party).
  • "A switched network makes sniffing impossible." → A switch limits sniffing compared to a hub, but ARP spoofing, port mirroring misuse, and compromised network taps all still allow an attacker to see traffic they should not on a fully switched network.

Learning objective(s): 3.1.B, 3.1.C
