Coding problem, 3.1.b: DNS resolver race classifier

Skill: Analyze Risk, Detect Attacks · Maps to: 3.1.A, 3.1.B · Language: Python 3 (pytest)

Problem

You are building triage logic for a resolver reply log at Crestfield Analytics. For each outstanding query, the log records the replies that arrived, and, for each reply, who sent it ("authoritative" or "attacker"), and the tx_id, port, and qname it carried. Classify each query's outcome:

  • "REJECT", no reply is a valid candidate (none match the query's tx_id, port, AND qname all three), so nothing is cached. This also covers the case of zero replies.
  • "WIN", among the valid candidates (replies matching all three fields), the one with the smallest arrival number (i.e. the first to arrive) has "from": "authoritative".
  • "POISON", among the valid candidates, the first-arriving one has "from": "attacker".

Function contract

Implement solve(queries) in the code editor (see the Reference section below).

Input

  • queries: list[dict], each with:
  • "qname": str, the domain name queried
  • "tx_id": int, the transaction ID the resolver sent
  • "port": int, the source port the resolver sent the query from
  • "replies": list[dict], each with "from" ("authoritative" or "attacker"), "tx_id" (int), "port" (int), "qname" (str), "arrival" (int, lower = earlier)

Output

A list[str] of classifications, one per input query, in the same order as the input. Each entry is one of "WIN", "POISON", "REJECT".

Examples

Constraints

  • Deterministic, offline, standard library only.
  • A reply is a "valid candidate" only if reply["tx_id"] == query["tx_id"] AND reply["port"] == query["port"] AND reply["qname"] == query["qname"].
  • Among valid candidates, only the one with the minimum arrival value matters (test data never has ties on the minimum arrival).
  • Replies may be given in any order in the list; use the arrival field, not list position, to determine which arrived first.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(queries: list[dict]) -> list[str]

Input (queries)

list[dict] where each dict has: - "qname": str, domain name queried - "tx_id": int, transaction ID the resolver sent - "port": int, source port the resolver sent the query from - "replies": list[dict], each with: - "from": str, "authoritative" or "attacker" - "tx_id": int - "port": int - "qname": str - "arrival": int, arrival order, lower arrives earlier

Output (result)

A list[str] the same length as queries, in the same order as the input, where each element is one of "WIN", "POISON", "REJECT".

Classification rules

  1. A reply is a valid candidate iff its tx_id, port, and qname all equal the query's tx_id, port, and qname.
  2. If there are no valid candidates (including an empty replies list), the result is "REJECT".
  3. Otherwise, take the valid candidate with the smallest arrival value (the first to arrive). If its "from" is "authoritative", the result is "WIN"; if "attacker", the result is "POISON".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Output order matches input order exactly.
  • Test data never has two valid candidates with an identical arrival value.

# Reference solution """Reference solution for 3.1.b. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List, Dict def solve(queries: List[Dict]) -> List[str]: """Classify each DNS query's resolver race outcome as WIN, POISON, or REJECT. Rules (see the Reference section below): 1. A reply is a "valid candidate" iff tx_id, port, and qname all match the query. 2. No valid candidates -> REJECT. 3. Otherwise the valid candidate with the smallest 'arrival' wins the race: from == "authoritative" -> WIN, from == "attacker" -> POISON. """ result = [] for q in queries: candidates = [ r for r in q["replies"] if r["tx_id"] == q["tx_id"] and r["port"] == q["port"] and r["qname"] == q["qname"] ] if not candidates: result.append("REJECT") continue winner = min(candidates, key=lambda r: r["arrival"]) result.append("WIN" if winner["from"] == "authoritative" else "POISON") return result
