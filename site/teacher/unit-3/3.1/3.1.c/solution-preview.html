1. Brief

The situation. You are building an arpwatch-style detector for Crestfield Analytics. Given a timestamp-ordered log of observed ARP replies (each mapping an IP to a MAC), identify which IP addresses show the ARP spoofing signature: the first reply seen for an IP establishes its trusted MAC binding. Any later reply for the same IP with a different MAC is a spoofing indicator. A later reply with the same MAC as the trusted binding is just a normal refresh and is not flagged.

Lesson objective. Explain how the Address Resolution Protocol (ARP) can be abused to insert an attacker between two hosts on a local network, trace the mechanics of an ARP spoofing attack step by step, and identify the technical controls that detect or prevent it.

What comes in

  • replies: list[dict], each with:
  • "ts": int, Unix timestamp (seconds) the reply was observed
  • "ip": str, the IP address claimed in the reply
  • "mac": str, the MAC address claimed for that IP

What must come out

A list[str], the distinct IP addresses that show the spoofing signature (at least one reply with a MAC different from that IP's first-seen MAC), sorted alphabetically, with no duplicates.

Entry point

def solve(replies: list[dict]) -> list[str]

Input (replies)

list[dict] where each dict has: - "ts": int, Unix timestamp in seconds the reply was observed - "ip": str, IP address claimed in the reply - "mac": str, MAC address claimed for that IP

Output (result)

A list[str] of distinct IP addresses that show the ARP spoofing signature, sorted alphabetically, with no duplicate entries.

Detection rule

  1. For each IP, find the reply with the smallest ts, this establishes the trusted MAC binding for that IP.
  2. If any other reply for that same IP has a mac different from the trusted binding, the IP is flagged (spoofed).
  3. IPs with only one observed reply, or where every reply agrees on the same MAC, are not flagged.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • replies may arrive in any order; use ts (not list position) to determine the trusted (first) binding.
  • Test data never has two replies for the same IP with a tied minimum ts.
  • Output is sorted alphabetically with no duplicates.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

This is the model solution.

  • [ ] solve handles the worked examples

from typing import List, Dict def solve(replies: List[Dict]) -> List[str]: by_ip = {} for r in replies: by_ip.setdefault(r["ip"], []).append(r) flagged = set() for ip, rs in by_ip.items(): trusted = min(rs, key=lambda r: r["ts"]) for r in rs: if r["mac"] != trusted["mac"]: flagged.add(ip) break return sorted(flagged)
