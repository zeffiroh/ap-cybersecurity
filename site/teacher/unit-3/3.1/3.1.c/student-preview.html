Man-in-the-middle and ARP spoofing

Coding problem, 3.1.c: ARP spoofing detector

Skill: Analyze Risk · Maps to: 3.1.B · Language: Python 3 (pytest)

Problem

You are building an arpwatch-style detector for Crestfield Analytics. Given a timestamp-ordered log of observed ARP replies (each mapping an IP to a MAC), identify which IP addresses show the ARP spoofing signature: the first reply seen for an IP establishes its trusted MAC binding. Any later reply for the same IP with a different MAC is a spoofing indicator. A later reply with the same MAC as the trusted binding is just a normal refresh and is not flagged.

Function contract

Implement solve(replies) in the code editor (see the Reference section below).

Input

  • replies: list[dict], each with:
  • "ts": int, Unix timestamp (seconds) the reply was observed
  • "ip": str, the IP address claimed in the reply
  • "mac": str, the MAC address claimed for that IP

Output

A list[str], the distinct IP addresses that show the spoofing signature (at least one reply with a MAC different from that IP's first-seen MAC), sorted alphabetically, with no duplicates.

Examples

replies = [
    {"ts": 100, "ip": "192.168.1.1", "mac": "aa:11:22:33:44:01"},
    {"ts": 130, "ip": "192.168.1.1", "mac": "aa:11:22:33:44:01"},
    {"ts": 145, "ip": "192.168.1.1", "mac": "de:ad:be:ef:00:99"},
]
solve(replies)  ->  ["192.168.1.1"]

replies2 = [
    {"ts": 100, "ip": "192.168.1.50", "mac": "11:22:33:44:55:66"},
]
solve(replies2)  ->  []

Constraints

  • Deterministic, offline, standard library only.
  • replies may be given in any timestamp order in the list; use the ts field (not list position) to determine which reply for a given IP came first (the "trusted" binding).
  • Test data never has two replies for the same IP with an identical minimum ts.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(replies: list[dict]) -> list[str]

Input (replies)

list[dict] where each dict has: - "ts": int, Unix timestamp in seconds the reply was observed - "ip": str, IP address claimed in the reply - "mac": str, MAC address claimed for that IP

Output (result)

A list[str] of distinct IP addresses that show the ARP spoofing signature, sorted alphabetically, with no duplicate entries.

Detection rule

  1. For each IP, find the reply with the smallest ts, this establishes the trusted MAC binding for that IP.
  2. If any other reply for that same IP has a mac different from the trusted binding, the IP is flagged (spoofed).
  3. IPs with only one observed reply, or where every reply agrees on the same MAC, are not flagged.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • replies may arrive in any order; use ts (not list position) to determine the trusted (first) binding.
  • Test data never has two replies for the same IP with a tied minimum ts.
  • Output is sorted alphabetically with no duplicates.
