1. Brief

The situation. A network monitoring tool has captured a log of IP packets on a corporate subnet. Each log entry records the packet's source IP, destination IP, and an expected source subnet (CIDR notation). Your job is to implement a spoofing detector: given a list of packet records, return the zero-based indices of packets whose source IP address falls outside the expected source subnet, which is a strong indicator of IP spoofing.

A packet is considered suspicious (spoofed) when src_ip does not belong to expected_subnet. Only IPv4 addresses are present. Subnets are given as "A.B.C.D/N" CIDR strings.

Lesson objective. Describe how the TCP/IP protocol stack works, identify structural weaknesses in common network topologies, and explain how those weaknesses create attack surfaces that adversaries exploit.

What comes in

A list of dicts. Each dict has three string keys: - "src_ip": e.g. "10.0.1.55" - "dst_ip": e.g. "10.0.1.1" - "expected_subnet": e.g. "10.0.1.0/24"

What must come out

A sorted list of zero-based integer indices of the suspicious (spoofed) packets. Empty list if none are suspicious.
