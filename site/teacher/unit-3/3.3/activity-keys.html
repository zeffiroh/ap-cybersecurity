Skill 3.3.a

VLANs and network segmentation

Instructor notes

  • Expected placement: MGMT-01 in Management; WS-01, WS-02, PRT-01 in Employee; SRV-01, SRV-02 in Server; CAM-01, GUEST-01 in Guest/IoT.
  • Common stumble: students place PRT-01 in the Server VLAN. Printers belong with employees, not servers. Printers on the server VLAN create a pivot path into server resources.
  • Another stumble: placing CAM-01 on the Employee VLAN because "cameras watch employees." Cameras belong in the IoT VLAN; their firmware is notoriously unpatched and should never share a broadcast domain with workstations.
  • This activity feeds the unit project (network hardening design) and scenario stage 3 (containing lateral movement after initial breach).
Skill 3.3.b

Traffic isolation and zero-trust segmentation

Instructor notes

  • PVLAN Design Solution:
  • Promiscuous: Default Gateway (192.168.1.1).
  • Isolated: Guest Wi-Fi AP, Waiting Room Check-in Tablets, MRI Imaging Machine. (This prevents guest devices or compromised tablets from scanning/reaching each other or the MRI machine).
  • Community: Doctor Workstations (can be placed in a community so they can collaborate or share local resources like a shared printer if needed, or they can also be isolated if zero trust is fully enforced).
  • Zero Trust Proxy Policy Solution:
  • Must authenticate user identity (MFA).
  • Must verify device posture (e.g., antivirus is active, OS is patched).
  • Must authorize the request (only allow access during clinic hours and block access if requests occur from external/unusual IPs).
