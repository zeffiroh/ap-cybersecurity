Unit 3 · Securing Networks · 3.3 Network Segmentation

Before class today. Traditional network security relies on a "perimeter" model, often compared to a castle with a moat. Under this design, the organization builds strong defenses at the network perimeter (using firewalls and intrusion prevention systems) to keep attackers out.

The intuition to hold onto: Before this lecture, sit with the uncomfortable fact this skill opens with: a VLAN-segmented network still runs on implicit trust, once you're inside a zone, or inside the perimeter at all, older security models simply assume you belong there. Zero Trust's whole premise is refusing that assumption entirely, treating a device on the corporate Wi-Fi with exactly as much suspicion as a device on the open internet, because getting in has never actually meant you should be trusted with everything inside.

A myth worth busting before we start: "Zero Trust means we don't trust our employees." → Zero Trust is a technical posture, not a human resource policy. It protects employees' credentials from being abused by automating checks and preventing compromised devices from spreading malware.
