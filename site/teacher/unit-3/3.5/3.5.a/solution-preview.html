Coding problem, 3.5.a: IDS signature matcher

Skill: Detect Attacks · Maps to: 3.5.A · Language: Python 3 (pytest)

Problem

You are implementing the rule-matching core of a simple IDS. The sensor receives a stream of packet-log entries. Each entry is a dict with the fields shown below. You are given a list of signature rules; each rule has a destination port and a keyword that must appear (case-insensitive) in the payload. A log entry matches a rule when BOTH the port AND the keyword condition are met.

Return the sorted list of id values for every log entry that matches at least one rule.

Function contract

Implement solve(logs: list[dict], rules: list[dict]) -> list[str] in the code editor (see the Reference section below).

Input

  • logs: list of dicts, each with keys:
  • "id" (str), unique entry identifier, e.g. "pkt-001"
  • "dst_port" (int), destination port of the packet
  • "payload" (str), packet payload (may be empty)
  • rules: list of dicts, each with keys:
  • "port" (int), destination port to match
  • "keyword" (str), substring to find (case-insensitive) in the payload

Output

A sorted list[str] of id values for entries that match at least one rule. Empty list if no entries match.

Examples

logs = [
    {"id": "pkt-001", "dst_port": 80,  "payload": "GET /admin/../etc/passwd HTTP/1.1"},
    {"id": "pkt-002", "dst_port": 443, "payload": "TLS handshake"},
    {"id": "pkt-003", "dst_port": 80,  "payload": "GET /index.html HTTP/1.1"},
    {"id": "pkt-004", "dst_port": 22,  "payload": "SSH-2.0-OpenSSH_8.9"},
]
rules = [
    {"port": 80, "keyword": "etc/passwd"},
    {"port": 22, "keyword": "libssh"},
]
solve(logs, rules)  ->  ["pkt-001"]

logs = []
solve(logs, rules)  ->  []

Constraints

  • Deterministic, offline, standard library only.
  • Keyword matching is case-insensitive substring match.
  • A log entry that matches multiple rules is included only once in the output.
  • Output is sorted ascending by id.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(logs: list[dict], rules: list[dict]) -> list[str]

Input (logs, rules)

  • logs: list of dicts with keys:
  • "id" (str), unique packet/log entry identifier
  • "dst_port" (int), destination port
  • "payload" (str), packet payload text
  • rules: list of dicts with keys:
  • "port" (int), destination port to match
  • "keyword" (str), substring to search for in payload

Output (result)

A sorted list[str] of id values for log entries that match at least one rule. Empty list if no entries match.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Keyword matching is case-insensitive (keyword.lower() in payload.lower()).
  • An entry matching multiple rules appears only once (de-duplicated).
  • Output is sorted ascending by id string value.
  • A log entry matches a rule when its dst_port == rule["port"] AND rule["keyword"].lower() is a substring of entry["payload"].lower().

Acceptance

# Reference solution """Reference solution for 3.5.a. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List, Dict, Any def solve(logs: List[Dict[str, Any]], rules: List[Dict[str, Any]]) -> List[str]: """Return sorted list of log entry IDs that match at least one IDS signature rule. A log entry matches a rule when its dst_port equals the rule's port AND the rule's keyword appears (case-insensitive) in the entry's payload. """ matched = set() for entry in logs: port = entry["dst_port"] payload_lower = entry["payload"].lower() for rule in rules: if rule["port"] == port and rule["keyword"].lower() in payload_lower: matched.add(entry["id"]) break # one match is enough; avoid duplicates return sorted(matched)
