1. Brief

The situation. Implement a simplified network traffic-anomaly detector. You are given a per-host baseline (the normal profile for that host) and a window of observed flow records. Flag every host that either exceeds its baseline byte-volume threshold or uses a destination port not in its baseline's allowed-port set.

A baseline is a dict mapping host IP (str) to a dict with: - "max_bytes": integer, the maximum total outbound bytes this host normally sends in the window - "allowed_ports": list of integers, destination ports this host normally uses

An observed flow record is a dict with: - "host": source host IP string - "dst_port": destination port integer - "bytes": integer, bytes sent in this flow

A host may appear in multiple flow records within the same window; volumes accumulate.

Lesson objective. Explain how baseline traffic profiles support anomaly detection, read basic flow-record and packet-capture data, and identify network-monitoring indicators of compromise such as beaconing, unusual port usage, and abnormal data-volume spikes.

<details><summary>Reference: the exact contract</summary>

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def solve(baseline: dict, flows: list[dict]) -> list[str]

Input

baseline, dict mapping host IP (str) -> profile dict

Each profile dict has: - "max_bytes" (int): maximum normal total outbound bytes for this host in the window - "allowed_ports" (list[int]): destination ports normally used by this host

flows, list of observed flow record dicts (any order, possibly multiple per host)

Each flow dict has: - "host" (str): source host IP - "dst_port" (int): destination port - "bytes" (int): bytes sent in this flow

Output (result)

Sorted list[str] of host IPs flagged as anomalous, no duplicates.

Flagging rules

A host is flagged if ANY of the following hold: 1. Host is not a key in baseline (unknown host, no profile to compare against). 2. The sum of "bytes" across all of that host's flow records exceeds baseline[host]["max_bytes"]. 3. Any single flow record for that host has a "dst_port" not in baseline[host]["allowed_ports"].

Guarantees / rules

  • Pure function; deterministic; no I/O; no network access.
  • baseline and flows are not mutated by solve.
  • Standard library only.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

3. Build it

This is the model solution.

from typing import Dict, List def solve(baseline: Dict, flows: List[Dict]) -> List[str]: totals: Dict[str, int] = {} port_violation: Dict[str, bool] = {} unknown_hosts = set() for flow in flows: host = flow["host"] if host not in baseline: unknown_hosts.add(host) continue totals[host] = totals.get(host, 0) + flow["bytes"] allowed_ports = baseline[host]["allowed_ports"] if flow["dst_port"] not in allowed_ports: port_violation[host] = True flagged = set(unknown_hosts) for host, total in totals.items(): if total > baseline[host]["max_bytes"]: flagged.add(host) for host in port_violation: flagged.add(host) return sorted(flagged)
