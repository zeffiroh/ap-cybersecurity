Coding problem, 3.5.c: Incident response phase sorter

Skill: Detect Attacks, Collaborate · Maps to: 3.5.C · Language: Python 3 (pytest)

Problem

The NIST SP 800-61 incident response lifecycle has six phases, in this canonical order:

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

You will implement a function that takes a list of response-action records, each tagged with the phase it belongs to, but given in shuffled order, and returns the actions sorted into correct lifecycle order. Actions within the same phase keep their original relative order (a stable sort).

An action record is a dict with: - "action", string description of the action - "phase", string, one of the six canonical phase names exactly as spelled above

Function contract

Implement solve(actions) in the code editor (see the Reference section below).

  • actions, list of action record dicts, in arbitrary order

Return a list[str] of the "action" text values, reordered so that all actions from an earlier phase (per the canonical order above) come before all actions from a later phase. Within the same phase, preserve the original input order (stable sort). If an action's "phase" value is not one of the six canonical names, raise ValueError.

Examples

actions = [
    {"action": "Rebuild the server from a clean backup", "phase": "Recovery"},
    {"action": "Write the incident response plan", "phase": "Preparation"},
    {"action": "Isolate the infected host from the network", "phase": "Containment"},
    {"action": "Confirm the IDS alert is a real compromise", "phase": "Identification"},
]
solve(actions) == [
    "Write the incident response plan",
    "Confirm the IDS alert is a real compromise",
    "Isolate the infected host from the network",
    "Rebuild the server from a clean backup",
]

actions = [
    {"action": "Bogus phase", "phase": "Investigation"},
]
solve(actions)  # raises ValueError

Constraints

  • Deterministic, offline, standard library only.
  • Must pass all cases in the tests (visible + hidden).
  • Sort is stable within a phase.

# Reference solution """Reference solution for 3.5.c. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests). Implements a stable sort of incident-response actions into NIST SP 800-61 phase order. """ from typing import Dict, List PHASE_ORDER = [ "Preparation", "Identification", "Containment", "Eradication", "Recovery", "Lessons Learned", ] _PHASE_RANK = {name: i for i, name in enumerate(PHASE_ORDER)} def solve(actions: List[Dict]) -> List[str]: """Sort action records into canonical NIST IR phase order (stable within a phase). Args: actions: list of {"action": str, "phase": str} dicts, phase must be one of the six canonical NIST SP 800-61 phase names. Returns: List of "action" strings, reordered by phase. Raises: ValueError: if any action's phase is not a canonical phase name. """ for entry in actions: if entry["phase"] not in _PHASE_RANK: raise ValueError(f"Unknown IR phase: {entry['phase']!r}") # sorted() is stable, so entries with equal rank keep their original relative order. ordered = sorted(actions, key=lambda entry: _PHASE_RANK[entry["phase"]]) return [entry["action"] for entry in ordered]
