1. Brief

The situation. The NIST SP 800-61 incident response lifecycle has six phases, in this canonical order:

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

You will implement a function that takes a list of response-action records, each tagged with the phase it belongs to, but given in shuffled order, and returns the actions sorted into correct lifecycle order. Actions within the same phase keep their original relative order (a stable sort).

An action record is a dict with: - "action": string description of the action - "phase": string, one of the six canonical phase names exactly as spelled above

Lesson objective. Name the six phases of the NIST incident-response lifecycle in order, classify a given response action into its correct phase, and explain why performing actions out of order (for example, eradicating before containing) can make an incident worse.

Entry point

def solve(actions: list[dict]) -> list[str]

Input

actions, list of action record dicts, in arbitrary order

Each dict has: - "action" (str): description of the response action - "phase" (str): one of the six canonical NIST IR phase names, spelled exactly: "Preparation", "Identification", "Containment", "Eradication", "Recovery", "Lessons Learned"

Canonical phase order

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

Output (result)

list[str] of the "action" text values from the input, reordered so actions belonging to an earlier phase (per the canonical order) precede actions from a later phase. Actions within the same phase retain their relative order from the input (stable sort).

Errors

  • If any action's "phase" is not one of the six canonical names exactly, raise ValueError.

Guarantees / rules

  • Pure function; deterministic; no I/O; no network access.
  • actions is not mutated by solve.
  • Standard library only.

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
from typing import Dict, List PHASE_ORDER = [ "Preparation", "Identification", "Containment", "Eradication", "Recovery", "Lessons Learned", ] _PHASE_RANK = {name: i for i, name in enumerate(PHASE_ORDER)} def solve(actions: List[Dict]) -> List[str]: for entry in actions: if entry["phase"] not in _PHASE_RANK: raise ValueError(f"Unknown IR phase: {entry['phase']!r}") ordered = sorted(actions, key=lambda entry: _PHASE_RANK[entry["phase"]]) return [entry["action"] for entry in ordered]
