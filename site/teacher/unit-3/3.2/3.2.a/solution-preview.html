1. Brief

The situation. You are building an automated Wi-Fi configuration checker for Crestfield Analytics, mirroring what enterprise wireless assessment tools do. Given a dictionary describing one access point's configuration, return the sorted list of security gap codes that configuration has, based on the criteria from the lesson (protocol strength, PSK password length, guest network isolation, admin interface password strength, and firmware currency).

Lesson objective. Compare WPA2 and WPA3 wireless security protocols, explain the vulnerabilities each addresses, and evaluate a Wi-Fi network configuration against current best practice.

What comes in

  • cfg: dict with:
  • "protocol": str, one of "WPA3", "WPA2-AES", "WPA2-TKIP", "WEP", "OPEN"
  • "mode": str, "personal" or "enterprise"
  • "psk_length": int, length of the pre-shared key/password (only meaningful when mode == "personal")
  • "guest_network_isolated": bool, whether guest devices are on a separate, isolated SSID/VLAN
  • "admin_password_strong": bool, whether the AP's management interface has a strong unique password
  • "firmware_current": bool, whether the AP is running current (patched) firmware

What must come out

A sorted list[str] of gap codes present in the configuration (empty list if there are no gaps). Possible gap codes: - "insecure_protocol": protocol is "WEP", "WPA2-TKIP", or "OPEN" - "weak_psk", mode == "personal" and psk_length < 20 - "no_guest_isolation", guest_network_isolated is False - "weak_admin_password", admin_password_strong is False - "outdated_firmware", firmware_current is False

from typing import Dict, List _INSECURE_PROTOCOLS = {"WEP", "WPA2-TKIP", "OPEN"} def evaluate_wifi_config(cfg: Dict) -> List[str]: gaps = [] if cfg["protocol"] in _INSECURE_PROTOCOLS: gaps.append("insecure_protocol") if cfg["mode"] == "personal" and cfg["psk_length"] < 20: gaps.append("weak_psk") if not cfg["guest_network_isolated"]: gaps.append("no_guest_isolation") if not cfg["admin_password_strong"]: gaps.append("weak_admin_password") if not cfg["firmware_current"]: gaps.append("outdated_firmware") return sorted(gaps)
