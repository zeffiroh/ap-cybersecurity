1. Brief

The situation. You are building a control matrix tool for Crestfield Analytics' security program. Given a list of implemented security scenarios, classify each one by control family: "managerial", "technical", or "physical", based on how the control is actually implemented (its "mechanism"), not on what risk it happens to address.

Lesson objective. Distinguish managerial (administrative) controls from technical and physical controls, describe the purpose of core security policy documents (AUP, least privilege, security awareness training), and match a given organizational scenario to the correct control type and policy.

What comes in

  • scenarios: list[dict], each with:
  • "id": str, a scenario identifier
  • "description": str, flavor text describing the scenario (not used for classification)
  • "mechanism": str, one of "policy_document", "training_program", "access_review_process", "software_or_hardware_enforcement", "physical_barrier"

What must come out

A list[str] of classifications, one per input scenario, in the same order as the input. Each entry is one of "managerial", "technical", "physical".
