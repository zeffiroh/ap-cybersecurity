Coding problem, 3.2.c: Defense-in-depth layer classifier

Skill: Mitigate Risk · Maps to: 3.2.B, 3.2.C · Language: Python 3 (pytest)

Problem

You are building a defense-in-depth mapping tool for Crestfield Analytics' security architecture review. Given a list of deployed controls, assign each one to its correct layer in the layered defense model taught in the lesson: "perimeter", "network", "host", "application", "data", or "human".

Function contract

Implement classify_layer(controls) in the code editor (see the Reference section below).

Input

  • controls: list[dict], each with:
  • "name": str, a human-readable control name (not used for classification)
  • "category": str, one of the following exact values:
    • Perimeter: "firewall", "ips", "dns_filter"
    • Network: "vlan_segmentation", "internal_firewall", "wifi_protocol"
    • Host: "endpoint_av", "host_firewall", "os_patching"
    • Application: "input_validation", "waf", "app_auth"
    • Data: "encryption_at_rest", "dlp", "data_classification"
    • Human: "awareness_training", "aup", "access_review", "incident_response_policy"

Output

A list[str] of layer assignments, one per input control, in the same order as the input. Each entry is one of "perimeter", "network", "host", "application", "data", "human".

Examples

controls = [
    {"name": "Border firewall", "category": "firewall"},
    {"name": "WPA3 wireless", "category": "wifi_protocol"},
    {"name": "Annual phishing training", "category": "awareness_training"},
]
classify_layer(controls)  ->  ["perimeter", "network", "human"]

Constraints

  • Deterministic, offline, standard library only.
  • Classification depends only on "category", never on "name" text.
  • "category" always contains one of the 16 listed values in test data (no invalid values).
  • Must pass all cases in the tests (visible + hidden).

Reference

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def classify_layer(controls: list[dict]) -> list[str]

Input (controls)

list[dict] where each dict has: - "name": str, flavor text, not used for classification logic - "category": str, one of 16 exact values, grouped as: - perimeter: "firewall", "ips", "dns_filter" - network: "vlan_segmentation", "internal_firewall", "wifi_protocol" - host: "endpoint_av", "host_firewall", "os_patching" - application: "input_validation", "waf", "app_auth" - data: "encryption_at_rest", "dlp", "data_classification" - human: "awareness_training", "aup", "access_review", "incident_response_policy"

Output (result)

A list[str] the same length as controls, in the same order as the input, where each element is one of "perimeter", "network", "host", "application", "data", "human".

Classification rule

Look up "category" in the grouping table above and return the corresponding layer name.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • "category" always contains one of the 16 listed values in test data.
  • Output order matches input order exactly.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

# Reference solution """Reference solution for 3.2.c. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import Dict, List _LAYER_MAP = { "firewall": "perimeter", "ips": "perimeter", "dns_filter": "perimeter", "vlan_segmentation": "network", "internal_firewall": "network", "wifi_protocol": "network", "endpoint_av": "host", "host_firewall": "host", "os_patching": "host", "input_validation": "application", "waf": "application", "app_auth": "application", "encryption_at_rest": "data", "dlp": "data", "data_classification": "data", "awareness_training": "human", "aup": "human", "access_review": "human", "incident_response_policy": "human", } def classify_layer(controls: List[Dict]) -> List[str]: """Assign each control to its defense-in-depth layer based on 'category'. See the Reference section below for the full category -> layer mapping. """ result = [] for c in controls: category = c["category"] if category not in _LAYER_MAP: raise ValueError(f"unknown category: {category}") result.append(_LAYER_MAP[category]) return result
