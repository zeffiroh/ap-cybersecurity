1. Brief

The situation. You are building a defense-in-depth mapping tool for Crestfield Analytics' security architecture review. Given a list of deployed controls, assign each one to its correct layer in the layered defense model taught in the lesson: "perimeter", "network", "host", "application", "data", or "human".

Lesson objective. Explain the principle of defense in depth, place a given security control at the correct layer of a layered network defense model, and evaluate why relying on any single control creates a single point of failure.

What comes in

  • controls: list[dict], each with:
  • "name": str, a human-readable control name (not used for classification)
  • "category": str, one of the following exact values:
    • Perimeter: "firewall", "ips", "dns_filter"
    • Network: "vlan_segmentation", "internal_firewall", "wifi_protocol"
    • Host: "endpoint_av", "host_firewall", "os_patching"
    • Application: "input_validation", "waf", "app_auth"
    • Data: "encryption_at_rest", "dlp", "data_classification"
    • Human: "awareness_training", "aup", "access_review", "incident_response_policy"

What must come out

A list[str] of layer assignments, one per input control, in the same order as the input. Each entry is one of "perimeter", "network", "host", "application", "data", "human".

Look up "category" in the grouping table above and return the corresponding layer name.

from typing import Dict, List _LAYER_MAP = { "firewall": "perimeter", "ips": "perimeter", "dns_filter": "perimeter", "vlan_segmentation": "network", "internal_firewall": "network", "wifi_protocol": "network", "endpoint_av": "host", "host_firewall": "host", "os_patching": "host", "input_validation": "application", "waf": "application", "app_auth": "application", "encryption_at_rest": "data", "dlp": "data", "data_classification": "data", "awareness_training": "human", "aup": "human", "access_review": "human", "incident_response_policy": "human", } def classify_layer(controls: List[Dict]) -> List[str]: result = [] for c in controls: category = c["category"] if category not in _LAYER_MAP: raise ValueError(f"unknown category: {category}") result.append(_LAYER_MAP[category]) return result
