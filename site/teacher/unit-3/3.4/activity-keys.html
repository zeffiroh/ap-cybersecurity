Firewall Access Controls · instructor-only · 2 entries

Skill 3.4.a

Firewall types (stateful vs. stateless)

Instructor notes

  • Key learning moment: packet D (ACK with no prior SYN) is allowed by the stateless firewall because its port matches Rule 1. The stateful firewall drops it because no session exists. This is the central "aha" of the atom.
  • Common stumble: students treat SYN-ACK return traffic as a new connection rather than as a response. Clarify that the firewall tracks the session from the initial SYN, so return traffic for an established session is automatically permitted regardless of direction rules.
  • Feeds the unit project (firewall rule design) and the scenario stage where students configure a simulated network perimeter.
Skill 3.4.b

Firewall rules and access control lists (ACLs)

Instructor notes

  • Expected fix: move rule 3 (the specific deny) above rule 1 (the broad allow). New order: 3, 1, 2, 4, 5 (or any order where rule 3 precedes rule 1). Re-traced: A=DENY, B=ALLOW, C=ALLOW, D=DENY, all match intent.
  • Key learning moment: the fix never changes any rule's content, only its position. Students who try to rewrite rule 1's conditions instead of reordering are missing the core lesson.
  • Common stumble: students think rule 3 being "more specific" gives it automatic priority. Firmly correct this, no such override exists in first-match-wins evaluation.
  • Feeds the unit project (firewall rule design) and the scenario stage where students harden a simulated network perimeter.
