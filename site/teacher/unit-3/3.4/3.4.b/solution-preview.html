1. Brief

The situation. Implement a firewall ACL evaluator. Given an ordered list of rules and a list of packets, decide the verdict ("allow" or "deny") for each packet using first-match-wins evaluation with an implicit deny-all at the end of the list.

A rule is a dict with these string/number keys: - "action", "allow" or "deny" - "src": source IP string, or "any" - "dst": destination IP string, or "any" - "port": destination port integer, or 0 meaning any port - "proto": protocol string: "tcp", "udp", or "any"

A packet is a dict with: - "src": source IP string - "dst": destination IP string - "port": destination port integer - "proto": protocol string ("tcp" or "udp")

Lesson objective. Write and evaluate an ordered firewall access control list (ACL), correctly apply first-match-wins evaluation, and identify when a rule's placement creates a security gap by shadowing a more specific rule below it.

Entry point

def solve(rules: list[dict], packets: list[dict]) -> list[str]

Input

rules, list of rule dicts, evaluated top-to-bottom (first match wins)

Each rule dict has: - "action" (str): "allow" or "deny" - "src" (str): source IP address, or "any" - "dst" (str): destination IP address, or "any" - "port" (int): destination port, or 0 meaning any port - "proto" (str): "tcp", "udp", or "any"

packets, list of packet dicts, evaluated independently, in order

Each packet dict has: - "src" (str): source IP address - "dst" (str): destination IP address - "port" (int): destination port - "proto" (str): "tcp" or "udp"

Output (result)

list[str] of verdicts, one per packet, each "allow" or "deny", in the same order as packets.

Rule matching

A rule matches a packet when ALL hold: 1. rule["src"] == "any" OR rule["src"] == packet["src"] 2. rule["dst"] == "any" OR rule["dst"] == packet["dst"] 3. rule["port"] == 0 OR rule["port"] == packet["port"] 4. rule["proto"] == "any" OR rule["proto"] == packet["proto"]

Evaluation returns the first matching rule's action. If no rule matches, the implicit deny-all applies: verdict = "deny".

Guarantees / rules

  • Pure function; deterministic; no I/O; no network access.
  • rules list is not mutated by solve.
  • Standard library only.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

from typing import List, Dict def _rule_matches(rule: Dict, packet: Dict) -> bool: if rule["src"] != "any" and rule["src"] != packet["src"]: return False if rule["dst"] != "any" and rule["dst"] != packet["dst"]: return False if rule["port"] != 0 and rule["port"] != packet["port"]: return False if rule["proto"] != "any" and rule["proto"] != packet["proto"]: return False return True def solve(rules: List[Dict], packets: List[Dict]) -> List[str]: verdicts: List[str] = [] for pkt in packets: verdict = "deny" for rule in rules: if _rule_matches(rule, pkt): verdict = rule["action"] break verdicts.append(verdict) return verdicts
