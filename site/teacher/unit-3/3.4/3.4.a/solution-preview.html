Firewall types (stateful vs. stateless) (MODEL SOLUTION, instructor copy, do not distribute)

Coding problem, 3.4.a: Stateless vs. stateful packet classifier

Skill: Mitigate Risk · Maps to: 3.4.A · Language: Python 3 (pytest)

Problem

You will implement two firewall decision functions that together illustrate the core difference between stateless and stateful packet filtering.

A packet is a dict with these string keys: - "src", source IP string (e.g. "203.0.113.10") - "dst", destination IP string - "sport", source port integer - "dport", destination port integer - "proto", protocol string, one of "tcp" / "udp" / "icmp" - "flags", TCP flag string: one of "SYN", "SYN-ACK", "ACK", "RST", "FIN", "DATA" (non-TCP packets use "")

A rule is a dict with: - "action", "allow" or "drop" - "proto", protocol to match ("tcp", "udp", "icmp", or "any") - "dport", destination port to match (integer) or 0 meaning any port

Rules are evaluated top-to-bottom; the first match decides. If no rule matches, the implicit verdict is "drop".

Function contract

Implement solve(rules, packets, mode) in the code editor (see the Reference section below).

  • rules, list of rule dicts (ordered, first-match)
  • packets, list of packet dicts (process in order)
  • mode, string: "stateless" or "stateful"

Return a list[str] of verdicts ("allow" or "drop"), one per packet, in order.

Stateless mode

For each packet, walk the rule list. A rule matches when: 1. rule["proto"] is "any" OR equals packet["proto"] 2. rule["dport"] is 0 OR equals packet["dport"]

Return the matched rule's action, or "drop" if nothing matches.

Stateful mode

Same rule matching applies, but also maintain an in-memory connection-tracking table (a dict). The table key is (src, dst, sport, dport, proto) (tuple of the five fields above).

Additional stateful logic for TCP packets only: - SYN: if the packet passes rules, add (src, dst, sport, dport, "tcp") to the table with state "SYN_SENT". Verdict = "allow". - SYN-ACK: look up the reverse key (dst, src, dport, sport, "tcp") in the table (the original SYN entry). If found, update its state to "ESTABLISHED". Verdict = "allow". If the reverse key is not in the table, verdict = "drop". - ACK / DATA: if the packet's key OR its reverse is in the table with state "ESTABLISHED", verdict = "allow". Otherwise verdict = "drop" (no established session for this endpoint pair, a stateful firewall drops it even though a static rule might otherwise permit the port). - RST / FIN: if the key or reverse is in the table, remove the entry. Verdict = "allow". Otherwise "drop".

Non-TCP packets (UDP, ICMP) are decided by rule matching only (no state tracking).

The table starts empty at the beginning of each solve() call.

Input

rules = [
    {"action": "allow", "proto": "tcp", "dport": 443},
    {"action": "allow", "proto": "tcp", "dport": 80},
    {"action": "drop",  "proto": "any", "dport": 0},
]
packets = [
    {"src": "203.0.113.10", "dst": "10.0.0.5", "sport": 55001, "dport": 443, "proto": "tcp", "flags": "SYN"},
    {"src": "10.0.0.5",     "dst": "203.0.113.10", "sport": 443, "dport": 55001, "proto": "tcp", "flags": "SYN-ACK"},
    {"src": "198.51.100.7", "dst": "10.0.0.5", "sport": 44000, "dport": 443, "proto": "tcp", "flags": "ACK"},
]

Output

stateless: ["allow", "drop", "allow"]   # SYN-ACK (dport 55001) matches no rule
stateful:  ["allow", "allow", "drop"]   # third packet: ACK with no prior SYN

Entry point

def solve(rules: list[dict], packets: list[dict], mode: str) -> list[str]

Input

rules, list of rule dicts, evaluated top-to-bottom (first match wins)

Each rule dict has: - "action" (str): "allow" or "drop" - "proto" (str): "tcp", "udp", "icmp", or "any" - "dport" (int): destination port to match, or 0 meaning any port

packets, list of packet dicts, processed in order

Each packet dict has: - "src" (str): source IP address - "dst" (str): destination IP address - "sport" (int): source port - "dport" (int): destination port - "proto" (str): "tcp", "udp", or "icmp" - "flags" (str): TCP flag, one of "SYN", "SYN-ACK", "ACK", "RST", "FIN", "DATA", or "" for non-TCP

mode, "stateless" or "stateful"

Output (result)

list[str] of verdicts, one per packet, each "allow" or "drop", in the same order as packets.

Rule matching (both modes)

A rule matches a packet when BOTH conditions hold: 1. rule["proto"] == "any" OR rule["proto"] == packet["proto"] 2. rule["dport"] == 0 OR rule["dport"] == packet["dport"] Implicit default if no rule matches: "drop".

Stateful TCP tracking (stateful mode only)

  • Connection table key: (src, dst, sport, dport, proto), all five fields.
  • SYN: passes rules -> add key with state "SYN_SENT" -> "allow".
  • SYN-ACK: reverse key (dst, src, dport, sport, proto) in table -> update to "ESTABLISHED" -> "allow". Reverse key not found -> "drop".
  • ACK / DATA: key or reverse in table with state "ESTABLISHED" -> "allow". Otherwise -> "drop" (no established session for this endpoint pair).
  • RST / FIN: key or reverse in table -> remove entry -> "allow". Not found -> "drop".
  • Non-TCP packets (UDP, ICMP): rule matching only; no state tracking.

Guarantees / rules

  • Pure function; deterministic; no I/O; no network access.
  • Connection table is initialized empty at the start of each solve() call.
  • Standard library only.

# Reference solution """Reference solution for 3.4.a. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests). Implements a stateless and stateful packet classifier demonstrating the core difference between the two firewall inspection models. """ from typing import List, Dict, Any def _match_rules(rules: List[Dict], packet: Dict) -> str: """Apply rule list top-to-bottom; return first matched action, or 'drop'.""" for rule in rules: proto_ok = rule["proto"] == "any" or rule["proto"] == packet["proto"] dport_ok = rule["dport"] == 0 or rule["dport"] == packet["dport"] if proto_ok and dport_ok: return rule["action"] return "drop" def solve(rules: List[Dict], packets: List[Dict], mode: str) -> List[str]: """Classify each packet as 'allow' or 'drop' using the given rule set. Args: rules: Ordered list of rule dicts (action, proto, dport). packets: List of packet dicts (src, dst, sport, dport, proto, flags). mode: 'stateless' or 'stateful'. Returns: List of 'allow' / 'drop' verdicts, one per packet. """ if mode == "stateless": return [_match_rules(rules, pkt) for pkt in packets] # Stateful mode: maintain a connection-tracking table. # Key: (src, dst, sport, dport, proto) Value: state string table: Dict[tuple, str] = {} verdicts: List[str] = [] for pkt in packets: proto = pkt["proto"] flags = pkt.get("flags", "") key = (pkt["src"], pkt["dst"], pkt["sport"], pkt["dport"], proto) rev = (pkt["dst"], pkt["src"], pkt["dport"], pkt["sport"], proto) if proto != "tcp": # Non-TCP: rule matching only. verdicts.append(_match_rules(rules, pkt)) continue if flags == "SYN": rule_verdict = _match_rules(rules, pkt) if rule_verdict == "allow": table[key] = "SYN_SENT" verdicts.append("allow") else: verdicts.append("drop") elif flags == "SYN-ACK": if rev in table: table[rev] = "ESTABLISHED" verdicts.append("allow") else: verdicts.append("drop") elif flags in ("ACK", "DATA"): if table.get(key) == "ESTABLISHED" or table.get(rev) == "ESTABLISHED": verdicts.append("allow") else: # No established session for this exact endpoint pair: a stateful # firewall drops it even if a static rule would otherwise permit # the port, because it cannot verify the packet belongs to a real # connection. verdicts.append("drop") elif flags in ("RST", "FIN"): if key in table or rev in table: table.pop(key, None) table.pop(rev, None) verdicts.append("allow") else: verdicts.append("drop") else: # Unknown flag: rule matching. verdicts.append(_match_rules(rules, pkt)) return verdicts
