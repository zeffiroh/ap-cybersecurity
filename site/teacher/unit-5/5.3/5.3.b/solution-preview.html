1. Brief

The situation. Build three small helpers a security engineer would use when reasoning about symmetric key management, without relying on any real crypto library (standard library only, this is a toy, pedagogical model, not production cryptography).

  1. Key wrapping (envelope encryption). Implement wrap_key(dek, kek) and unwrap_key(wrapped, kek) using a repeating-XOR keystream: each byte of dek is XORed with the KEK byte at the same position modulo len(kek). This models how a Key Encryption Key (KEK) wraps a Data Encryption Key (DEK) for storage (see atom.md, "Key wrapping (Envelope Encryption)"). Unwrapping with the same KEK must recover the original DEK exactly, since XOR is its own inverse.
  2. Weak-RNG detection. Implement looks_like_csprng(key_bytes), a heuristic that flags keys that could NOT plausibly have come from a CSPRNG because they show low entropy / obvious structure (e.g., a single repeated byte, a short repeating pattern, or a strictly monotonic/arithmetic byte sequence like 0,1,2,3...). Real CSPRNG output has no such structure.
  3. ECB pattern-leakage detection. Implement detect_ecb_leakage(ciphertext_blocks), which takes a list of same-size bytes blocks (as an ECB-mode block cipher would produce) and returns True if any two blocks are identical, the tell-tale sign that ECB mode is leaking repeated plaintext patterns into the ciphertext (see atom.md, "Electronic Codebook (ECB) Mode (Insecure)").

Lesson objective. Explain the mechanics of symmetric encryption, differentiate between ECB and secure modes of operation (like CBC and GCM), and describe the key lifecycle management principles necessary to protect keys from compromise.

What comes in

  • wrap_key/unwrap_key: dek/wrapped are bytes (may be empty); kek is non-empty bytes.
  • looks_like_csprng: key_bytes is bytes, at least 1 byte.
  • detect_ecb_leakage: ciphertext_blocks is list[bytes], all blocks the same length.

What must come out

  • wrap_key/unwrap_key return bytes the same length as their key argument.
  • looks_like_csprng returns bool.

  • detect_ecb_leakage returns bool.

Entry points

def wrap_key(dek: bytes, kek: bytes) -> bytes

Input / output

wrap_key(dek, kek) -> bytes
  • dek: bytes, the plaintext Data Encryption Key to wrap (may be empty).
  • kek: bytes, the Key Encryption Key, non-empty.
  • Returns bytes of the same length as dek, where output byte i is dek[i] XOR kek[i % len(kek)] (repeating-XOR keystream).
unwrap_key(wrapped, kek) -> bytes
  • Inverse of wrap_key: unwrap_key(wrap_key(dek, kek), kek) == dek for any dek and any non-empty kek, since XOR is its own inverse.
looks_like_csprng(key_bytes) -> bool
  • key_bytes: bytes, a candidate generated key.
  • Returns False if len(key_bytes) < 8 (too short to judge).
  • Returns False if the bytes show obvious low-entropy structure:
  • all bytes identical, OR
  • the byte sequence is a short repeating pattern (period p with 1 <= p <= len(key_bytes)//2) that tiles the whole input, OR
  • the byte sequence is strictly a constant-step arithmetic sequence (e.g. 0,1,2,3... or 10,8,6,4...), taken modulo 256.
  • Returns True otherwise.
detect_ecb_leakage(ciphertext_blocks) -> bool
  • ciphertext_blocks: list[bytes], all the same length (as ECB-mode block-cipher output would be); may be empty or contain a single block.
  • Returns True if any two blocks in the list are byte-for-byte identical (indicating the plaintext blocks that produced them were also identical, the ECB pattern-leakage weakness).
  • Returns False if all blocks are distinct, or if there are fewer than 2 blocks.

Guarantees / rules

  • Pure functions, deterministic, no I/O, no network. Standard library only.
  • No use of random, os.urandom, secrets, or any real cipher/hash primitive, the point of this toy toolkit is to reason about structure and wrapping mechanics, not to be secure.
  • wrap_key/unwrap_key: kek non-empty is a caller guarantee, not something the function must validate defensively beyond raising on empty kek.

def wrap_key(dek: bytes, kek: bytes) -> bytes: if not kek: raise ValueError("kek must be non-empty") return bytes(b ^ kek[i % len(kek)] for i, b in enumerate(dek)) def unwrap_key(wrapped: bytes, kek: bytes) -> bytes: return wrap_key(wrapped, kek) def looks_like_csprng(key_bytes: bytes) -> bool: n = len(key_bytes) if n < 8: return False if len(set(key_bytes)) == 1: return False for period in range(1, n // 2 + 1): pattern = key_bytes[:period] tiled = (pattern * (n // period + 1))[:n] if tiled == key_bytes: return False step = (key_bytes[1] - key_bytes[0]) % 256 is_arithmetic = all( (key_bytes[i] - key_bytes[i - 1]) % 256 == step for i in range(1, n) ) if is_arithmetic: return False return True def detect_ecb_leakage(ciphertext_blocks: list) -> bool: seen = set() for block in ciphertext_blocks: if block in seen: return True seen.add(block) return False
