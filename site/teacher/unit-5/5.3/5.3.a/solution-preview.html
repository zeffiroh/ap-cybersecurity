Coding problem, 5.3.a: Encryption vs. hashing

Skill: Mitigate Risk · Maps to: 5.3.A · Language: Python 3 (pytest)

Problem

In secure systems, credentials like passwords should never be stored in their original plaintext form, nor should they be encrypted (which implies they could be decrypted if the key is compromised). Instead, they should be hashed using a one-way cryptographic function combined with a unique, random value called a salt. The salt ensures that identical passwords result in different digests, defeating precomputed lookup attacks (like rainbow tables).

Your task is to implement a password hashing and verification module.

You must implement the function solve(action: str, password: str, param: str) to handle two actions: 1. Hash a password: Given action "hash", a plaintext password, and a salt, compute the SHA-256 hash of the concatenated string salt + password. Return a combined string of the format salt$digest (where digest is the hex-encoded hash). 2. Verify a password: Given action "verify", a plaintext password, and a stored hash string in the format salt$digest, extract the salt and digest, compute the salted hash of the password, and verify if it matches the expected digest. Use a constant-time comparison helper like hmac.compare_digest to prevent timing side-channel attacks.

Function contract

Implement solve(action: str, password: str, param: str) -> Union[str, bool] in the code editor (see the Reference section below).

Input

  • action: Either "hash" or "verify"
  • password: The plaintext password
  • param: Either the salt (if hashing) or the stored_hash of format salt$digest (if verifying)

Output

  • If hashing: A string of format salt$digest
  • If verifying: A boolean indicating whether the password matches the digest

Examples

solve("hash", "myPassword", "somesalt")
# -> "somesalt$4f24ef3001859bf9016e7a750ef90333d833890ea70c99a6cfbf6e568ea46a9a"

solve("verify", "myPassword", "somesalt$4f24ef3001859bf9016e7a750ef90333d833890ea70c99a6cfbf6e568ea46a9a")
# -> True

solve("verify", "wrongPassword", "somesalt$4f24ef3001859bf9016e7a750ef90333d833890ea70c99a6cfbf6e568ea46a9a")
# -> False

Entry point

def solve(action: str, password: str, param: str) -> Union[str, bool]

Input

  • action: A string, either "hash" or "verify".
  • password: A string, the plaintext password to hash or verify.
  • param:
  • If action is "hash": this is the salt (string) to be prepended to the password.
  • If action is "verify": this is the stored hash (string) of format salt$digest to verify against.

Output

  • If action is "hash": returns salt$digest where digest is the hex-encoded SHA-256 hash of salt + password.
  • If action is "verify": returns a boolean (True if matches, False otherwise).

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only.
  • Safe verification should use a constant-time comparison helper like hmac.compare_digest.
# Reference solution """Reference solution for 5.3.a. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests). """ import hashlib import hmac from typing import Union def solve(action: str, password: str, param: str) -> Union[str, bool]: """Perform salted hashing or verification of passwords. If action == "hash": param is the salt (string). Returns "salt$digest" where digest is the SHA-256 hex digest of (salt + password). If action == "verify": param is the stored hash "salt$digest". Returns True if the computed hash matches the stored digest, False otherwise. """ if action == "hash": salt = param hasher = hashlib.sha256() hasher.update((salt + password).encode("utf-8")) digest = hasher.hexdigest() return f"{salt}${digest}" elif action == "verify": stored_hash = param if "$" not in stored_hash: return False parts = stored_hash.split("$", 1) if len(parts) != 2: return False salt, expected_digest = parts hasher = hashlib.sha256() hasher.update((salt + password).encode("utf-8")) computed_digest = hasher.hexdigest() return hmac.compare_digest(computed_digest, expected_digest) else: raise ValueError("Invalid action. Must be 'hash' or 'verify'.")
