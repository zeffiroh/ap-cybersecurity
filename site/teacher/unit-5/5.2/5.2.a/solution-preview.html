Access control models (RBAC, DAC, MAC) (MODEL SOLUTION, instructor copy, do not distribute)

Coding problem, 5.2.a: RBAC / DAC / MAC access decision

Skill: Mitigate Risk · Maps to: 5.2.A · Language: Python 3 (pytest)

Problem

Build the access-decision function a policy engine would run for a fictional file system that supports all three access control models. Given a request (subject, object, action, and the object's model), decide whether the request is ALLOWed or DENYed.

Rules by model

  • "dac", allowed if the subject is the object's owner, OR the subject appears in the object's grants list for that action (e.g., grants: {"read": ["bob"], "write": []}).
  • "mac", allowed only if the subject's clearance level is >= the object's classification level. Levels (low to high): "public" < "confidential" < "secret" < "top_secret".
  • "rbac", allowed if any of the subject's roles is present in the object's allowed_roles list for the requested action (e.g., allowed_roles: {"read": ["nurse","admin"], "write": ["admin"]}).

If the object's model is not one of "dac", "mac", "rbac", deny with reason "unknown_model".

Function contract

Implement solve(request: dict) -> dict in the code editor (see the Reference section below).

Input

request: a dict with keys "subject" (dict) and "object" (dict) and "action" (str). See the Reference section below for the exact shape per model.

Output

{"allowed": bool, "reason": str} where reason is one of "owner", "granted", "dac_denied", "clearance_sufficient", "clearance_insufficient", "role_match", "rbac_denied", "unknown_model".

Examples

DAC owner:
  {"subject":{"name":"alice"},"object":{"model":"dac","owner":"alice","grants":{}},"action":"read"}
  -> {"allowed": True, "reason": "owner"}

MAC insufficient clearance:
  {"subject":{"clearance":"confidential"},"object":{"model":"mac","classification":"secret"},"action":"read"}
  -> {"allowed": False, "reason": "clearance_insufficient"}

RBAC role match:
  {"subject":{"roles":["nurse"]},"object":{"model":"rbac","allowed_roles":{"read":["nurse","admin"]}},"action":"read"}
  -> {"allowed": True, "reason": "role_match"}

Constraints

  • Deterministic, offline, standard library only.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(request: dict) -> dict

Input (request)

{"subject": dict, "object": dict, "action": str}

  • DAC object: {"model": "dac", "owner": str, "grants": {action: [subject_name...]}}; subject: {"name": str}.
  • MAC object: {"model": "mac", "classification": str}; subject: {"clearance": str}. Levels low->high: "public", "confidential", "secret", "top_secret".
  • RBAC object: {"model": "rbac", "allowed_roles": {action: [role...]}}; subject: {"roles": [role...]}.

Output (result)

{"allowed": bool, "reason": str} where reason is one of "owner", "granted", "dac_denied", "clearance_sufficient", "clearance_insufficient", "role_match", "rbac_denied", "unknown_model".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • DAC: owner check takes priority over grants list.
  • MAC: allowed when subject clearance level >= object classification level (equal is allowed).
  • RBAC: allowed if any of the subject's roles appears in the object's allowed_roles for the action.
  • Any object.model outside {"dac","mac","rbac"} -> {"allowed": False, "reason": "unknown_model"}.

# Reference solution """Reference solution for 5.2.a. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import Dict _LEVELS = {"public": 0, "confidential": 1, "secret": 2, "top_secret": 3} def solve(request: Dict[str, object]) -> Dict[str, object]: """Decide ALLOW/DENY for a DAC, MAC, or RBAC access request.""" subject = request["subject"] obj = request["object"] action = request["action"] model = obj.get("model") if model == "dac": if subject.get("name") == obj.get("owner"): return {"allowed": True, "reason": "owner"} grants = obj.get("grants", {}) if subject.get("name") in grants.get(action, []): return {"allowed": True, "reason": "granted"} return {"allowed": False, "reason": "dac_denied"} if model == "mac": sub_level = _LEVELS.get(subject.get("clearance"), -1) obj_level = _LEVELS.get(obj.get("classification"), 99) if sub_level >= obj_level: return {"allowed": True, "reason": "clearance_sufficient"} return {"allowed": False, "reason": "clearance_insufficient"} if model == "rbac": allowed_roles = obj.get("allowed_roles", {}).get(action, []) subject_roles = subject.get("roles", []) if any(r in allowed_roles for r in subject_roles): return {"allowed": True, "reason": "role_match"} return {"allowed": False, "reason": "rbac_denied"} return {"allowed": False, "reason": "unknown_model"}
