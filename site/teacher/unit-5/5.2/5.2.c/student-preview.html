Credential theft prevention and lateral movement

Coding problem, 5.2.c: Detect lateral movement in an authentication log

Skill: Mitigate Risk, Detect Attacks · Maps to: 5.2.B, 5.2.C · Language: Python 3 (pytest)

Problem

Build the detector a security team's SIEM rule would run over authentication events. Given a list of authentication events (account, destination host, timestamp in minutes), flag any account that authenticated to at least threshold distinct hosts within any rolling window_minutes window, a classic lateral-movement signal.

Function contract

Implement solve(events: list, threshold: int, window_minutes: int) -> list in the code editor (see the Reference section below).

Input

  • events: list[dict], each {"account": str, "host": str, "ts": int} (ts = minutes since start of log, non-negative integer, not necessarily sorted).
  • threshold: int, minimum number of distinct hosts within the window to flag the account.
  • window_minutes: int, size of the rolling time window, in minutes (inclusive on both ends).

Output

A sorted, de-duplicated list[str] of account names that hit the threshold at any point.

Examples

events = [
  {"account":"mkt_dana","host":"h1","ts":0},
  {"account":"mkt_dana","host":"h2","ts":2},
  {"account":"mkt_dana","host":"h3","ts":4},
  {"account":"svc_backup","host":"h9","ts":0},
]
solve(events, threshold=3, window_minutes=5) -> ["mkt_dana"]

events = [
  {"account":"alice","host":"h1","ts":0},
  {"account":"alice","host":"h2","ts":100},
]
solve(events, threshold=2, window_minutes=5) -> []   # too far apart for the window

Constraints

  • Deterministic, offline, standard library only.
  • A window [t, t + window_minutes] counts an event if its ts falls within that inclusive range; consider every event's ts as a possible window start.
  • Repeated authentications to the SAME host do not add distinct-host count.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(events: list, threshold: int, window_minutes: int) -> list

Input

  • events: list[dict], each {"account": str, "host": str, "ts": int}. Not necessarily sorted by ts. ts is minutes since the start of the log (non-negative int).
  • threshold: int, minimum number of distinct hosts within a window to flag the account.
  • window_minutes: int, inclusive window size in minutes.

Output (result)

Sorted, de-duplicated list[str] of account names for which some window [start, start + window_minutes] (with start equal to some event's ts for that account) contains events touching >= threshold distinct hosts.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • The window bounds are inclusive: an event with ts == start + window_minutes counts.
  • Repeated events to the same host within a window count once toward distinct-host count.
