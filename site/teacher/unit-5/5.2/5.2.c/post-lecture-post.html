The big picture: The detail worth remembering past this lecture is pass-the-hash: an attacker moving laterally frequently never needs your actual password at all, because many authentication protocols will accept a stolen hash or ticket as proof of identity just as readily as the plaintext would have been. That single fact should reshape how you think about password strength, a 20-character unguessable password does nothing to stop an attacker who scraped its hash straight out of memory on a compromised machine and replayed it. This is exactly why MFA earns its place as the standout defense in this skill: it's the one control that breaks the assumption underlying every credential-theft technique here, because a stolen credential, hashed, plaintext, or ticketed, is worthless without the second factor. Keep this skill in mind through the rest of the unit as the connective tissue to Unit 4's detection material: the behavioral signals described here (unusual host counts, atypical hours, first-time admin-tool use) are the same anomaly-detection logic as 5.6's log analysis, just applied to authentication events specifically.

Key terms to lock in:

  • Lateral movement: an attacker using a compromised account/host to reach additional systems within a network after an initial foothold.
  • Pass-the-hash / pass-the-ticket: authenticating using a stolen password hash or session ticket without ever knowing the plaintext password.
  • Privilege escalation: increasing the level of access an attacker holds, often paired with lateral movement toward higher-value accounts/systems.
  • Multi-factor authentication (MFA): requiring a second proof of identity beyond a password, which neutralizes most stolen-credential replay attempts.
  • Network segmentation: dividing a network so that compromise of one segment does not grant direct reach into another (e.g., isolating finance systems from general workstations).

Common misconceptions to watch for:

  • "A strong password alone stops credential theft." → Many lateral-movement techniques replay a stolen hash or ticket without ever needing the plaintext password, MFA and hygiene practices matter more than password strength alone.
  • "Lateral movement is only detectable after the fact." → Behavioral signals (unusual host counts, atypical hours, first-time admin-tool use) can flag lateral movement while it is in progress, which is exactly what the detection tooling covered in Unit 4 is built to surface.

Learning objective(s): 5.2.B, 5.2.C
