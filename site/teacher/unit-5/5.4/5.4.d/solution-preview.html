Coding problem, 5.4.d: Validate a certificate chain

Skill: Mitigate Risk · Maps to: 5.4.B, 5.4.C · Language: Python 3 (pytest)

Problem

A browser has just received a TLS certificate chain from a server: a leaf (end-entity) certificate and one or more issuing CA certificates, and it needs to decide whether to trust it. Real browsers call into a full X.509 library to do this; you are going to implement the validation logic itself, the same logic that library runs under the hood, using the small-number RSA sign/verify math from 5.4.b/5.4.c.

Each certificate is a plain dict:

{
  "subject": "www.meridianbank.example",     # who this certificate identifies
  "issuer": "Meridian Intermediate CA",       # who issued (signed) it
  "public_key": [17, 2501],                   # [e, n] -- this cert's own public key
  "signature": 1271,                          # issuer's signature over this cert's fields
  "not_before": 1000,                         # validity window, integer "time units"
  "not_after": 9000,
  "revoked": False,
}

A chain is a list of these dicts ordered leaf-first: [leaf, intermediate..., root]. The last entry is claimed to be a root CA certificate (self-signed: its own issuer equals its own subject).

What you implement (in the code editor)

  • compute_digest(cert: dict) -> int, a deterministic, keyless digest of a certificate's identity fields (everything except signature and revoked), used as the thing that actually gets signed. Canonicalize as the string f"{subject}|{issuer}|{public_key[0]}:{public_key[1]}|{not_before}|{not_after}" and reduce it with the rolling hash: python h = 0 for ch in s: h = (h * 131 + ord(ch)) % (2**61 - 1)
  • rsa_sign(digest: int, d: int, n: int) -> int, signature = (digest mod n) ** d mod n.
  • rsa_verify(digest: int, signature: int, e: int, n: int) -> bool, return whether signature ** e mod n == digest mod n.
  • validate_chain(chain: list[dict], trusted_roots: dict[str, list[int]], current_time: int) -> dict, validate the whole chain (see below). trusted_roots maps a trusted root CA's subject name to its known-good [e, n] public key (this is the browser's local trust store, never taken from the chain itself).
  • solve(data: dict) -> dict, blackbox dispatcher (see the Reference section below).

Validation algorithm

Walk the chain from the leaf (index 0) upward. For each certificate cert at index i:

  1. Validity window, if current_time < cert["not_before"] or current_time > cert["not_after"] -> reason "expired".
  2. Revocation, if cert["revoked"] is True -> reason "revoked".
  3. Chain linkage / signer's public key:
  4. If this is not the last certificate in the chain, the next certificate up (chain[i+1]) must be its issuer: cert["issuer"] == chain[i+1]["subject"]. If not -> reason "broken_chain". The public key used to check this cert's signature is chain[i+1]["public_key"].
  5. If this is the last certificate in the chain, it must be a certificate for a root in trusted_roots: cert["subject"] must be a key in trusted_roots, and trusted_roots[cert["subject"]] must equal cert["public_key"] exactly. If either check fails -> reason "untrusted_root". The public key used to check this cert's own (self-)signature is trusted_roots[cert["subject"]].
  6. Signature check, recompute compute_digest(cert) and check rsa_verify(digest, cert["signature"], e, n) using the public key established in step 3. If it fails -> reason "bad_signature".

If every certificate in the chain passes all four checks, the chain is valid -> reason "valid". Stop at the first certificate (starting from the leaf) that fails any check and return that specific reason -- do not keep scanning past a failure.

Input / Output

  • validate_chain(chain, trusted_roots, current_time) -> {"valid": bool, "reason": str} where reason is one of: "valid", "expired", "revoked", "broken_chain", "untrusted_root", "bad_signature".
  • solve(data): data = {"op": "validate", "chain": [...], "trusted_roots": {...}, "current_time": int} -> validate_chain(...)'s return dict directly. data = {"op": "digest", "cert": {...}} -> {"digest": int}.

Examples

validate_chain([leaf, intermediate, root], {"Meridian Root CA": [17, 2773]}, 5000)
  -> {"valid": True, "reason": "valid"}

validate_chain([expired_leaf, intermediate, root], {"Meridian Root CA": [17, 2773]}, 9500)
  -> {"valid": False, "reason": "expired"}

Constraints

  • Deterministic, offline, standard library only. No cryptography, no ssl, no hashlib -- this is a from-scratch textbook-RSA exercise (same style as 5.4.b/5.4.c), not a real X.509 parser.
  • trusted_roots is the only source of truth for which root keys are trusted -- a self-signed certificate whose subject is not in trusted_roots must be rejected as "untrusted_root", even if its self-signature verifies correctly.
  • Must pass all cases in the tests (visible + hidden): a fully valid chain, an expired leaf, a revoked intermediate, a broken issuer/subject link, an untrusted (self-signed but unrecognized) root, and a tampered signature.

Entry points

def compute_digest(cert: dict) -> int

solve() is the blackbox entry point; the other functions are the underlying primitives it is built on and are tested directly as well.

Input

  • compute_digest(cert): cert is a dict with keys subject (str), issuer (str), public_key ([e, n] list of two int), not_before (int), not_after (int). (signature and revoked may also be present but are not part of the digest.)
  • rsa_sign(digest, d, n) / rsa_verify(digest, signature, e, n): all int.
  • validate_chain(chain, trusted_roots, current_time):
  • chain: list[dict], leaf-first, each dict shaped like cert above plus signature (int, the issuer's signature over compute_digest(cert)) and revoked (bool).
  • trusted_roots: dict[str, list[int]] mapping a trusted root CA's subject name to its known [e, n] public key (the local trust store).
  • current_time: int.
  • solve(data): data is a dict with "op" equal to "validate" or "digest".
  • "validate": {"op": "validate", "chain": [...], "trusted_roots": {...}, "current_time": int}
  • "digest": {"op": "digest", "cert": {...}}

Output (result)

  • compute_digest(...) returns an int.
  • rsa_sign(...) returns an int.
  • rsa_verify(...) returns bool.
  • validate_chain(...) returns {"valid": bool, "reason": str}, where reason is one of "valid", "expired", "revoked", "broken_chain", "untrusted_root", "bad_signature".
  • solve(...) returns validate_chain(...)'s dict for op "validate", or {"digest": int} for op "digest".

Guarantees / rules

  • Pure functions, deterministic, no I/O, no network. Standard library only -- no cryptography, ssl, or hashlib; this is a from-scratch textbook-RSA exercise, not a real X.509 parser.
  • compute_digest canonicalizes as f"{subject}|{issuer}|{e}:{n}|{not_before}|{not_after}" and reduces with the rolling hash h = (h * 131 + ord(ch)) % (2**61 - 1) over every character.
  • validate_chain walks the chain leaf-first (index 0) to root (last index) and, for each certificate, checks in this order: validity window, revocation, issuer/subject chain linkage (or trusted-root membership for the last certificate), then signature -- returning the first failure encountered.
  • The public key used to verify a non-root certificate's signature is always the next certificate's public_key, never the certificate's own key. The public key used to verify the root's self-signature is always looked up from trusted_roots, never trusted from the chain data itself.
  • A self-signed certificate whose subject is absent from trusted_roots is "untrusted_root", even if its own signature verifies correctly.

# Reference solution """Reference solution for 5.4.d. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests). Implements X.509-style certificate chain validation directly (no cryptography/ssl libraries), using the small-number textbook-RSA sign/verify math from 5.4.b/5.4.c as the signature primitive. """ from typing import Any _MODULUS = (2 ** 61) - 1 # large Mersenne prime used only to bound the rolling hash def compute_digest(cert: dict) -> int: """Deterministic, keyless digest of a certificate's identity fields (everything except 'signature' and 'revoked' -- those aren't part of what gets signed).""" e, n = cert["public_key"] canonical = f'{cert["subject"]}|{cert["issuer"]}|{e}:{n}|{cert["not_before"]}|{cert["not_after"]}' h = 0 for ch in canonical: h = (h * 131 + ord(ch)) % _MODULUS return h def rsa_sign(digest: int, d: int, n: int) -> int: """signature = (digest mod n) ** d mod n, using the issuer's private exponent d.""" return pow(digest % n, d, n) def rsa_verify(digest: int, signature: int, e: int, n: int) -> bool: """True iff signature ** e mod n recovers digest mod n, using the issuer's public key (e, n).""" return pow(signature, e, n) == digest % n def validate_chain(chain: list, trusted_roots: dict, current_time: int) -> dict: """Validate a leaf-first certificate chain against a local trust store. Walks leaf -> root, checking (in order, per certificate) validity window, revocation, issuer/subject linkage (or trusted-root membership at the top), and signature. Returns the first failure encountered, or {"valid": True, "reason": "valid"} if the whole chain checks out. """ for i, cert in enumerate(chain): if current_time < cert["not_before"] or current_time > cert["not_after"]: return {"valid": False, "reason": "expired"} if cert.get("revoked", False): return {"valid": False, "reason": "revoked"} if i + 1 < len(chain): issuer_cert = chain[i + 1] if cert["issuer"] != issuer_cert["subject"]: return {"valid": False, "reason": "broken_chain"} issuer_pubkey = issuer_cert["public_key"] else: root_key = trusted_roots.get(cert["subject"]) if root_key is None or list(root_key) != list(cert["public_key"]): return {"valid": False, "reason": "untrusted_root"} issuer_pubkey = root_key digest = compute_digest(cert) e, n = issuer_pubkey if not rsa_verify(digest, cert["signature"], e, n): return {"valid": False, "reason": "bad_signature"} return {"valid": True, "reason": "valid"} def solve(data: Any) -> Any: """Blackbox entry point. Dispatches on data['op']: - {"op": "validate", "chain": [...], "trusted_roots": {...}, "current_time": int} -> validate_chain(...)'s result dict - {"op": "digest", "cert": {...}} -> {"digest": int} """ op = data["op"] if op == "validate": return validate_chain(data["chain"], data["trusted_roots"], data["current_time"]) elif op == "digest": return {"digest": compute_digest(data["cert"])} else: raise ValueError(f"unknown op: {op!r}")
