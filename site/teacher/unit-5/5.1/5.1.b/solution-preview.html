<details><summary>Reference: the exact contract</summary>

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def render_comment(username: str, comment: str) -> str

Input

  • username: the commenter's display name (untrusted input).
  • comment: the comment body (untrusted input).

Output

A single HTML string, the comment card:

<div class="c"><b>USERNAME</b>: COMMENT</div>

where USERNAME and COMMENT are the HTML-encoded forms of the two inputs.

Encoding rules

  • User values are HTML-encoded with html.escape(value, quote=True) semantics: & → &amp;, < → &lt;, > → &gt;, " → &quot;, ' → &#x27;.
  • The structural markup the function itself emits (<div class="c">, <b>, </b>, </div>) is real HTML and is not encoded.
  • No detection, stripping, or blocklisting of input. Encoding alone is the defense.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only (html).

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them). user values are encoded rather than concatenated raw.

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
import html def render_comment(username: str, comment: str) -> str: safe_user = html.escape(username, quote=True) safe_comment = html.escape(comment, quote=True) return '<div class="c"><b>' + safe_user + "</b>: " + safe_comment + "</div>"
