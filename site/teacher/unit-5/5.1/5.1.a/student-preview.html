<details><summary>Reference: the exact contract</summary>

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def authenticate(users: list[tuple[str, str, str]], username: str, password: str) -> str | None

Input

  • users: a list of (username, role, password) rows to load into an in-memory table.
  • username, password: the submitted login credentials (untrusted input).

Output

  • The matching user's role (a string) when a row's username AND password both equal the submitted values.
  • None when no row matches, including every injection attempt.

Guarantees / rules

  • Deterministic, no network. Standard library only (sqlite3).
  • The username/password comparison must be performed by a SQL query, using a parameterized statement with ? placeholders and the values bound separately.
  • No input filtering, blocklisting, or Python-side list comparison.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them). the query is parameterized rather than built by string concatenation.

import sqlite3 def authenticate(users, username, password): """ Return the role of the user whose username AND password both match a row, or None if the login fails. VULNERABLE starter: it concatenates user input into the SQL text, so an attacker can inject SQL. Rewrite the query to use parameter placeholders (?) with the values passed separately, so input can never change the query's structure. Do not blocklist input; fix the query itself. """ conn = sqlite3.connect(":memory:") cur = conn.cursor() cur.execute("CREATE TABLE users (username TEXT, role TEXT, password TEXT)") cur.executemany("INSERT INTO users VALUES (?, ?, ?)", users) # --- the injectable part: user input is glued straight into the SQL text --- query = ( "SELECT role FROM users WHERE username = '" + username + "' AND password = '" + password + "'" ) try: cur.execute(query) row = cur.fetchone() except sqlite3.Error: row = None conn.close() return row[0] if row else None

import __main__ as impl USERS = [ ("admin", "administrator", "S3cr3t-Admin-Pw"), ("jordan", "staff", "autumn-maple-31"), ("priya", "staff", "river-stone-77"), ] def test_valid_admin(): assert impl.authenticate(USERS, "admin", "S3cr3t-Admin-Pw") == "administrator" def test_valid_staff(): assert impl.authenticate(USERS, "jordan", "autumn-maple-31") == "staff" def test_wrong_password_rejected(): assert impl.authenticate(USERS, "admin", "not-the-password") is None def test_unknown_user_rejected(): assert impl.authenticate(USERS, "nobody", "whatever") is None def test_comment_truncation_blocked(): assert impl.authenticate(USERS, "admin'--", "anything") is None def test_or_bypass_blocked(): assert impl.authenticate(USERS, "' OR '1'='1", "x") is None def test_or_bypass_with_comment_blocked(): assert impl.authenticate(USERS, "' OR '1'='1'--", "x") is None def test_union_blocked(): assert impl.authenticate(USERS, "' UNION SELECT role FROM users--", "x") is None def test_injection_in_password_blocked(): assert impl.authenticate(USERS, "admin", "' OR '1'='1") is None def test_literal_quote_username(): users = USERS + [("o'brien", "staff", "pw-123")] assert impl.authenticate(users, "o'brien", "pw-123") == "staff" assert impl.authenticate(users, "o'brien", "wrong") is None def test_empty_users(): assert impl.authenticate([], "admin", "x") is None # ---- run every test above ------------------------------------------------ _results = [] for _name, _fn in list(globals().items()): if _name.startswith("test_") and callable(_fn): try: _fn() _results.append((_name, None)) except Exception as _e: _results.append((_name, _e)) for _name, _e in _results: print(("PASS " if _e is None else "FAIL ") + _name + ("" if _e is None else f": {_e!r}")) print(f"{sum(e is None for _, e in _results)}/{len(_results)} tests passed")
