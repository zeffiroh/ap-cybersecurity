1. Brief

The situation. Build the severity scorer a security team's intake triage tool would run on each incoming breach report. Given the categories of data exposed, the number of records affected, and how many days it took to detect the breach, compute a total severity score and a label.

Lesson objective. Explain what a data breach is, identify the categories of data whose exposure causes the most harm, and estimate the severity of a breach from the type of data exposed, the number of records affected, and how quickly it was detected/contained.

What comes in

report: {"categories": list[str], "record_count": int, "days_to_detect": int}

What must come out

{"score": int, "label": str}

<details><summary>Reference: the exact contract</summary>

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def solve(report: dict) -> dict

Input (report)

{"categories": list[str], "record_count": int, "days_to_detect": int}

  • categories: zero or more of {"pii", "financial", "health", "auth_plaintext", "auth_hashed", "email", "public"}. Unknown strings are ignored (contribute 0 points).
  • record_count: non-negative int.
  • days_to_detect: non-negative int.

Output (result)

{"score": int, "label": str} where label is one of "low", "medium", "high", "critical".

Rubric

  • Category points (sum, each category counted once): pii=40, financial=40, health=40, auth_plaintext=40, auth_hashed=15, email=10, public=0, unknown=0.
  • Scale points: <100->0, 100-9999->10, 10000-999999->20, >=1000000->30.
  • Detection points: <=1->0, 2-30->10, >30->20.
  • Label thresholds on total score: >=80->critical, >=50->high, >=20->medium, else low.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Categories with duplicates in the input list are only counted once.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
from typing import Dict CATEGORY_POINTS = { "pii": 40, "financial": 40, "health": 40, "auth_plaintext": 40, "auth_hashed": 15, "email": 10, "public": 0, } def _scale_points(record_count: int) -> int: if record_count >= 1_000_000: return 30 if record_count >= 10_000: return 20 if record_count >= 100: return 10 return 0 def _detect_points(days_to_detect: int) -> int: if days_to_detect > 30: return 20 if days_to_detect >= 2: return 10 return 0 def _label(score: int) -> str: if score >= 80: return "critical" if score >= 50: return "high" if score >= 20: return "medium" return "low" def solve(report: Dict[str, object]) -> Dict[str, object]: categories = report.get("categories", []) record_count = report.get("record_count", 0) days_to_detect = report.get("days_to_detect", 0) score = sum(CATEGORY_POINTS.get(cat, 0) for cat in categories) score += _scale_points(record_count) score += _detect_points(days_to_detect) return {"score": score, "label": _label(score)}
