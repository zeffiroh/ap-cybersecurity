Coding problem, 5.6.c: Attack classifier (evidence -> category)

Skill: Detect Attacks, Collaborate · Maps to: 5.6.B, 5.6.C · Language: Python 3 (pytest)

Problem

Formalize the analyst reasoning process from the lesson: given a bundle of evidence indicators collected during an investigation, score each known attack category by how many of its indicators are present, and return the best-supported classification.

Function contract

Implement solve(indicators: list) -> str in the code editor (see the Reference section below).

Input

indicators: list[str] of evidence tags (may contain duplicates).

Known indicator-to-category mapping

  • "brute-force": multiple_401_responses, single_source_ip, many_usernames_targeted, credential_guessing_pattern
  • "sql-injection": sql_meta_characters_in_request, database_error_in_response, union_select_pattern, unexpected_query_result_size
  • "malware": known_malware_file_hash, unexpected_process_spawned, outbound_c2_connection, persistence_mechanism_installed
  • "phishing": suspicious_email_attachment, credential_harvesting_url, spoofed_sender_domain, user_reported_suspicious_email

Output

str, the category with the most matching indicators (as a set; duplicates don't add extra weight). Ties go to the alphabetically first tied category. "unknown" if nothing matches.

Examples

["multiple_401_responses", "single_source_ip"]  ->  "brute-force"
["server_restarted"]                             ->  "unknown"

Constraints

  • Deterministic, offline, standard library only.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(indicators: list) -> str

Input (indicators)

list[str], evidence tags collected during an investigation. May contain duplicates (treated as a set, duplicates do not increase a category's score).

Known indicator-to-category mapping

  • "brute-force": multiple_401_responses, single_source_ip, many_usernames_targeted, credential_guessing_pattern
  • "sql-injection": sql_meta_characters_in_request, database_error_in_response, union_select_pattern, unexpected_query_result_size
  • "malware": known_malware_file_hash, unexpected_process_spawned, outbound_c2_connection, persistence_mechanism_installed
  • "phishing": suspicious_email_attachment, credential_harvesting_url, spoofed_sender_domain, user_reported_suspicious_email

Output (result)

str, the category name whose known indicators appear most often (as a set) in indicators. Ties are broken by choosing the alphabetically first category among the tied leaders. If no indicator in the input matches any known category, return "unknown".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Indicators outside the known mapping are ignored (they contribute to no category's score).

# Reference solution """Reference solution for 5.6.c. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List # Known indicators per attack category (case-insensitive exact match against evidence tags). _CATEGORY_INDICATORS = { "brute-force": { "multiple_401_responses", "single_source_ip", "many_usernames_targeted", "credential_guessing_pattern", }, "sql-injection": { "sql_meta_characters_in_request", "database_error_in_response", "union_select_pattern", "unexpected_query_result_size", }, "malware": { "known_malware_file_hash", "unexpected_process_spawned", "outbound_c2_connection", "persistence_mechanism_installed", }, "phishing": { "suspicious_email_attachment", "credential_harvesting_url", "spoofed_sender_domain", "user_reported_suspicious_email", }, } def solve(indicators: List[str]) -> str: """Classify an evidence bundle by scoring each category's matching indicator count. Returns the category name with the highest score. Ties are broken by choosing the alphabetically first category among the tied leaders. If no indicator matches any known category, returns "unknown". """ evidence = set(indicators) scores = { category: len(evidence & known_indicators) for category, known_indicators in _CATEGORY_INDICATORS.items() } best_score = max(scores.values()) if best_score == 0: return "unknown" winners = sorted(cat for cat, score in scores.items() if score == best_score) return winners[0]
