1. Brief

The situation. Implement the volume/behavior-based DLP rule described in the lesson: given a list of outbound transfer events, flag the ones that exceed a size threshold AND go to a destination that is not on the organization's approved-destination list, a classic egress-monitoring rule.

Lesson objective. Explain what data loss prevention (DLP) systems detect and why, describe the difference between content-based and volume/behavior-based detection, and evaluate a stream of outbound data-transfer events to flag likely data exfiltration.

What comes in

  • transfers: list[dict], each {"id": str, "bytes_mb": int, "destination": str}.
  • approved_destinations: list[str] of known-good destination names.
  • volume_threshold_mb: int, transfer must exceed this size to be eligible for flagging.

What must come out

Sorted list[str] of flagged transfer ids.

Entry point

def solve(transfers: list, approved_destinations: list, volume_threshold_mb: int) -> list

Input

  • transfers: list[dict], each {"id": str, "bytes_mb": int, "destination": str}. id is unique per transfer.
  • approved_destinations: list[str] of destination names considered safe/sanctioned.
  • volume_threshold_mb: int, a transfer must exceed this size (strictly greater than) to be eligible for flagging.

Output (result)

Sorted list[str] of transfer ids that should be flagged: bytes_mb > volume_threshold_mb AND destination is NOT in approved_destinations.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • The size comparison is strict (>, not >=): a transfer exactly at the threshold is not flagged.
  • An empty approved_destinations list means every destination is treated as unapproved.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
from typing import Dict, List def solve( transfers: List[Dict[str, object]], approved_destinations: List[str], volume_threshold_mb: int, ) -> List[str]: approved = set(approved_destinations) flagged = [ t["id"] for t in transfers if t["bytes_mb"] > volume_threshold_mb and t["destination"] not in approved ] return sorted(flagged)
