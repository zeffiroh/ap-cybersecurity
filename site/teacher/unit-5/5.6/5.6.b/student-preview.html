Coding problem, 5.6.b: DLP egress rule

Skill: Detect Attacks · Maps to: 5.6.B · Language: Python 3 (pytest)

Problem

Implement the volume/behavior-based DLP rule described in the lesson: given a list of outbound transfer events, flag the ones that exceed a size threshold AND go to a destination that is not on the organization's approved-destination list, a classic egress-monitoring rule.

Function contract

Implement solve(transfers: list, approved_destinations: list, volume_threshold_mb: int) -> list in the code editor (see the Reference section below).

Input

  • transfers: list[dict], each {"id": str, "bytes_mb": int, "destination": str}.
  • approved_destinations: list[str] of known-good destination names.
  • volume_threshold_mb: int, transfer must exceed this size to be eligible for flagging.

Output

Sorted list[str] of flagged transfer ids.

Examples

transfers = [{"id":"t1","bytes_mb":500,"destination":"unknown-cloud.example"}]
solve(transfers, ["corp-backup.internal"], volume_threshold_mb=100) -> ["t1"]

transfers = [{"id":"t2","bytes_mb":500,"destination":"corp-backup.internal"}]
solve(transfers, ["corp-backup.internal"], volume_threshold_mb=100) -> []   # approved destination

Constraints

  • Deterministic, offline, standard library only.
  • The size comparison is strict (bytes_mb > volume_threshold_mb).
  • Must pass all cases in the tests (visible + hidden).

Reference

Entry point

def solve(transfers: list, approved_destinations: list, volume_threshold_mb: int) -> list

Input

  • transfers: list[dict], each {"id": str, "bytes_mb": int, "destination": str}. id is unique per transfer.
  • approved_destinations: list[str] of destination names considered safe/sanctioned.
  • volume_threshold_mb: int, a transfer must exceed this size (strictly greater than) to be eligible for flagging.

Output (result)

Sorted list[str] of transfer ids that should be flagged: bytes_mb > volume_threshold_mb AND destination is NOT in approved_destinations.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • The size comparison is strict (>, not >=): a transfer exactly at the threshold is not flagged.
  • An empty approved_destinations list means every destination is treated as unapproved.
