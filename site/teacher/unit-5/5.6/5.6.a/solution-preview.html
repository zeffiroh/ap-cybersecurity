1. Brief

The situation. Implement the SIEM alert rule described in the lesson: given a list of parsed application log entries, return every IP address whose failed-login (401) count exceeds a threshold within a rolling time window, a classic brute-force signal.

Lesson objective. Explain what application logging captures, describe how security teams use log analysis to detect attacks in progress, and identify the key log fields and patterns that signal brute-force, injection, and account-takeover activity.

What comes in

  • entries: list[dict], each {"ip": str, "ts": int, "status": int} (ts = seconds since start of log, not necessarily sorted).
  • threshold: int, minimum number of 401 events within the window to flag the IP.
  • window_seconds: int, rolling window size, in seconds (inclusive on both ends).

What must come out

A sorted, de-duplicated list[str] of flagged IP addresses.

Entry point

def solve(entries: list, threshold: int, window_seconds: int) -> list

Input

  • entries: list[dict], each {"ip": str, "ts": int, "status": int}. ts is seconds since the start of the log (non-negative int, not necessarily sorted). status is an HTTP status code; only 401 entries count toward brute-force detection.
  • threshold: int, minimum number of 401 events within the window to flag the IP.
  • window_seconds: int, inclusive rolling window size, in seconds.

Output (result)

Sorted, de-duplicated list[str] of IP addresses for which some window [start, start + window_seconds] (with start equal to one of that IP's 401 timestamps) contains >= threshold 401 events.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Only entries with status == 401 count; other status codes are ignored for detection.
  • The window bounds are inclusive: an event with ts == start + window_seconds counts.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
from collections import defaultdict from typing import Dict, List def solve(entries: List[Dict[str, object]], threshold: int, window_seconds: int) -> List[str]: by_ip: Dict[str, List[int]] = defaultdict(list) for e in entries: if e.get("status") == 401: by_ip[e["ip"]].append(e["ts"]) flagged = set() for ip, times in by_ip.items(): times = sorted(times) for start in times: count = sum(1 for t in times if start <= t <= start + window_seconds) if count >= threshold: flagged.add(ip) break return sorted(flagged)
