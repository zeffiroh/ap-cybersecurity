Coding problem, 1.3.c: Detect sustained wireless jamming

Skill: Analyze Risk · Maps to: 1.3.B · Language: Python 3 (pytest)

Problem

A wireless intrusion detection system samples the noise floor of a Wi-Fi channel once per second. Each sample is an integer noise measurement (higher = more noise). Your job is to detect whether the sample series contains a sustained jamming event.

Detection rule: a series indicates jamming if it contains a run of at least N = 5 consecutive samples that are ALL strictly greater than T = 80.

These constants are fixed for this problem (see the Reference section below). A single spike, or a short burst of noise below the window, is not considered jamming.

Function contract

Implement solve(samples: list[int]) -> bool in the code editor (see the Reference section below).

Return True if the series contains a sustained jamming event; False otherwise.

Input

A list of integers (noise-floor samples). May be empty. No length limit. Values >= 0.

Output

True (jamming detected) or False (no sustained jamming).

Examples

[20, 25, 90, 22, 30, 18, 24]            -> False  (only one spike; run length 1 < N=5)
[15, 82, 85, 88, 91, 83, 87, 20]        -> True   (positions 1-6 all > 80; run = 6 >= N=5)
[70, 72, 75, 71, 73, 74, 76]            -> False   (none exceed T=80)
[50, 81, 82, 83, 84, 85, 86, 87, 88, 30]-> True   (positions 1-8 all > 80; run = 8 >= N=5)
[]                                       -> False  (empty input)

Constraints

  • T = 80 (strictly greater than), N = 5 (minimum consecutive samples above T).
  • Deterministic, offline, standard library only.
  • Must pass all cases in the tests (visible + hidden).

Reference

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def solve(samples: list[int]) -> bool

Input (samples)

A list of integers, each representing one noise-floor measurement from a wireless monitor. Values are >= 0. The list may be empty.

Output (result)

True if the series contains a sustained jamming event; False otherwise.

Detection rule

Threshold T = 80 (strictly greater than). Minimum consecutive window N = 5.

A series is flagged as jamming if it contains a run of at least N = 5 consecutive samples where every sample in the run is strictly greater than T = 80.

A run is interrupted as soon as any sample is <= T. The run counter resets to zero.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • T and N are fixed constants (T=80, N=5); do not parameterize them.
  • An empty list returns False.

Acceptance

# Reference solution """Reference solution for 1.3.c. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" from typing import List THRESHOLD = 80 # noise floor threshold (strictly greater than) WINDOW = 5 # minimum consecutive samples above threshold to flag jamming def solve(samples: List[int]) -> bool: """Return True if the sample series contains a sustained jamming event. A series contains sustained jamming if it has a run of at least WINDOW consecutive samples each strictly greater than THRESHOLD. """ run = 0 for s in samples: if s > THRESHOLD: run += 1 if run >= WINDOW: return True else: run = 0 return False
