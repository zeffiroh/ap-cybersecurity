1. Brief

The situation. You are building the risk-assessment routine a network-policy tool runs before letting a device connect to a public Wi-Fi network. Given a description of one network and the user's current posture, return the risk flags that apply, so the user (or an administrator) can make an informed decision. This is exactly the three-step personal protocol from the lesson, expressed as code: verify the SSID, avoid open networks, always use a VPN.

The function is pure and deterministic, no network, no I/O.

Lesson objective. Explain what war driving is and why it enables targeted wireless attacks, evaluate a Wi-Fi network against a set of risk criteria, and apply a systematic risk-flagging process to decide whether connecting is safe.

What comes in

network, a dict describing one network and the user's posture toward it. Recognized keys:

Key Type Meaning
"encryption" str Wi-Fi security type, e.g. "open", "wpa2", "wpa3". Case-insensitive. Missing / None / "" is treated as open (worst case).
"verified" bool True if the SSID was confirmed with venue staff / an official source. Missing is treated as False.
"vpn" bool True if a VPN tunnel is active on the device. Missing is treated as False.

Example:

{"ssid": "AirportFreeWifi", "encryption": "open", "verified": False, "vpn": False}

What must come out

A sorted, de-duplicated list[str] of the risk flags that apply, drawn from:

  • "open-network": the network is open (no Wi-Fi-layer encryption).
  • "unverified-ssid": the SSID has not been confirmed with an authoritative source.
  • "no-vpn": no VPN is protecting the user's traffic.

Return [] when none apply (a verified, encrypted network used over a VPN).

Entry point

def solve(network: dict) -> list[str]

Input (network)

A dict describing one Wi-Fi network and the user's posture toward it. Recognized keys (any may be absent; extra keys such as "ssid" are ignored):

  • "encryption": str, Wi-Fi security type ("open", "wpa2", "wpa3"...). Compared case-insensitively. Missing, None, or "" counts as open.
  • "verified": bool, True if the SSID was confirmed with an authoritative source. Missing counts as False.
  • "vpn": bool, True if a VPN tunnel is active. Missing counts as False.

Output (result)

A sorted, de-duplicated list[str] drawn from {"no-vpn", "open-network", "unverified-ssid"}. Empty list if no risk applies.

Risk rules

  • open-network: encryption, lowercased, is one of {"open", "none", ""} (or the key is absent / None). Encrypted types (wpa, wpa2, wpa3, anything else non-empty) do not flag.
  • unverified-ssid: verified is not truthy.
  • no-vpn: vpn is not truthy.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • encryption matching is case-insensitive.
  • Output always sorted ascending and de-duplicated.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
from typing import List OPEN_VALUES = {"open", "none", ""} def solve(network: dict) -> List[str]: network = network or {} flags = set() encryption = network.get("encryption") if encryption is None or str(encryption).strip().lower() in OPEN_VALUES: flags.add("open-network") if not network.get("verified", False): flags.add("unverified-ssid") if not network.get("vpn", False): flags.add("no-vpn") return sorted(flags)
