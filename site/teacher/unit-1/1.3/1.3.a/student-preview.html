Coding problem, 1.3.a: Classify adversary skill tier

Skill: Analyze Risk · Maps to: 1.3.A · Language: Python 3 (pytest)

Problem

Security analysts use observable attacker behaviors to infer capability level. Given a profile of an adversary's tools and behaviors, classify them as either a low-skilled or high-skilled threat actor.

Function contract

Implement solve(adversary: dict) -> str in the code editor (see the Reference section below). Return "low" or "high" based on the classification rules defined in the Reference section below.

Input

A dict with exactly these boolean keys: - uses_zero_day, exploits an unpublished vulnerability - custom_tooling, writes or substantially modifies their own tools - targets_specific_victim, selects a specific high-value target - off_the_shelf_only, relies solely on public tools without modification - adapts_to_defenses, changes tactics when initial attempts fail

Output

The string "low" or "high".

Classification rules (from the Reference section below)

  1. If uses_zero_day OR custom_tooling -> "high"
  2. If targets_specific_victim AND adapts_to_defenses -> "high"
  3. Otherwise -> "low"

Examples

 "off_the_shelf_only": False, "adapts_to_defenses": False}  ->  "high"

{"uses_zero_day": False, "custom_tooling": False, "targets_specific_victim": False,
 "off_the_shelf_only": True,  "adapts_to_defenses": False}  ->  "low"

{"uses_zero_day": False, "custom_tooling": False, "targets_specific_victim": True,
 "off_the_shelf_only": False, "adapts_to_defenses": True}   ->  "high"

Entry point

def solve(adversary: dict) -> str

Input (adversary)

A dict describing one adversary. Keys and types:

Key Type Description
uses_zero_day bool Does the adversary exploit an unpublished vulnerability?
custom_tooling bool Does the adversary write or substantially modify their own tools?
targets_specific_victim bool Does the adversary select a specific high-value target?
off_the_shelf_only bool Does the adversary rely solely on public tools without modification?
adapts_to_defenses bool Does the adversary change tactics when initial attempts fail?

All five keys are always present and are booleans.

Output (result)

A single string: either "low" or "high".

Classification rules (deterministic)

Apply in order; first matching rule wins:

  1. If uses_zero_day is True OR custom_tooling is True -> return "high".
  2. If targets_specific_victim is True AND adapts_to_defenses is True -> return "high".
  3. Otherwise -> return "low".

Rationale: zero-day capability and custom tooling are unambiguous high-skill markers. An adversary that both selects specific targets AND adapts to defenses exhibits sustained, directed capability that also places them in the high tier.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Input dict always contains exactly the five keys listed above.
  • Output is always exactly the string "low" or "high" (lowercase).
