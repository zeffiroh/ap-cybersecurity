1. Brief

The situation. A wireless scanner returns a list of detected access points. Each AP is a dict with keys: - ssid (str), the human-readable network name - bssid (str), the hardware MAC address of the radio (normalized to uppercase) - security (str), one of "OPEN", "WEP", "WPA", "WPA2", "WPA3" - signal (int), received signal strength in dBm (negative; stronger = closer to 0)

An AP is suspicious (potential evil twin) if ANY of the following holds:

  1. Duplicate SSID / multiple BSSIDs, the same SSID is being broadcast by more than one BSSID in the scan. Every BSSID in such a group is flagged.
  2. Security downgrade, an SSID appears with at least two different security levels and the AP in question does not have the strongest security level seen for that SSID. Those weaker entries are flagged.

Rules combine: an AP is flagged if either condition is true for it.

Lesson objective. Explain how an evil twin attack works at the network level, identify the indicators that reveal a rogue access point in a wireless scan, and apply those indicators to detect one programmatically.

What comes in

A list of dicts, each with keys ssid, bssid, security, signal. The list may be empty. BSSIDs are already uppercase.

What must come out

A sorted list of BSSIDs (strings) that are suspicious. Empty list if none.

Entry point

def solve(aps: list[dict]) -> list[str]

Input (aps)

A list of access-point dicts. Each dict has exactly these keys: - ssid (str), human-readable network name - bssid (str), hardware MAC address, uppercase, colon-separated (e.g. "AA:BB:CC:11:22:33") - security (str), one of "OPEN", "WEP", "WPA", "WPA2", "WPA3" - signal (int), dBm (negative integer; e.g. -55)

Output (result)

A sorted, de-duplicated list[str] of suspicious BSSIDs. Empty list if no anomaly.

Detection rules (both are OR-combined per AP)

  1. Duplicate SSID: an SSID appears with more than one distinct BSSID in the scan. All BSSIDs for that SSID are flagged.
  2. Security downgrade: an SSID appears with multiple security levels. Any AP for that SSID whose security level is not the maximum (strongest) for that SSID is flagged.

Security strength order (weakest to strongest): OPEN < WEP < WPA < WPA2 < WPA3

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • BSSIDs in input are already uppercase.
  • Output is always sorted ascending and de-duplicated.

Acceptance

from typing import List _SEC_ORDER = ["OPEN", "WEP", "WPA", "WPA2", "WPA3"] def _sec_rank(sec: str) -> int: try: return _SEC_ORDER.index(sec.upper()) except ValueError: return -1 def solve(aps: List[dict]) -> List[str]: if not aps: return [] from collections import defaultdict ssid_entries = defaultdict(list) for ap in aps: ssid_entries[ap["ssid"]].append((ap["bssid"], ap["security"])) suspicious = set() for ssid, entries in ssid_entries.items(): bssids = [e[0] for e in entries] secs = [e[1] for e in entries] if len(set(bssids)) > 1: suspicious.update(bssids) ranks = [_sec_rank(s) for s in secs] max_rank = max(ranks) if len(set(ranks)) > 1: for bssid, rank in zip(bssids, ranks): if rank < max_rank: suspicious.add(bssid) return sorted(suspicious)
