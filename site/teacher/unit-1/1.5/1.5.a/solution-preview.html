1. Brief

The situation. Build the rule-engine core of an AI-assisted configuration auditor. Given a list of configuration file lines (as a real tool would read from /etc/ssh/sshd_config or a service config), return the sorted set of security finding tags for every insecure directive detected. This mirrors exactly what tools like Lynis and OpenSCAP do at their rule-evaluation layer.

Lesson objective. Describe how AI-assisted tools audit security configuration files for common misconfigurations, identify specific insecure settings in a sample config, and explain why automated review catches issues that manual checklists often miss.

What comes in

A list[str], each element one line from a config file. Lines may be blank, start with # (comments), or contain leading/trailing whitespace. Matching is case-insensitive.

Example input:

[
    "# sshd_config for web01",
    "Port 22",
    "PermitRootLogin yes",
    "PasswordAuthentication yes",
    "X11Forwarding yes",
    "",
]

What must come out

A sorted list[str] of finding tags. Tags are drawn from: - "insecure:PermitRootLogin" - "insecure:PasswordAuthentication" - "insecure:Port23" - "insecure:SSLDisabled" - "insecure:X11Forwarding" - "insecure:PermitEmptyPasswords"

<details><summary>Reference: the exact contract</summary>

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def solve(config_lines: list[str]) -> list[str]

Input (config_lines)

A list of strings, each representing one line of a configuration file (e.g., SSH sshd_config or a generic service config). Lines may include whitespace, inline comments, or blank lines. Matching is case-insensitive and strips leading/trailing whitespace per line.

Output (result)

A sorted, de-duplicated list[str] of finding tags drawn from the set below. Return an empty list if no insecure settings are found.

Rule set (case-insensitive substring match on each stripped line)

Tag returned Trigger substring(s) Why it is insecure
"insecure:PermitRootLogin" permitrootlogin yes Allows direct root login over SSH
"insecure:PasswordAuthentication" passwordauthentication yes Enables brute-force password attacks
"insecure:Port23" port 23 Port 23 = Telnet; cleartext credentials
"insecure:SSLDisabled" ssl false OR ssl off OR tls false OR tls off Disables transport encryption
"insecure:X11Forwarding" x11forwarding yes Unnecessary attack surface
"insecure:PermitEmptyPasswords" permitemptypasswords yes Allows accounts with no password

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Matching is case-insensitive. Output always sorted ascending (lexicographic) and de-duplicated.
  • A single line may trigger at most one rule (rules are mutually exclusive by tag).
  • Blank lines and lines whose stripped form starts with # are ignored.
  • A config_lines value of [] returns [].

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

from typing import List RULES = [ ("insecure:PermitRootLogin", ["permitrootlogin yes"]), ("insecure:PasswordAuthentication", ["passwordauthentication yes"]), ("insecure:Port23", ["port 23"]), ("insecure:SSLDisabled", ["ssl false", "ssl off", "tls false", "tls off"]), ("insecure:X11Forwarding", ["x11forwarding yes"]), ("insecure:PermitEmptyPasswords", ["permitemptypasswords yes"]), ] def solve(config_lines: List[str]) -> List[str]: findings = set() for raw in config_lines: line = raw.strip() if not line or line.startswith("#"): continue low = line.lower() for tag, triggers in RULES: if any(t in low for t in triggers): findings.add(tag) return sorted(findings)
