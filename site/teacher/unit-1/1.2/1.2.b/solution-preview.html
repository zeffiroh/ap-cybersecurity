1. Brief

The situation. Build the password-weakness checker an authentication backend would use to give users actionable feedback when they choose a new password. Given a password string, return a report dict identifying whether the password is weak and which specific rules it violates.

Lesson objective. Evaluate a password against the core weakness criteria (length, dictionary membership, character variety, and sequential/repeated patterns) and explain how adversaries build and use wordlists to attack weak passwords.

What comes in

A single string, the candidate password. May be empty.

What must come out

A dict with exactly two keys: - "weak" (bool), True if the password fails ANY rule; False only if it passes all rules. - "reasons" (list[str]), sorted list of rule-labels for each rule the password fails. Empty list if the password passes all rules.

Possible reason labels (exact strings, lowercase): - "too_short": length < 12 characters - "in_dictionary": password (lowercased) is in the built-in common wordlist - "only_lowercase": contains no uppercase letters, digits, or non-alphabetic characters - "sequential_or_repeated": contains a sequential run of 3+ characters (e.g. abc, 123, xyz) OR a repeated run of 3+ identical characters (e.g. aaa, 111)

<details><summary>Reference: the exact contract</summary>

Entry point

def solve(password: str) -> dict

Input (password)

A single str, the candidate password. May be empty or contain any Unicode.

Output (result)

A dict with exactly these keys: - "weak" (bool), True if any rule below is triggered; False if all rules pass. - "reasons" (list[str]), sorted list of triggered rule labels (see below). Empty if no rules triggered.

Rules (all must be checked; collect all failures)

Rule 1: "too_short"

Triggered when len(password) < 12.

Rule 2: "in_dictionary"

Triggered when password.lower() is a member of the COMMON_WORDS set below.

COMMON_WORDS = {
    "password", "password1", "password123", "123456", "123456789", "12345678",
    "qwerty", "qwerty123", "letmein", "iloveyou", "admin", "welcome",
    "monkey", "dragon", "master", "abc123", "sunshine", "princess",
    "shadow", "superman", "football", "baseball", "login", "passw0rd",
    "pa$$word", "access", "mustang", "1234567890", "starwars", "hello",
}
Rule 3: "only_lowercase"

Triggered when the password contains ONLY lowercase ASCII letters (a-z), i.e., password.isalpha() and password == password.lower(). Note: an empty string does NOT trigger this rule (it has no lowercase letters either).

Rule 4: "sequential_or_repeated"

Triggered when the password contains: - A run of 3 or more consecutive ASCII characters in ascending order (e.g. abc, bcd, xyz, 123, 234, 789), OR - A run of 3 or more identical characters (e.g. aaa, 111, )

Detection algorithm: For each window of 3 consecutive characters at position i: - Repeated: c[i] == c[i+1] == c[i+2] - Sequential ascending: ord(c[i+1]) - ord(c[i]) == 1 AND ord(c[i+2]) - ord(c[i+1]) == 1

If any window matches either condition, the rule is triggered.

Output contract

  • "reasons" is always sorted ascending (alphabetical order of the label strings).
  • "weak" equals len(reasons) > 0.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • The COMMON_WORDS set above is the exact set used by tests.

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

COMMON_WORDS = { "password", "password1", "password123", "123456", "123456789", "12345678", "qwerty", "qwerty123", "letmein", "iloveyou", "admin", "welcome", "monkey", "dragon", "master", "abc123", "sunshine", "princess", "shadow", "superman", "football", "baseball", "login", "passw0rd", "pa$$word", "access", "mustang", "1234567890", "starwars", "hello", } def solve(password: str) -> dict: reasons = [] if len(password) < 12: reasons.append("too_short") if password.lower() in COMMON_WORDS: reasons.append("in_dictionary") if password and password.isalpha() and password == password.lower(): reasons.append("only_lowercase") triggered = False for i in range(len(password) - 2): a, b, c = password[i], password[i + 1], password[i + 2] oa, ob, oc = ord(a), ord(b), ord(c) if a == b == c: triggered = True break if ob - oa == 1 and oc - ob == 1: triggered = True break if triggered: reasons.append("sequential_or_repeated") reasons.sort() return {"weak": len(reasons) > 0, "reasons": reasons}
