1. Brief

The situation. Build the detector a login-monitoring system would use. Given a list of authentication events, return every username that has five or more failed login attempts within any 60-second window.

This is the core algorithm behind real intrusion-detection rules (e.g., fail2ban's default policy). The defender's goal is to catch automated password-guessing tools before they succeed.

Lesson objective. Read an authentication log, identify the three key signals of a password attack (repeated failed attempts, logins at anomalous times, and access from unknown devices), and write a rule that flags brute-force attempts automatically.

What comes in

A list of event dicts. Each dict has: - ts (int), Unix timestamp in seconds of the login attempt - user (str), the username targeted - ok (bool), True if the login succeeded, False if it failed

Events may arrive in any order (do not assume sorted by timestamp).

What must come out

A sorted list[str] of unique usernames that triggered the brute-force threshold: 5 or more failed logins (where ok == False) within any 60-second window. A window is valid when max_ts - min_ts < 60 (strict less-than, so exactly 60 is NOT within the window). Successes are ignored for counting purposes.

Entry point

def solve(events: list[dict]) -> list[str]

Input (events)

A list[dict]. Each dict is one authentication event with exactly these keys: - ts (int), Unix timestamp in whole seconds - user (str), username targeted by the attempt - ok (bool), True = login succeeded, False = login failed

The list may be empty. Events may appear in any order (unsorted by timestamp).

Output (result)

A sorted, de-duplicated list[str] of usernames that are flagged as brute-force targets.

Detection rule (precise)

A username is flagged if and only if there exist at least 5 events for that user where: 1. ok == False (failed logins only; successes do NOT count toward the threshold) 2. max(ts) - min(ts) < 60 across those 5 (or more) events (strict less-than; the window is open on the right, spans of exactly 60 seconds are NOT within the window)

Algorithm: for each username, collect all timestamps where ok == False, sort them, then use a sliding window: for each position i, check if ts[i+4] - ts[i] < 60; if so, flag the user.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Output always sorted ascending and de-duplicated.
  • Empty input returns [].

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

from collections import defaultdict from typing import List, Dict, Any def solve(events: List[Dict[str, Any]]) -> List[str]: failures: Dict[str, List[int]] = defaultdict(list) for ev in events: if not ev.get("ok", True): failures[ev["user"]].append(ev["ts"]) flagged = set() for user, timestamps in failures.items(): timestamps.sort() for i in range(len(timestamps) - 4): if timestamps[i + 4] - timestamps[i] < 60: flagged.add(user) break return sorted(flagged)
