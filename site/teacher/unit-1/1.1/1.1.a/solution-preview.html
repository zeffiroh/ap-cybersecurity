1. Brief

The situation. Build the detector a phishing-awareness tool would use. Given the raw text of a message, return which of the four psychological pressure tactics it employs:

  • "urgency": manufactured time pressure
  • "authority": borrowed legitimacy (boss, IT, government, bank)
  • "scarcity": limited availability / fear of missing out
  • "intimidation": threats / fear

A message may use zero, one, or several tactics.

Lesson objective. Identify the four core psychological pressure tactics in a social-engineering message and explain why each one lowers a victim's guard.

What comes in

A single string, the message body (and/or subject) to analyze.

What must come out

A sorted list of unique tactic labels from the set above (empty list if none).

from typing import List INDICATORS = { "urgency": [ "urgent", "act now", "immediately", "right now", "asap", "expires", "within 24 hours", "24 hours", "as soon as possible", "don't delay", "do not delay", ], "authority": [ "it department", "ceo", "manager", "administrator", "irs", "bank", "police", "official", "help desk", "human resources", "hr department", ], "scarcity": [ "limited", "only", "last chance", "running out", "few left", "exclusive", "while supplies last", "act fast", ], "intimidation": [ "legal action", "account suspended", "account will be locked", "penalty", "arrested", "fired", "terminated", "lawsuit", "consequences", "reported", ], } def solve(text: str) -> List[str]: low = (text or "").lower() found = {tactic for tactic, phrases in INDICATORS.items() if any(p in low for p in phrases)} return sorted(found)
