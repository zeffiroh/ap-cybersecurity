Antivirus and endpoint protection

Unit 4 · Securing Devices · 4.3 Endpoint Hardening Controls

Before class today. Even on a fully hardened device, users must interact with files, websites, and external media. This interaction introduces the risk of malware, malicious software designed to disrupt, damage, or gain unauthorized access to a computer system. To mitigate this risk, security teams deploy antivirus and endpoint protection systems.

The intuition to hold onto: The frame to hold going in: a hardened device still has to let users open files, click links, and plug in that USB drive from the front office, hardening shrinks the target, it doesn't eliminate the need for something to be watching what happens after a user interacts with something risky. That's the job endpoint protection exists to do, and the single most important idea in this skill is the shift from asking "does this file match something bad I've already seen" to asking "is this program currently doing something a legitimate program wouldn't do."

A myth worth busting before we start: "Having an antivirus means I don't need a firewall." → Antivirus blocks malicious files and code execution, whereas a firewall regulates network traffic. You need both to protect against different attack vectors.
