Coding problem, 4.3.b: Endpoint Detection Engine

Skill: Mitigate Risk · Maps to: 4.3.B · Language: Python 3 (pytest)

Problem

Endpoint Protection Platforms (EPP) use a mixture of signature detection (known hashes) and behavioral heuristics (actions taken by the process, such as excessive file updates or network socket connections) to identify and suspend threats.

You are tasked with writing a process-auditing rule engine solve(data). The engine evaluates a list of running processes against: 1. A database of known malicious file hashes (signatures). 2. Max thresholds on process behavior: max_file_modifications and max_network_connections.

The function must return a list of PIDs of all processes that violate any of these rules.

Function contract

Implement solve(data) in the code editor (see the Reference section below).

Input

A dictionary containing security signatures, behavioral thresholds, and a list of active processes:

{
  "signatures": ["d41d8cd98f00b204e9800998ecf8427e", "098f6bcd4621d373cade4e832627b4f6"],
  "behavioral_rules": {
    "max_file_modifications": 10,
    "max_network_connections": 5
  },
  "processes": [
    {
      "pid": 101,
      "name": "backup_agent.exe",
      "hash": "81dc9bdb52d04dc20036dbd8313ed055",
      "file_modifications": 8,
      "network_connections": 2
    },
    {
      "pid": 102,
      "name": "ransomware.exe",
      "hash": "d41d8cd98f00b204e9800998ecf8427e",
      "file_modifications": 2,
      "network_connections": 0
    },
    {
      "pid": 103,
      "name": "spam_sender.exe",
      "hash": "1f10c9aa0090ff91e90ff8a8bc8a9bcf",
      "file_modifications": 1,
      "network_connections": 12
    }
  ]
}

Output

A list of integers representing the PIDs of flagged processes, sorted in ascending order. For the example input above:

[102, 103]

(Explanation: PID 102 matches a known signature; PID 103 exceeds the network connections threshold)

Constraints

  • Signature matching is case-insensitive (e.g., "A1B2" matches "a1b2").
  • Behavioral violations occur when a metric is strictly greater than the threshold (i.e. file_modifications > max_file_modifications).
  • Standard library only.

Reference

Any implementation that satisfies this interface can be swapped in (reference, student, or composite) and must pass the tests unchanged.

Entry point

def solve(data: dict) -> list[int]

Input (data)

A dictionary containing: - "signatures": list of strings (MD5 hashes of known malware) - "behavioral_rules": dict with keys: - "max_file_modifications" (int) - "max_network_connections" (int) - "processes": list of dicts, where each dict has: - "pid" (int) - "name" (string) - "hash" (string) - "file_modifications" (int) - "network_connections" (int)

Output (result)

A list of integers representing the PIDs of flagged processes. A process is flagged if: 1. Its hash is in the "signatures" list. 2. Its "file_modifications" is strictly greater than "max_file_modifications". 3. Its "network_connections" is strictly greater than "max_network_connections".

The output list of PIDs must be sorted in ascending order. If no processes are flagged, returns [].

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only.
  • Case-insensitivity: MD5 hash comparisons should be case-insensitive (e.g., "A1B2" matches "a1b2").

Acceptance

Your code passes when every test below shows a checkmark (some are hidden until you run them).

# Reference solution """Reference solution for 4.3.b. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" def solve(data: dict) -> list: """Flag processes that match a known-malware signature or exceed behavioral thresholds. Args: data: dict with keys "signatures" (list[str]), "behavioral_rules" (dict with "max_file_modifications" and "max_network_connections"), and "processes" (list of dicts with pid, name, hash, file_modifications, network_connections). Returns: Sorted list of PIDs (int) for every process that matches a signature or exceeds a behavioral threshold. """ signatures = {s.lower() for s in data.get("signatures", [])} rules = data.get("behavioral_rules", {}) max_files = rules.get("max_file_modifications", 0) max_net = rules.get("max_network_connections", 0) flagged = set() for proc in data.get("processes", []): pid = proc["pid"] if proc.get("hash", "").lower() in signatures: flagged.add(pid) continue if proc.get("file_modifications", 0) > max_files: flagged.add(pid) continue if proc.get("network_connections", 0) > max_net: flagged.add(pid) continue return sorted(flagged)
