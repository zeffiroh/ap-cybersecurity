1. Brief

The situation. A patch-management team needs to triage a queue of pending vulnerabilities and decide how urgently each must be addressed. Each vulnerability has a CVSS severity score, a flag for whether it is being actively exploited in the wild, a flag for whether the affected asset is internet-facing, and a flag for whether the affected software is end-of-life (no patch will ever be released). Build the triage engine that assigns one urgency label to each vulnerability.

Lesson objective. Explain why unpatched software is a top attack vector, describe how the vulnerability-disclosure-to-exploit timeline works, and prioritize which patches an organization should deploy first using severity, exploitation status, and exposure.

What comes in

A list of dicts, each with keys: id (str), cvss (float, 0.0-10.0), exploited_in_wild (bool), internet_facing (bool), end_of_life (bool).

What must come out

A list of dicts, one per input vulnerability (same order as input), each with keys id (str, copied from input) and urgency (str), where urgency is one of: "emergency", "scheduled", "routine", "compensate".

Output (result)

A list of dicts, same length and same order as the input, each with: - "id": the same id string from the corresponding input entry - "urgency": one of "emergency", "scheduled", "routine", "compensate"

Decision rule (exact priority order, evaluate top to bottom per vulnerability, return on

first match) 1. If end_of_life is True → "compensate". This overrides everything else, no CVSS score or exploitation status changes this, because patching an end-of-life product is not possible. 2. Else if exploited_in_wild is True and internet_facing is True → "emergency". 3. Else if cvss >= 9.0 and internet_facing is True → "emergency". 4. Else if cvss >= 9.0 → "scheduled". 5. Else if cvss >= 7.0 and internet_facing is True → "scheduled". 6. Else → "routine".

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.

  • CVSS thresholds are inclusive (>=), not strict.
  • Input order is preserved in the output.
