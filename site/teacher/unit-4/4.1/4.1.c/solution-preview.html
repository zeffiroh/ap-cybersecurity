Coding problem, 4.1.c: Audit an IoT device for its dominant vulnerability

Skill: Analyze Risk · Maps to: 4.1.A, 4.1.C · Language: Python 3 (pytest)

Problem

A security analyst is auditing smart devices on a network. Each device is described by a dictionary of attributes. Build the classifier that inspects a device and returns its single most severe vulnerability category, or "secure" if none of the checked issues are present.

A device can technically have more than one issue at once; when it does, report only the most severe one, using this fixed priority order (highest severity first):

  1. "default_credentials", the device still uses its factory default password
  2. "outdated_firmware", the device's firmware is out of date
  3. "exposed_port", the device has an insecure management port open (23 = Telnet, 21 = FTP)
  4. "unauthenticated_api", the device's API accepts requests with no authentication
  5. "unencrypted_traffic", the device's network traffic is not encrypted
  6. "secure", none of the above apply

Function contract

Implement solve(device: dict) -> str in the code editor (see the Reference section below). Return the single verdict label string.

Input

A dictionary with the following keys: - default_password (bool), True if the factory default password is still in use - firmware_outdated (bool), True if the firmware is out of date - open_ports (list[int]), list of open network ports on the device - unauthenticated_api (bool), True if the device's API requires no authentication - encrypted_traffic (bool), True if the device's traffic is encrypted (note: False means traffic is UNencrypted, which is the risk condition)

An insecure management port is any of 23 (Telnet) or 21 (FTP) appearing in open_ports.

Output

One of: "default_credentials", "outdated_firmware", "exposed_port", "unauthenticated_api", "unencrypted_traffic", "secure".

Examples

{"default_password": True, "firmware_outdated": True, "open_ports": [23], "unauthenticated_api": True, "encrypted_traffic": False}  ->  "default_credentials"
{"default_password": False, "firmware_outdated": True, "open_ports": [443], "unauthenticated_api": False, "encrypted_traffic": True}  ->  "outdated_firmware"
{"default_password": False, "firmware_outdated": False, "open_ports": [23, 443], "unauthenticated_api": False, "encrypted_traffic": True}  ->  "exposed_port"
{"default_password": False, "firmware_outdated": False, "open_ports": [443], "unauthenticated_api": True, "encrypted_traffic": True}  ->  "unauthenticated_api"
{"default_password": False, "firmware_outdated": False, "open_ports": [443], "unauthenticated_api": False, "encrypted_traffic": False}  ->  "unencrypted_traffic"
{"default_password": False, "firmware_outdated": False, "open_ports": [443], "unauthenticated_api": False, "encrypted_traffic": True}  ->  "secure"

Constraints

  • Deterministic, offline, standard library only.
  • Priority order is fixed as listed above and must be applied exactly.
  • Only ports 23 and 21 count as insecure/exposed management ports.
  • Exactly one label returned (string, not list).
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(device: dict) -> str

Input (device)

A dictionary with keys: - default_password (bool), True if the factory default password is still in use. - firmware_outdated (bool), True if the firmware is out of date. - open_ports (list[int]), open network ports on the device. - unauthenticated_api (bool), True if the device's API requires no authentication. - encrypted_traffic (bool), True if the device's traffic is encrypted (False = the risk condition: traffic is unencrypted).

Insecure/exposed management ports: {23, 21} (Telnet, FTP). Any other port does not count as "exposed" for this problem.

Output (result)

Exactly one string from: {"default_credentials", "outdated_firmware", "exposed_port", "unauthenticated_api", "unencrypted_traffic", "secure"}

Priority order (highest severity first)

When a device matches more than one condition, return only the highest-priority match: 1. default_password is True -> "default_credentials" 2. firmware_outdated is True -> "outdated_firmware" 3. any of {23, 21} present in open_ports -> "exposed_port" 4. unauthenticated_api is True -> "unauthenticated_api" 5. encrypted_traffic is False -> "unencrypted_traffic" 6. none of the above -> "secure"

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • open_ports may be empty or contain any integers; only 23 and 21 trigger "exposed_port".
  • Missing keys should be treated as the "safe" default for that key (False for booleans, [] for open_ports, and True for encrypted_traffic, i.e. "assume secure/encrypted if not specified").
  • Returns a single string (not a list).

Args: device: dict with keys default_password (bool), firmware_outdated (bool), open_ports (list[int]), unauthenticated_api (bool), encrypted_traffic (bool). Missing keys default to the "safe" value for that key. Returns: One of: "default_credentials", "outdated_firmware", "exposed_port", "unauthenticated_api", "unencrypted_traffic", "secure". """ if not isinstance(device, dict): return "secure" default_password = bool(device.get("default_password", False)) firmware_outdated = bool(device.get("firmware_outdated", False)) open_ports = device.get("open_ports", []) or [] unauthenticated_api = bool(device.get("unauthenticated_api", False)) encrypted_traffic = bool(device.get("encrypted_traffic", True)) # Priority order: default_credentials > outdated_firmware > exposed_port > # unauthenticated_api > unencrypted_traffic > secure if default_password: return "default_credentials" if firmware_outdated: return "outdated_firmware" if any(port in INSECURE_PORTS for port in open_ports): return "exposed_port" if unauthenticated_api: return "unauthenticated_api" if not encrypted_traffic: return "unencrypted_traffic" return "secure"
