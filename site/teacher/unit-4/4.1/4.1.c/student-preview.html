1. Brief

The situation. A security analyst is auditing smart devices on a network. Each device is described by a dictionary of attributes. Build the classifier that inspects a device and returns its single most severe vulnerability category, or "secure" if none of the checked issues are present.

A device can technically have more than one issue at once; when it does, report only the most severe one, using this fixed priority order (highest severity first):

  1. "default_credentials", the device still uses its factory default password
  2. "outdated_firmware", the device's firmware is out of date
  3. "exposed_port", the device has an insecure management port open (23 = Telnet, 21 = FTP)
  4. "unauthenticated_api", the device's API accepts requests with no authentication
  5. "unencrypted_traffic", the device's network traffic is not encrypted
  6. "secure", none of the above apply

Lesson objective. Explain why Internet of Things (IoT) devices carry unusually high risk, identify the specific vulnerability categories that make them easy targets, and classify a described smart device by its dominant weakness.

What comes in

A dictionary with the following keys: - default_password (bool), True if the factory default password is still in use - firmware_outdated (bool), True if the firmware is out of date - open_ports (list[int]), list of open network ports on the device - unauthenticated_api (bool), True if the device's API requires no authentication - encrypted_traffic (bool), True if the device's traffic is encrypted (note: False means traffic is UNencrypted, which is the risk condition)

An insecure management port is any of 23 (Telnet) or 21 (FTP) appearing in open_ports.

What must come out

One of: "default_credentials", "outdated_firmware", "exposed_port", "unauthenticated_api", "unencrypted_traffic", "secure".

Entry point

def solve(device: dict) -> str

Input (device)

A dictionary with keys: - default_password (bool), True if the factory default password is still in use. - firmware_outdated (bool), True if the firmware is out of date. - open_ports (list[int]), open network ports on the device. - unauthenticated_api (bool), True if the device's API requires no authentication. - encrypted_traffic (bool), True if the device's traffic is encrypted (False = the risk condition: traffic is unencrypted).

Insecure/exposed management ports: {23, 21} (Telnet, FTP). Any other port does not count as "exposed" for this problem.

Output (result)

Exactly one string from: {"default_credentials", "outdated_firmware", "exposed_port", "unauthenticated_api", "unencrypted_traffic", "secure"}

Priority order (highest severity first)

When a device matches more than one condition, return only the highest-priority match: 1. default_password is True -> "default_credentials" 2. firmware_outdated is True -> "outdated_firmware" 3. any of {23, 21} present in open_ports -> "exposed_port" 4. unauthenticated_api is True -> "unauthenticated_api" 5. encrypted_traffic is False -> "unencrypted_traffic" 6. none of the above -> "secure"

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • open_ports may be empty or contain any integers; only 23 and 21 trigger "exposed_port".
  • Missing keys should be treated as the "safe" default for that key (False for booleans, [] for open_ports, and True for encrypted_traffic, i.e. "assume secure/encrypted if not specified").
  • Returns a single string (not a list).
