1. Brief

The situation. A security analyst receives short incident-report strings that describe observed device behavior. Build the classifier that maps each description to the correct malware category.

Categories: - "virus": attaches to host files; spreads when files are shared or opened - "worm": self-propagates across the network without user action; autonomous scanning - "trojan": disguised as legitimate software; creates backdoor / exfiltrates data - "ransomware": encrypts files; demands payment for decryption key

A report may match exactly one category. If no category matches, return "unknown".

Lesson objective. Identify the four major malware categories, viruses, worms, trojans, and ransomware, describe how each spreads and causes harm, and classify a described infection by its behavioral signature.

What comes in

A single string describing observed behavior on a device or network.

What must come out

One of: "virus", "worm", "trojan", "ransomware", "unknown".
