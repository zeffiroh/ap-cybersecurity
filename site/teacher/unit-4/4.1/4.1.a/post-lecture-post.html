  • Simulation: SimLab
  • Self-check quiz: due before next class

The big picture: The detail worth keeping long after the quiz is that these four categories describe mechanism, not damage, and real attacks freely mix them, a worm that carries a trojan payload that later fetches ransomware isn't a contradiction, it's the normal case. That should reframe how you read the ransomware section, too: the popular image of ransomware as digital vandalism is wrong in a way that matters. It doesn't destroy your files, it locks them, which is precisely why the single most effective countermeasure isn't a smarter antivirus, it's an offline backup that makes the attacker's leverage worthless. Keep that distinction between destruction and encryption in mind, because the rest of Unit 4 is really the story of what you build to keep that leverage from ever existing: hardened devices (4.3.a) so the infection vector narrows, endpoint protection (4.3.b) so the payload gets caught mid-execution, and detection (4.4.a-c) so that even a successful infection gets noticed before it finishes its job.

Key terms to lock in:

  • Malware: malicious software intentionally designed to harm, steal from, or take control of a device or network.
  • Virus: malware that attaches to a host file and spreads when the host is executed or shared; requires user action to propagate.
  • Worm: self-replicating malware that spreads autonomously across networks by exploiting vulnerabilities; no host file or user action needed.
  • Trojan: malware disguised as legitimate software; relies on social deception for installation and does not self-replicate.
  • Ransomware: malware that encrypts victim files and demands payment for the decryption key.
  • Infection vector: the initial path or method by which malware enters a device or network.
  • Payload: the harmful action malware performs after infecting a system (beyond spreading).

Common misconceptions to watch for:

  • "Antivirus software catches all malware." → Signature-based tools miss new variants; behavioral detection helps but zero-day malware can evade it. Defense-in-depth (backups, patching, user awareness) is essential.
  • "Worms and viruses are the same thing." → Viruses need a host file and user action; worms are self-contained and spread without user interaction. The distinction changes which defenses matter most.
  • "Ransomware destroys your files." → Ransomware typically encrypts files, leaving them intact but inaccessible; the attacker can decrypt them if paid. The files are not gone, they are locked. Backups break this leverage entirely.

Learning objective(s): 4.1.A, 4.1.B
