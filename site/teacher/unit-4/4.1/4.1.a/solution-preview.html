Malware types (viruses, worms, trojans, ransomware) (MODEL SOLUTION, instructor copy, do not distribute)

Coding problem, 4.1.a: Classify malware by behavioral signature

Skill: Analyze Risk · Maps to: 4.1.A, 4.1.B · Language: Python 3 (pytest)

Problem

A security analyst receives short incident-report strings that describe observed device behavior. Build the classifier that maps each description to the correct malware category.

Categories: - "virus", attaches to host files; spreads when files are shared or opened - "worm", self-propagates across the network without user action; autonomous scanning - "trojan", disguised as legitimate software; creates backdoor / exfiltrates data - "ransomware", encrypts files; demands payment for decryption key

A report may match exactly one category. If no category matches, return "unknown".

Function contract

Implement solve(report: str) -> str in the code editor (see the Reference section below). Return the single category label string. Matching is case-insensitive substring detection using the indicator sets defined in the Reference section below.

Input

A single string describing observed behavior on a device or network.

Output

One of: "virus", "worm", "trojan", "ransomware", "unknown".

Examples

"Device is scanning all ports on the subnet with no user logged in" -> "worm"
"All .docx files have been encrypted; a ransom note appeared on the desktop" -> "ransomware"
"A free game installer is sending keystrokes to a remote server" -> "trojan"
"An email attachment infected the file and spread copies to shared folders" -> "virus"
"Battery usage is higher than usual after a long meeting" -> "unknown"

Constraints

  • Deterministic, offline, standard library only.
  • Detection by case-insensitive substring match against indicator sets in the Reference section below.
  • Exactly one label returned (string, not list).
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(report: str) -> str

Input (report)

A single string describing observed device or network behavior.

Output (result)

Exactly one string from {"virus", "worm", "trojan", "ransomware", "unknown"}.

Indicator phrase sets (case-insensitive substring match)

  • worm: scanning, self-propagat, autonomous, no user action, spreading across network, network scan, subnet scan, port scan, exploiting vulnerab
  • ransomware: encrypt, ransom, decryption key, locked, .locked, bitcoin, btc, pay to recover, files inaccessible
  • trojan: backdoor, keylog, exfiltrat, disguised, fake installer, remote control, command and control, c2, sending keystrokes, free crack, pirated
  • virus: host file, infected file, macro, attachment infected, spread copies, shared folder infect, email attachment, copied to usb, file infect
  • If no indicator matches: return "unknown".
  • Priority order when multiple sets match (should not occur in well-formed test data, but if it does): worm > ransomware > trojan > virus > unknown.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Matching is case-insensitive substring match.
  • Returns a single string (not a list).
