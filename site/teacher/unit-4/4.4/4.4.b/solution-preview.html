Coding problem, 4.4.b: Brute-force log correlator

Skill: Detect Attacks · Maps to: 4.4.B · Language: Python 3 (pytest)

Problem

An authentication log records every login attempt as an event with a username, a timestamp (in seconds), and a result ("SUCCESS" or "FAILED"). A brute-force attack shows up as a cluster of failed attempts for the same user, tightly packed in time. Build the correlator that scans the log and flags every username showing this pattern.

Function contract

Implement def solve(entries: list) -> list in the code editor (see the Reference section below).

Input

A list of dicts, each with keys ts (int, seconds since some reference point), user (str), result (str, "SUCCESS" or "FAILED"). Entries are not guaranteed to already be sorted by timestamp.

Output

A sorted list of usernames (str) flagged for a brute-force pattern.

Detection rule

A user is flagged if there exist 5 or more "FAILED" entries for that user where the time span from the earliest to the latest of those 5 (or more) entries is at most 60 seconds (inclusive). In other words: sort that user's failed-attempt timestamps ascending; if any 5 consecutive failed timestamps (in that sorted order) span 60 seconds or less (timestamps[i+4] - timestamps[i] <= 60), the user is flagged. SUCCESS entries do not count toward the failure count and do not reset or break a streak of failures, only FAILED entries matter for this rule.

Examples

[{"ts": 0, "user": "jsmith", "result": "FAILED"},
 {"ts": 13, "user": "jsmith", "result": "FAILED"},
 {"ts": 21, "user": "jsmith", "result": "FAILED"},
 {"ts": 30, "user": "jsmith", "result": "FAILED"},
 {"ts": 38, "user": "jsmith", "result": "FAILED"},
 {"ts": 46, "user": "jsmith", "result": "SUCCESS"},
 {"ts": 100, "user": "agarcia", "result": "FAILED"},
 {"ts": 1662, "user": "agarcia", "result": "FAILED"}]
    -> ["jsmith"]

(jsmith has 5 failures spanning 0-38s = 38s <= 60s -> flagged. agarcia has only 2 failures, 1562s apart -> not flagged.)

Constraints

  • Deterministic, offline, standard library only.
  • Input entries may arrive out of timestamp order; sort within your implementation.
  • Return a de-duplicated, alphabetically sorted list of usernames.
  • Must pass all cases in the tests (visible + hidden).

Entry point

def solve(entries: list) -> list

Input (entries)

A list of dicts, each an authentication log event:

key type meaning
ts int timestamp in seconds (not guaranteed sorted across the list)
user str username the attempt was made against
result str "SUCCESS" or "FAILED"

Output (result)

A de-duplicated, alphabetically sorted list of str usernames flagged for a brute-force pattern.

Detection rule

For each user, collect all FAILED timestamps and sort them ascending. The user is flagged if any 5 consecutive timestamps in that sorted list (t[i] through t[i+4]) satisfy t[i+4] - t[i] <= 60. A user needs at least 5 total failed attempts to be eligible; SUCCESS entries are ignored entirely for this rule (they do not reset or interrupt a failure streak).

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only unless the hidden grading tests: allow_deps` lists otherwise.
  • Input order is not guaranteed; sort per-user failed timestamps before evaluating the rule.
  • The 60-second window is inclusive (<= 60, not < 60).

# Reference solution """Reference solution for 4.4.b. MUST pass 100% of the tests. Also the default 'blackbox' implementation students can swap out (see the hidden grading tests).""" WINDOW_SECONDS = 60 MIN_FAILURES = 5 def solve(entries: list) -> list: """Flag usernames showing a brute-force pattern: 5+ FAILED attempts within any 60-second window. Args: entries: list of dicts with keys ts (int), user (str), result ("SUCCESS"/"FAILED"). Not guaranteed sorted by timestamp. Returns: Alphabetically sorted list of unique usernames flagged for brute-force. """ failures_by_user = {} for entry in entries: if entry.get("result") == "FAILED": user = entry["user"] failures_by_user.setdefault(user, []).append(entry["ts"]) flagged = set() for user, timestamps in failures_by_user.items(): timestamps.sort() if len(timestamps) < MIN_FAILURES: continue for i in range(len(timestamps) - MIN_FAILURES + 1): span = timestamps[i + MIN_FAILURES - 1] - timestamps[i] if span <= WINDOW_SECONDS: flagged.add(user) break return sorted(flagged)
