1. Brief

The situation. An authentication log records every login attempt as an event with a username, a timestamp (in seconds), and a result ("SUCCESS" or "FAILED"). A brute-force attack shows up as a cluster of failed attempts for the same user, tightly packed in time. Build the correlator that scans the log and flags every username showing this pattern.

Lesson objective. Explain what a security log records and why it matters, identify the common log sources security analysts review, and detect a brute-force login pattern by correlating multiple log entries over time.

What comes in

A list of dicts, each with keys ts (int, seconds since some reference point), user (str), result (str, "SUCCESS" or "FAILED"). Entries are not guaranteed to already be sorted by timestamp.

What must come out

A sorted list of usernames (str) flagged for a brute-force pattern.

Entry point

def solve(entries: list) -> list

Input (entries)

A list of dicts, each an authentication log event:

key type meaning
ts int timestamp in seconds (not guaranteed sorted across the list)
user str username the attempt was made against
result str "SUCCESS" or "FAILED"

Output (result)

A de-duplicated, alphabetically sorted list of str usernames flagged for a brute-force pattern.

Detection rule

For each user, collect all FAILED timestamps and sort them ascending. The user is flagged if any 5 consecutive timestamps in that sorted list (t[i] through t[i+4]) satisfy t[i+4] - t[i] <= 60. A user needs at least 5 total failed attempts to be eligible; SUCCESS entries are ignored entirely for this rule (they do not reset or interrupt a failure streak).

Guarantees / rules

  • Pure function, deterministic, no I/O, no network.
  • Standard library only unless the hidden grading tests: allow_deps` lists otherwise.
  • Input order is not guaranteed; sort per-user failed timestamps before evaluating the rule.
  • The 60-second window is inclusive (<= 60, not < 60).

Acceptance

3. Build it

This is the model solution.

  • [ ] solve handles the worked examples
  • [ ] solve handles your edge cases
WINDOW_SECONDS = 60 MIN_FAILURES = 5 def solve(entries: list) -> list: failures_by_user = {} for entry in entries: if entry.get("result") == "FAILED": user = entry["user"] failures_by_user.setdefault(user, []).append(entry["ts"]) flagged = set() for user, timestamps in failures_by_user.items(): timestamps.sort() if len(timestamps) < MIN_FAILURES: continue for i in range(len(timestamps) - MIN_FAILURES + 1): span = timestamps[i + MIN_FAILURES - 1] - timestamps[i] if span <= WINDOW_SECONDS: flagged.add(user) break return sorted(flagged)
