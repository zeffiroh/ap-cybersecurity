1. Brief

The situation. A security analyst receives short incident-report strings describing observed session behavior. Build the classifier that maps each description to the correct session-security category.

Categories: - "hijacking": an already-authenticated session token is stolen (XSS read, network sniffing, malware) and reused by an attacker - "fixation": an attacker supplies a session ID to the victim before login, then reuses that same ID after the victim authenticates - "insecure_cookie": the session cookie is missing a secure attribute (HttpOnly, Secure, or SameSite) that would have prevented exposure or misuse - "timeout_issue": a session remains valid far longer than it should because of a missing or misconfigured idle/absolute timeout - "secure": the report describes a session that is properly protected (regeneration, secure flags, timeouts all present) with no vulnerability - "unknown": nothing in the report matches any category

A report may match exactly one category. If no category matches, return "unknown".

Lesson objective. Explain how session tokens keep a user authenticated across requests, identify session hijacking and session fixation from a described scenario, and recommend the specific control (secure cookie flag, timeout, or session regeneration) that mitigates each.

What comes in

A single string describing observed session behavior on a device, browser, or server.

What must come out

One of: "hijacking", "fixation", "insecure_cookie", "timeout_issue", "secure", "unknown".

Input (report)

A single string describing observed session behavior on a device, browser, or server.

Output (result)

Exactly one string from {"hijacking", "fixation", "insecure_cookie", "timeout_issue", "secure", "unknown"}.

Indicator phrase sets (case-insensitive substring match)

  • fixation: fixation, pre-set session, attacker-supplied session, session id unchanged after login, id unchanged, session id before, known session id, id was already set
  • hijacking: sniffed, sniffing, intercepted, stolen session, stole the session, replayed, captured token, plain http, plaintext, read by an injected script, read via injected, malware read the, xss (only when paired with theft/read context, treated as a hijacking signal), reused by an attacker
  • insecure_cookie: missing httponly, no httponly, httponly flag, missing secure flag, no secure flag, missing samesite, no samesite, cookie has no, cookie is missing, readable from client-side javascript, not set to httponly
  • timeout_issue: no idle timeout, no timeout, without a timeout, left unattended, no absolute timeout, never expires, does not expire, session never times out, unattended for, abandoned, kiosk
  • secure: regenerated at login, session id regenerated, secure, httponly, all secure flags, properly secured, idle timeout combined with secure context, secure flags set, set secure, set httponly, samesite=strict, session expired automatically
  • If no indicator matches: return "unknown".
  • Priority order when multiple sets match (should not occur in well-formed test data, but if it does): fixation > hijacking > insecure_cookie > timeout_issue > secure > unknown. Rationale: fixation and hijacking describe an active compromise and must be surfaced first; insecure_cookie and timeout_issue describe latent misconfigurations; secure is the fallback "all clear" only when nothing else matched.

Guarantees / rules

  • Pure function, deterministic, no I/O, no network. Standard library only.
  • Matching is case-insensitive substring match.
  • Returns a single string (not a list).

def solve(report: str) -> str: if not isinstance(report, str): return "unknown" report_lower = report.lower() fixation_indicators = [ "fixation", "pre-set session", "attacker-supplied session", "session id unchanged after login", "id unchanged", "session id before", "known session id", "id was already set" ] if any(ind in report_lower for ind in fixation_indicators): return "fixation" hijacking_indicators = [ "sniffed", "sniffing", "intercepted", "stolen session", "stole the session", "replayed", "captured token", "plain http", "plaintext", "read by an injected script", "read via injected", "malware read the", "xss", "reused by an attacker" ] if any(ind in report_lower for ind in hijacking_indicators): return "hijacking" insecure_cookie_indicators = [ "missing httponly", "no httponly", "httponly flag", "missing secure flag", "no secure flag", "missing samesite", "no samesite", "cookie has no", "cookie is missing", "readable from client-side javascript", "not set to httponly" ] if any(ind in report_lower for ind in insecure_cookie_indicators): return "insecure_cookie" timeout_indicators = [ "no idle timeout", "no timeout", "without a timeout", "left unattended", "no absolute timeout", "never expires", "does not expire", "session never times out", "unattended for", "abandoned", "kiosk" ] if any(ind in report_lower for ind in timeout_indicators): return "timeout_issue" secure_indicators = [ "regenerated at login", "session id regenerated", "secure, httponly", "all secure flags", "properly secured", "secure flags set", "set secure", "set httponly", "samesite=strict", "session expired automatically" ] if any(ind in report_lower for ind in secure_indicators): return "secure" return "unknown"
