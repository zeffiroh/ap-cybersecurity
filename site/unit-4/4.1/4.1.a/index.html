Objective

Identify the four major malware categories, viruses, worms, trojans, and ransomware, describe how each spreads and causes harm, and classify a described infection by its behavioral signature.

Lesson

The word "malware" is a contraction of malicious software: any program intentionally designed to cause harm, steal data, disrupt operations, or give an attacker unauthorized control. Malware is not a single thing, it is a family of distinct weapon types, each with different mechanics. The AP framework focuses on four categories that account for the vast majority of real-world device compromises. Understanding them is the first step toward recognizing and stopping an attack.

Viruses are the oldest recognized malware category. A virus attaches its code to a legitimate host file, an executable, a document with embedded macros, or a script, and waits. When a user runs that host file, the virus code executes and typically searches for other files to infect, embedding a copy of itself in each one. The virus then spreads further every time an infected file is copied to another device or emailed to another user. Like a biological virus, it needs a host and user action (opening the file) to propagate. The payload, what the virus actually does beyond spreading, varies widely: some delete files, some corrupt data, some install backdoors. Key distinguishing trait: a virus requires a host file and direct user interaction to spread.

Worms are similar to viruses in that they replicate themselves, but they do not need a host file or user interaction. A worm is a self-contained program that actively probes a network, finds vulnerable devices, and copies itself across automatically. Once inside a new host it repeats the process. A single worm released on a university network can infect thousands of machines in minutes, consuming bandwidth and crashing systems even before its payload activates. The 2003 Slammer worm (rebuilt scenario in the simulation) doubled its infected-host count every 8.5 seconds by exploiting a single SQL Server flaw. Key distinguishing trait: self-propagating over a network with no user action required.

Trojans take their name from the ancient story of soldiers hidden inside a gift horse. A trojan presents itself as something useful or desirable, a free game, a pirated application, a "system cleaner" tool, but contains hidden malicious functionality. Unlike viruses and worms, trojans do not replicate; the attacker relies on the user to willingly install them. Once installed, trojans often open a back door that lets the attacker take remote control, steal credentials, log keystrokes, or use the machine as a launch point for further attacks (a "command and control" relationship). Because the user installed the software, security tools that rely on detecting unauthorized changes may not flag the initial infection. Key distinguishing trait: disguised as legitimate software; spread by social deception, not self-replication.

Ransomware is the most financially devastating malware category active today. After gaining access to a device (often through a phishing email or an unpatched vulnerability), ransomware encrypts the victim's files or entire drive with a key that only the attacker holds. A ransom demand then appears, typically requiring payment in cryptocurrency in exchange for the decryption key. If the victim has no offline backup, they face a stark choice: pay or lose the data. Modern ransomware campaigns target hospitals, schools, municipalities, and businesses, any organization that cannot afford downtime. Key distinguishing trait: encrypts data and demands payment; harm is financial and operational, not immediate destruction.

These categories are not mutually exclusive. A real attack often stacks them: a worm might carry a trojan payload that later downloads ransomware. Understanding each piece individually is what lets you recognize the combined threat.

How attacks begin. Malware enters a device through an infection vector, the initial path of entry. Common vectors include: phishing emails with infected attachments or links (covered in 1.1); drive-by downloads from compromised websites; infected USB drives; and exploitation of unpatched software vulnerabilities. Recognizing the vector matters because the defense is vector-specific: no attachment policy addresses email-delivered viruses, network segmentation limits worm spread, user education prevents trojan installation, and offline backups neutralize ransomware.

How to recognize an infection. Behavioral indicators vary by type. Unusual CPU or network activity with no open user application is a worm signature (it is scanning). New files appearing in unexpected locations, or known files suddenly growing, suggests a virus. A system that behaves strangely despite appearing legitimate hints at a trojan. Files suddenly inaccessible and a demand message is unmistakably ransomware. The coding problem in problem/ asks you to build a classifier that reads behavioral signatures and maps them to the correct malware type, the same reasoning a security analyst applies when triaging an incident report.

Key terms

  • Malware, malicious software intentionally designed to harm, steal from, or take control of a device or network.
  • Virus, malware that attaches to a host file and spreads when the host is executed or shared; requires user action to propagate.
  • Worm, self-replicating malware that spreads autonomously across networks by exploiting vulnerabilities; no host file or user action needed.
  • Trojan, malware disguised as legitimate software; relies on social deception for installation and does not self-replicate.
  • Ransomware, malware that encrypts victim files and demands payment for the decryption key.
  • Infection vector, the initial path or method by which malware enters a device or network.
  • Payload, the harmful action malware performs after infecting a system (beyond spreading).

Common misconceptions

  • "Antivirus software catches all malware." → Signature-based tools miss new variants; behavioral detection helps but zero-day malware can evade it. Defense-in-depth (backups, patching, user awareness) is essential.
  • "Worms and viruses are the same thing." → Viruses need a host file and user action; worms are self-contained and spread without user interaction. The distinction changes which defenses matter most.
  • "Ransomware destroys your files." → Ransomware typically encrypts files, leaving them intact but inaccessible; the attacker can decrypt them if paid. The files are not gone, they are locked. Backups break this leverage entirely.
