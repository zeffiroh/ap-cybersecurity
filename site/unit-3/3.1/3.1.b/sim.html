3.1.b, Resolver Race Console[_][^][X]

Objective

A recursive resolver logged two candidate replies for the same outstanding query. Decide whether the second (later-arriving in log order) reply is a WIN for the real authoritative server, a successful POISON by an attacker, or a REJECT (the resolver correctly discards it because it does not match the outstanding query). A reply is only a valid candidate answer if its tx_id, qport, and qname all match the original query. Among valid candidates, the reply that arrived FIRST is cached; if that first-arrived valid reply is the attacker's forged one, the event is POISON; if it's the legitimate server's, it's WIN. Reach 6 correct calls to meet the objective.
