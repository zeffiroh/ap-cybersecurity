3.3 Activities

Network Segmentation · 2

Skill 3.3.a · pairs · 20 min · Offline: yes

VLANs and network segmentation

Goal

Students design a VLAN segmentation scheme for a small office network, assign hosts to VLANs, and argue which traffic flows should be permitted or blocked. Ties to LO 3.3.A (explain how VLANs segment a network to reduce risk).

Materials

Printed host inventory (if no laptop)

Host Role
WS-01, WS-02 Employee workstations
PRT-01 Department printer
SRV-01 File server
SRV-02 HR payroll database
CAM-01 IP security camera
GUEST-01 Visitor laptop
MGMT-01 Network switch management interface

Steps

Check off all materials above to unlock the steps.
  1. Each pair draws four VLAN boxes on paper (Management, Employee, Server, Guest/IoT) and assigns each host in the inventory to one VLAN. They must be ready to justify each placement.
  2. The pair writes three traffic flow statements (e.g., "WS-01 sends a file request to SRV-01") and decides: Allow or Block? They circle their answer and write one sentence of justification.
  3. Pairs open the simulation, enter their VLAN assignments, and run the test flows to see whether the sim agrees. For any disagreement, they revise their reasoning.

Collaborate

Assign roles: one partner is the "network designer" (defends the VLAN placement), the other is the "red team analyst" (argues which flows an attacker would try first if they compromised GUEST-01). After step 3, swap roles and repeat with MGMT-01 as the hypothetical target.

Exit Ticket

AP

Certificate of Completion

Each student submits: their finalized VLAN map (4 VLANs, all 7 hosts assigned) plus one sentence explaining why SRV-02 (payroll) should never be reachable from the Guest VLAN even if a firewall rule was accidentally left open.

Skill 3.3.b · Pairs or small groups · 30 min · Offline: yes

Traffic isolation and zero-trust segmentation

Goal

Students will design a secure network topology for a healthcare clinic using Private VLAN (PVLAN) isolation and Zero Trust principles. They will identify port-isolation states and specify access-control policies to prevent lateral movement of malware (e.g., ransomware) between patient-facing and backend medical devices.

Materials

Scenario: The Oakridge Clinic

Oakridge Clinic has a flat network where everything is on one subnet (192.168.1.0/24). They recently experienced a security incident where malware on a waiting room check-in tablet spread to their local Electronic Health Records (EHR) server. The clinic's devices include: 1. Default Gateway / Router (192.168.1.1): Connects the clinic to the internet. 2. EHR Local Database Server (192.168.1.10): Contains sensitive patient medical histories. 3. Doctor Workstations (3 hosts): Used by doctors to retrieve and update records. 4. Waiting Room Check-in Tablets (2 hosts): Used by patients to check in. 5. Guest Wi-Fi Access Point (1 host): Used by patients waiting in the lobby. 6. MRI Imaging Machine (1 host): Runs an older legacy operating system that cannot be updated.

Steps

Check off all materials above to unlock the steps.
  1. Analyze Vulnerabilities (10 min): In your group, list the traffic flows that are absolutely necessary for the clinic to function. For example, do the check-in tablets need to speak to the doctor workstations? Does the MRI machine need internet access?
  2. Apply Private VLANs (10 min): Map the 6 types of devices listed above to Private VLAN port designations to restrict layer-2 communication:
  3. Promiscuous Port(s): Which devices must talk to everything?
  4. Isolated Port(s): Which devices must never talk to each other?
  5. Community Port(s): Which devices need to talk to each other in a small group, but not the rest of the network?
  6. Zero Trust Access Policy (5 min): The clinic plans to place a Zero Trust Access Proxy in front of the EHR Database Server. Define a set of 3 rules/checks the proxy must run before allowing a doctor workstation to query the server (e.g., identity, location, device health posture).

Collaborate

Assign roles within your pair/group: - Network Architect: Designs the PVLAN mapping. - Security Analyst: Designs the Zero Trust policy rules. Compare designs with another group. Discuss: If an attacker compromises the Guest Wi-Fi Access Point, does your design prevent them from reaching the EHR Server or the legacy MRI machine? Why?

Exit Ticket

AP

Certificate of Completion

Each student submits a written response: "Explain how Private VLAN (PVLAN) isolated ports differ from traditional VLANs in limiting the blast radius of a compromised device inside a corporate office."
