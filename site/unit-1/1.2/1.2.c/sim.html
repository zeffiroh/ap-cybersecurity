1.2.c -- MFA Implementation: TOTP Login Simulator[_][^][X]

Objective

You run the login server. Each scenario shows what the user's authenticator app displayed and what code reached your server, and when. Decide whether the server should ACCEPT or REJECT the code, then read why. Reach 5 correct to meet the objective.

Server rules: step = floor(unix time / 30), so a code lives for one 30-second step. The server recomputes the code from its copy of the user's secret key and the current step, accepts only an exact match for the current step, and remembers used codes so each one works only once.

totp-server> Awaiting login attempt...
SCORE 0 / 5 | answered 0 of 7 | OBJECTIVE: not yet met
TOTP (RFC 6238): step = floor(t / 30); code = 6 digits taken from HMAC-SHA1(secret, step). This sim uses a simplified stand-in for HMAC-SHA1 so it runs offline, but the rules are the real ones: same secret + same step = same code; a different secret or a different step gives a different code.
