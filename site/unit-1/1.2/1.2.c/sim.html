Objective

For each scenario below, compute the 6-digit TOTP code that the authenticator app would display, then enter it to log in. Reach 4 correct to meet the objective. Use the TOTP algorithm: code = HMAC-SHA1(secret, step)[offset..offset+4] mod 10^6 (see legend). The sim computes the correct answer internally -- your job is to understand when a code is valid and predict the outcome.
